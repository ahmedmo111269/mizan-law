# متطلبات المحاسبة

## متطلبات معتمدة
- [REQ-016] محاسبة متكاملة بقيد مزدوج تشمل دليل الحسابات والقيود اليومية والأستاذ العام وميزان المراجعة والخزائن والحسابات البنكية والإيرادات والمصروفات والأتعاب والمستحقات والتحصيلات والمدفوعات وحسابات الموكلين وأموال الموكلين لدى المكتب والربط بالملفات عند الحاجة والتقارير المالية.
- [REQ-016] فصل بيانات العمل القانوني عن القيود المحاسبية مع علاقات لازمة؛ سلامة القيود وتوازنها.
- [REQ-017] مراعاة خصوصية المالية عند المزامنة والنقل.

## قرارات مؤجلة
[يحتاج قرار] لا دليل حسابات نهائي ولا سياسة محاسبية معتمدة. لم تُحدد قواعد ترحيل القيود أو تعديلها أو إلغائها، ولا معالجة نقل القيود، ولا سياسات التعارض الخاصة بالسجلات المالية أو السماح بتعديلها المتزامن.
