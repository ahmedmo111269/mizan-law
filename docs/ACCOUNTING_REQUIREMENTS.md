# متطلبات المحاسبة

## متطلبات معتمدة
- [REQ-016] محاسبة متكاملة بقيد مزدوج تشمل دليل الحسابات والقيود اليومية والأستاذ العام وميزان المراجعة والخزائن والحسابات البنكية والإيرادات والمصروفات والأتعاب والمستحقات والتحصيلات والمدفوعات وحسابات الموكلين وأموال الموكلين لدى المكتب وحساب مستقل لكل ملف وإجمالي للموكل داخل القاعدة نفسها والتقارير المالية.
- [REQ-016] فصل بيانات العمل القانوني عن القيود المحاسبية مع علاقات لازمة؛ سلامة القيود وتوازنها.
- [REQ-017] مراعاة خصوصية المالية عند المزامنة والنقل.

## القرارات السلوكية المعتمدة في إغلاق المرحلة

المرجع: `DECISIONS.md`؛ التنفيذ التقني غير مختار.

- [ADQ-33] حساب مالي مستقل لكل ملف، وحساب إجمالي للموكل يجمع ملفاته داخل القاعدة نفسها. يظل تتبع كل مبلغ إلى الملف والعملية الأصلية ممكنًا. لا تُجمع الحسابات بين قواعد مستقلة تلقائيًا.
- [ADQ-34] لا يُحرر ولا يُمحى القيد المُرحّل. يُعالج التصحيح بقيد عكسي أو تصحيحي مترابط وموثق. يمكن تعديل المسودة قبل الترحيل.
- [ADQ-35] فترات قابلة للإعداد، مع إقفال وإعادة فتح بصلاحيات وسجل تدقيق. لا تُفترض فترات ثابتة لا يمكن تغييرها، ولا يُعدّل قيد في فترة مقفلة دون إجراء معتمد؛ وتظل قاعدة عدم تحرير القيد المُرحّل في ADQ-34 نافذة.
- [ADQ-36] دفتر أستاذ عام مع دفتر فرعي مستقل لأموال الموكلين والتسوية بينهما، وفصل الأموال المحتفظ بها نيابة عن الموكلين عن إيرادات المكتب ومصروفاته.
- [ADQ-37] دعم تعدد العملات، مع عملة أساسية لكل قاعدة، وحفظ العملة الأصلية وسعر الصرف المستخدم والقيمة المحاسبية المحولة. لا تُجمع مبالغ بعملات مختلفة دون تحويل واضح.

- [ADQ-16، ADQ-19، ADQ-22] لا دمج أو تعديل تلقائي للقيود المالية عند التعارض، ولا أثر مكرر لإعادة المحاولة؛ بيانات الملف المالية ضمن النقل الصريح مع تتبع المصدر والتحقق من اكتمالها.

## تفاصيل محاسبية مؤجلة

دليل الحسابات التفصيلي، إجراءات الترحيل والتصحيح والتسوية، ضبط الفترات وأسعار الصرف والتقارير المتخصصة ومعالجة النقل محاسبيًا، ضمن الحدود أعلاه. لا نموذج قيد تنفيذي ولا سياسة تخصصية مستنتجة.
