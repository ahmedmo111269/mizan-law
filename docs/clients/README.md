## 1. لماذا هذه الوحدة مكتوبة بهذا الشكل

أمر صاحب المشروع لهذه المرحلة يجمع شرطين متوترين ظاهريًا: أن يكون التصميم **شاملًا وعميقًا** (نموذج هوية، رحلات، نموذج بيانات، عقود، تخصيص، سيناريوهات)، وأن يبقى **في حدود التحليل** (لا تنفيذ ولا قرارات تقنية). الحل المعتمد في هذه الحزمة:

1. **الفصل بين المواصفة والتنفيذ.** كل ما هو قابل للتنفيذ مباشرة يُكتب كقاعدة سلوكية أو عقد، لا كخوارزمية ولا كاختيار تقنية.
2. **تثبيت القرار المعتمد قبل الابتكار.** كل جملة في هذه الوثائق مسنودة إلى معرف معتمد (`ADQ-xx` / `REQ-xxx` / قاعدة في `docs/DOMAIN_MODEL.md`)، وما لا سند له فمعلّم صراحةً `[مقترح]`.
3. **فصل «الموصوف» عن «المعتمد».** تُستخدم بطاقات حالة صريحة في كل جدول: `[معتمد]`، `[مقترح]`، `[معلّق]`، `[خارج نطاق الوحدة]`.

## 2. قواعد قراءة الحزمة

- `[معتمد]` — سلوك أو حدّ مقرّ في سجل قرارات المشروع؛ يُنفَّذ كما هو.
- `[مقترح]` — تصميم اقترحه هذا التقرير؛ لا يسري إلا بعد اعتماد صريح.
- `[معلّق]` — مسألة تحتاج قرارًا من صاحب المشروع؛ رقمها في `CLIENTS_OPEN_DECISIONS.md` بصيغة `CD-nn`.
- `[خارج نطاق الوحدة]` — مسؤول نظام عام آخر؛ الوحدة تستهلكه ولا تنشئ نسخة موازية منه.
- الأسماء الإنجليزية مثل `ClientEngagement` **مقابض توثيقية** للحديث عن المفهوم، وليست أسماء جداول أو كيانات أو دوال تنفيذية.
- **لا يرد في هذه الحزمة**: مخطط SQL، أو جداول، أو مفاتيح، أو أنواع بيانات، أو إطار عمل، أو محرك قاعدة بيانات، أو شيفرة. هذه المرحلة ممنوعة صراحةً، والقرارات التقنية كلها مؤجلة في `docs/TECHNICAL_DECISIONS_PENDING.md`.

## 4. ترتيب القراءة الموصى به

1. `CLIENTS_MODULE_VISION.md` — لفهم الحدود والمبادئ قبل أي تفصيل.

3. `CLIENTS_INFORMATION_ARCHITECTURE.md` و`CLIENTS_UX_SPECIFICATION.md` — للواجهة.

## 6. حدود هذه الحزمة بالضبط

- **ما تم:** تصميم وظيفي وتجربة استخدام ونموذج بيانات منطقي وعقود تكامل مقترحة، مع تحقق نظري بالسيناريوهات.
- **ما لم يتم عمدًا:** شيفرة، مخطط قاعدة بيانات، مخطط SQL، اختيار لغة/إطار/محرك، نماذج أولية تفاعلية، بيانات اختبار، وتقديرات أداء غير مقاسة.
- **ما لا يُفترض:** أن أي `[مقترح]` في هذه الحزمة أصبح قرارًا. الانتقال إلى التنفيذ يحتاج اعتمادًا صريحًا للقرارات في `CLIENTS_OPEN_DECISIONS.md`، ثم تكليفًا منفصلًا بمرحلة التنفيذ.
