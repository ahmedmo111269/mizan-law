## 2. مسارا إضافة الموكل

### 2.1 المسار (أ): الإضافة السريعة

**الهدف:** حفظ صالح خلال أقل من 30 ثانية، مع إمكانية الاستكمال لاحقًا.

**الحقول:**

| # | الحقل | إلزامي؟ | الملاحظة |
|---|---|---|---|
| 1 | نوع الشخص | ✔ | افتراضي: شخص طبيعي |
| 2 | الاسم الرئيسي | ✔ | تحقق سريع أثناء الكتابة |
| 3 | وسيلة تواصل واحدة (نوع + قيمة) | اختياري | يمكن تركه فارغًا صراحةً |
| 4 | تصنيف/وسم (اختياري) | ✖ | — |
| 5 | ملاحظة أولية (اختياري) | ✖ | سطر واحد |

**السلوك:**

| المرحلة | السلوك |
|---|---|
| أثناء الكتابة في الاسم | يظهر **تنبيه تشابه** (لا يمنع) إذا وُجد تشابه: «يوجد 2 سجلات قريبة» ومعاينة الأسماء |
| عند الضغط «حفظ» | يُنشأ السجل **في السجل المشترك** (الهوية) **وعلاقة موكل في القاعدة النشطة** كوحدة واحدة (ADQ-19) |
| أثناء الحفظ | الزر معطّل مع مؤشر «جارٍ الحفظ…» |
| بعد الحفظ | انتقال إلى **البطاقة** مع فتح قسم «يحتاج استكمالًا» تلقائيًا، وحالة نجاح تختفي تلقائيًا |
| الخيار البديل | «حفظ وإضافة آخر» (للإدخال المتتابع) + «حفظ وربط بملف» (إن كان المستخدم في سياق ملف) |

**رسائل الفشل:**

| الحالة | الرسالة | الإجراء المتاح |
|---|---|---|
| الاسم فارغ | «الاسم مطلوب» | ينقل التركيز إلى الحقل |
| تعارض تزامن على نفس السجل | «عدّل السجل من جهاز آخر. تم تحديث النسخة المعروضة» | تحديث + إعادة المحاولة |
| تعارض هوية | «لا يمكن الحفظ: يوجد تعارض غير محسوم» | فتح شاشة التعارض |
| انقطاع اتصال | «تم الحفظ على هذا الجهاز. سيُزامَن لاحقًا» | **نجاح** مع تنبيه حالة |

### 2.2 المسار (ب): الإضافة التفصيلية

**البنية:** أقسام مرئية تدريجيًا، كل قسم له «التفاصيل» القابلة للفتح:

| القسم | المحتوى | إلزامي |
|---|---|---|
| 1. الهوية | الاسم الرئيسي، الرسمي، البديلة، النوع | الاسم الرئيسي |
| 2. المعرّفات | المعرّف الوطني/التجاري/الضريبي/الآخر | لا شيء (عند الحاجة فقط) |
| 3. التواصل | وسائل الاتصال + المفضلة | لا شيء |
| 4. العناوين | العناوين بنوعها | لا شيء |
| 5. الصفة في المكتب | علاقة الموكل: التصنيف، تاريخ الفتح، تفضيلات | لا شيء |
| 6. الصفات والقيود | جهات التمثيل، الصفة داخل الملفات القائمة | — |
| 7. ملاحظات ووسوم | — | — |
| 8. متقدم | الحقول المخصصة | — |

**مبدأ:** الأقسام 2–4 تظهر **عند الحاجة** ولا تربك من يريد الإدخال السريع. كل قسم قابل للطي مع تذكر حالة الطي (تفضيل محلي).

## 3. كتالوج الحقول

### 3.1 مفاتيح القراءة

| الرمز | المعنى |
|---|---|
| **النطاق** | `تثبيت` = سجل الأشخاص المشترك (مشترك بين قواعد التثبيت) — `قاعدة` = بيانات القاعدة النشطة فقط |
| **الإلزام** | `مطلوب` = يمنع الحفظ — `اختياري` — `مطلوب عند الحاجة` (يظهر فقط عندما ينطبق) |
| **الحساسية** | `عادية` / `حساسة` (بيانات تعريف) / `حساسة جدًا` (تحدد هوية قانونية) |
| **البحث** | `نعم` = مفهرسة للبحث؛ `جزئي` = بحث حرفي فقط؛ `لا` |
| **التاريخ** | `نعم` = يُحفظ تاريخ آخر تعديل للقيمة؛ `لا` |
| **المصدر** | من أين تأتي القيمة أول مرة: `إدخال المستخدم` / `مستند مُعرَّف` / `استيراد` / `مزامنة` / `مشتق` |

## 4. سلوك التحقق من التكرار

### 4.1 متى يفحص النظام

| التوقيت | الوصف | الشدة |
|---|---|---|
| أثناء الكتابة | بعد 3 أحرف في الاسم أو إدخال رقم/معرّف | تنبيه لطيف في حقل الاسم: «3 سجلات قريبة» |
| عند الحفظ | فحص شامل | تنبيه في نافذة مقارنة (لا يمنع) |
| عند تطابق موثوق | تطابق تام في معرّف رسمي | **منع** مع عرض السجل القائم ومسار «فتحه بدلًا من ذلك» |

### 4.2 نافذة المقارنة

| عنصر | المواصفة |
|---|---|
| العنوان | «هل هذا الشخص موجود بالفعل؟» |
| السجل الجديد | ملخص: الاسم + النوع + المعرّف + التواصل |
| السجل القائم | نفس الأعمدة + قاعدة السجل + آخر نشاط |
| **الأدلة** | قائمة ما تطابق: «نفس الرقم»، «نفس الهاتف»، «الاسم متقارب» |
| الخيارات | ① «إنشاء سجل مستقل رغم التشابه» ② «فتح السجل القائم وربطه» ③ «إلغاء» |
| مبدأ | **لا يوجد خيار دمج هنا**؛ الدمج إجراء منفصل بصلاحيات (ADQ-13) |
| التوثيق | الخيار ① يُسجَّل في سجل النشاط مع سبب |

> **قاعدة UX مستمدة من ADQ-11**: يُعرض في النافذة سطر: «**الاسم وحده لا يثبت أن الشخص واحد**». هذه الجملة تظهر للمستخدم، لا في الوثيقة التقنية فقط.

### 4.3 قائمة مراجعة التكرار

| البند | المواصفة |
|---|---|
| المدخل | تشابهات مكتشفة تلقائيًا (اسم/هاتف/معرّف) + مراجعات يدوية |
| الأعمدة | الاسم، قاعدة السجل، سبب الاشتباه، تاريخ الاكتشاف، حالة المراجعة |
| الحالات | «جديد»، «تمت المراجعة — مستقل»، «تمت المراجعة — مرتبط»، «مؤرشف» |
| الإجراء | فتح المقارنة (S-04) |
| المالك | مسؤول النظام (أو من يفوضه) |
| الدورية | أسبوعية مقترحة |

## 5. الحالات الواجهة الإلزامية

| # | الحالة | المعالجة |
|---|---|---|
| E1 | تحميل أول | هيكل (skeleton) يحافظ على الشكل، لا مؤشر دوّار في المنتصف |

| E5 | لا عملاء بعد | «لم تُسجَّل أي موكل بعد» + «أضف أول موكل» + «استورد من ملف» (ADQ-45) |
| E6 | لا ملفات مرتبطة | «لا توجد ملفات مرتبطة في هذه القاعدة» + «أنشئ ملفًا لهذا العميل» |

| E10 | تعارضات | لافتة: «3 تعديلات متعارضة تحتاج مراجعتك» + رابط |
| E11 | قاعدة غير متاحة | «تعذّر فتح قاعدة (س)» + إبقاء ما يمكن عرضه |

| E15 | فشل الحفظ | يبقى الإدخال كما هو + رسالة + «إعادة المحاولة» |

## 6. الحفظ والتراجع

| البند | المواصفة |
|---|---|
| الحفظ التلقائي | **للنماذج الطويلة**: مسودة محفوظة محليًا كل 30 ثانية (أو عند تغيير حقل) |
| استعادة المسودة | عند إعادة فتح المسودة: «لديك مسودة غير محفوظة. استعادتها؟» |
| منع الحفظ المزدوج | تعطيل الزر + معرّف عملية (ADQ-19) |
| تراجع بعد الحفظ | إشعار مع «تراجع» لمدة محدودة (5–10 ثوانٍ) — للإجراءات القابلة للتراجع البسيط |
| تراجع معقّد | لا يُعتمد على «تراجع» وحده؛ تُستخدم السلة/الأرشيف (ADQ-40، ADQ-31) |
| ذرّية | فشل أي جزء = فشل العملية كلها (ADQ-19) |
| أثر التعديل على الأجزاء الأخرى | **معاينة الأثر قبل التنفيذ** (انظر J13) |

## 9. استجابة الهاتف والكمبيوتر

### 9.1 كيف تتغير البنية فعليًا

| البنية | الكمبيوتر | الهاتف | السبب |
|---|---|---|---|
| **جدول الموكلين** | جدول بأعمدة | **بطاقات**: الاسم + الصفة + آخر نشاط + مؤشر تعارض | الجدول على 360 بكسل يفرض تمريرًا أفقيًا |
| **البطاقة** | عمود + فهرس جانبي ملتصق | أقسام مكدّسة + أكورديون | لا يوجد هامش لفهرس جانبي |
| **الفلاتر** | شريط ثابت | ورقة منبثقة من الأسفل | لا مساحة أفقية |
| **المعاينة** | لوحة جانبية | صفحة كاملة | لا مساحة للطبقة الجانبية |
| **الأفعال** | قائمة منسدلة | شريط سفلي (إجراءان) + «المزيد» | الوصول بالإبهام |
| **الإضافة** | نموذج في نافذة | **صفحة كاملة متدرجة** | الحقول تُدخل بلوحة المفاتيح دون أن تحجبه |
| **المقارنة (تكرار)** | جنبًا إلى جنب | تبويبان: «الجديد» / «الموجود» | لا عرض مزدوج في 360 |
| **الفرز** | نقر على رأس العمود | قائمة فرز | المس على رؤوس الأعمدة |
| **التحديد المتعدد** | شيك + أفعال جماعية | إجراء واحد لكل صف | الإبهام |

### 9.2 نقاط العرض المطلوبة

### 9.3 المساحات الآمنة ولوحة المفاتيح على الهاتف

| الحالة | السلوك |
|---|---|
| فتح لوحة المفاتيح | لا يُغطى زر الحفظ؛ يتحرك لأعلى |
