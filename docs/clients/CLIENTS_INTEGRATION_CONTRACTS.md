## 1. حالة الواقع: لا توجد عقود قائمة

> فحص المستودع في هذه المرحلة: **لا توجد منظومة تشغيل ولا عقود تنفيذية**. الوثائق المتاحة كلها **متطلبات سلوكية** معتمدة، وليست عقودًا تقنية.

| المطلوب في أمر المرحلة | الموجود فعلًا | القرار |
|---|---|---|
| «راجع العقود الموجودة للبحث والتخصيص والأمان والنشاط والمستندات» | **لا توجد**؛ يوجد: `docs/PERFORMANCE_REQUIREMENTS.md`، `docs/SECURITY_REQUIREMENTS.md`، `docs/DATA_INTEGRITY.md`، `docs/DOCUMENT_REQUIREMENTS.md`، `docs/SYNC_REQUIREMENTS.md` — كلها سلوكية | هذه الوثيقة **تضع مسودات عقود** مبنية على السلوك المعتمد |
| «استخدم منظومة البحث والتصفية العامة إذا كانت موجودة» | **غير موجودة** | يُقترح **عقد بحث عام** (§9 في `CLIENTS_SEARCH_AND_FILTERS.md`) |
| «لا تنشئ أنظمة موازية لوظائف عامة موجودة» | لا يوجد ما يُوازى | الوحدات هي **المالكة** لهذه الوظائف، والوحدة **مستهلك** |

> **قاعدة**: كل عقد أدناه **مسودة مقترحة** بُنيت على السلوك المعتمد، وليست وصفًا لتطبيق قائم.

## 3. C1 — سجل الأشخاص المشترك

| البند | المواصفة |
|---|---|
| **الاتجاه** | ثنائي: الوحدة تكتب الهوية، وتقرأها |
| **نطاق البيانات** | الهوية والتعريف ووسائل الاتصال والعنوان فقط (ADQ-10) |
| **ما لا يعبر** | ملفات، قضايا، بيانات مالية، ملاحظات القاعدة، تصنيفات القاعدة (ADQ-10، A-27) |
| **الكتابة** | عند إنشاء موكل جديد، أو تعديل حقل هوية |
| **القراءة** | عند فتح البطاقة، أو البحث في S2، أو ربط ممثل |
| **غير المتصل** | **الكتابة مسموحة محليًا** وفق ضوابط الوصول (ADQ-14، A-24) |
| **الذاكرة المحلية** | نسخة محلية من السجل على كل جهاز (ADQ-14) |
| **المزامنة** | نقل التغييرات عند توفّر وسيلة اتصال (ADQ-14) |
| **التعارض** | **حفظ التعديلين وإتاحتهما للمراجعة والحسم**؛ لا محو ولا استبدال صامت (ADQ-16، A-26) |
| **الترتيب** | تسلسل منطقي + توقيت مرجعي (ADQ-15) |
| **المستوى** | الحقل (مقترح) — `CD-09` |
| **الدمج** | إجراء صريح بصلاحية، يحفظ المعرفات السابقة والإحالات والتاريخ، وله تراجع منضبط (ADQ-13) |
| **الواجهة** | الوحدة **لا تملك واجهة السجل**؛ تعرض الهوية كجزء من بطاقتها، وتترك إدارة السجل العام لنظام السجل |
| **معلّق** | `CD-02`: من يملك الكتابة؟ |

## 4. C2 — وحدة الملفات والقضايا

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة من الوحدة (الملفات ← الموكلون) |
| **ما تقرأه الوحدة** | الملفات المرتبطة بالشخص، الصفة في كل ملف، القضايا المرتبطة، الحالات |
| **العلاقة** | متعدد إلى متعدد، مع صف (القاعدتان 1–2 من `DOMAIN_MODEL`) |
| **الكتابة** | **لا تكتب الوحدة** في ملفات أو قضايا؛ ولا تنشئ ملفًا من داخل الموكلين (تفتح مسار الإنشاء في وحدة الملفات) |
| **الصف** | يُقرأ من العلاقة، ولا يُشتق من كون الشخص موكلًا |
| **الملف بلا قضية** | حالة عادية معروضة، لا خلل |
| **الملفات في قواعد أخرى** | لا تظهر في قسم الملفات داخل القاعدة الحالية؛ تظهر في البحث الشامل مع اسم القاعدة (ADQ-41) |
| **الأرشفة** | أرشفة الموكل **لا** تمس الملفات (ADQ-40) |
| **النقل بين القواعد** | نقل الملف ينقل أطرافه وصفاتهم، **ولا ينشئ هوية شخص جديدة** (ADQ-22) |
| **الحساب المالي** | عبر C3، لا عبر الملفات |

## 5. C3 — وحدة المحاسبة

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة فقط من الوحدة |
| **ما تعرضه** | إجمالي الموكل **داخل القاعدة نفسها** فقط (ADQ-33)، وأحدث العمليات إن كانت مرئية |
| **ما لا تعرضه** | حسابات ملفات من قواعد أخرى (ADQ-33: «لا تُجمع الحسابات بين قواعد مستقلة تلقائيًا») |
| **القيود** | لا تحرير ولا حذف ولا ترحيل (ADQ-34) |
| **العملات** | لا جمع بين العملات (ADQ-37) |
| **الخصوصية** | إجمالي الموكل بيانات مالية؛ يخضع لقيود الوصول (ADQ-17، ADQ-27) |
| **عند الأرشفة** | الأرشفة **لا** تؤرّف القيد ولا تمسه (ADQ-34) |

## 6. C4 — وحدة المستندات

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة من الوحدة |
| **ما تعرضه** | روابط المستندات المرتبطة بالشخص أو بعلاقته |
| **الأصل** | لا يُنسخ ولا يُحمّل داخل الوحدة؛ الفتح يتم في وحدة المستندات |
| **الروابط المتعددة** | مستند واحد قد يرتبط بسجلات متعددة (ADQ-30) — لا يُفترض ملكيته للموكل |
| **الإصدارات** | تُعرض إصدارات المستند في وحدة المستندات (ADQ-38) |
| **الربط عبر القواعد** | **لا يوجد ربط حي تلقائي** بين قواعد مستقلة (ADQ-30) |
| **الحماية** | المستندات الحساسة محمية (ADQ-24) |

## 7. C5 — سجل النشاط والتدقيق

| البند | المواصفة |
|---|---|
| **الاتجاه** | كتابة أحداث (من الوحدة) + قراءة السجل (في الوحدة) |
| **النوع** | سجل إلحاقي غير قابل للتحرير العادي (ADQ-32) |
| **ما تُسجّله الوحدة** | إنشاء موكل، تعديل حقل، أرشفة، استعادة، نقل إلى السلة، قرار «سجل مستقل رغم التشابه»، تعارض، مزامنة، دمج |
| **الحقول** | الحدث، السجل، المستخدم، الجهاز، التوقيت، النتيجة، القيمة قبل/بعد «حيثما أمكن» (ADQ-32) |
| **تقليل البيانات الحساسة** | **لا تُسجَّل قيم حساسة غير لازمة**: يكفي اسم الحقل ونوع التغيير في بعض الحالات (ADQ-32، ADQ-27) |
| **المصدر** | معرّف المستخدم + معرّف الجهاز |
| **القراءة** | صفحة مستقلة داخل الوحدة، بفلاتر (نوع الحدث، المستخدم، الفترة) |
| **العدم** | سجل النشاط **لا يُحذف** ولا يُعدّل (ADQ-31، ADQ-32) |

## 8. C6 — نظام الصلاحيات

| البند | المواصفة |
|---|---|
| **الاتجاه** | استعلام من الوحدة + تطبيق |
| **المبدأ** | الصلاحيات **قيد فعلي على الوصول والعمليات**، لا إخفاء عناصر واجهة (ADQ-25) |
| **التطبيق** | الفحص يقع عند **الاستعلام عن البيانات** لا عند رسم الشاشة |
| **النسخة المحلية** | النسخة المحلية الكاملة لا تعني إتاحة كل البيانات لكل مستخدم (REQ-004) |
| **التحديث** | قد لا تصل تحديثات الصلاحيات إلى جهاز غير متصل فورًا (ADQ-25) |
| **الأثر على الواجهة** | العنصر المعطّل **يُخفى** ويُعلَّم؛ إن كان الإجراء متاحًا في الواجهة ومرفوضًا عند التنفيذ، تُعرض رسالة «غير متاح الآن» |
| **الأدوار** | قائمة الأدوار مؤجلة في المشروع؛ تصور الأدوار في `CLIENTS_USER_JOURNEYS.md` §2 **فرضية اختبار** |

## 9. C7/C8 — منظومة البحث والتخصيص

| البند | المواصفة |
|---|---|
| **C7 — البحث** | المسودة الكاملة في `CLIENTS_SEARCH_AND_FILTERS.md` §8 |
| **C8 — التخصيص** | المسودة الكاملة في `CLIENTS_CUSTOMIZATION.md` §9 |

| **مصدر الحقيقة** | منظومة البحث والتخصيص؛ الوحدة **مستهلك** |

## 10. C9 — منظومة المزامنة

| البند | المواصفة |
|---|---|
| **الاتجاه** | ثنائي: تسليم تغييرات + استقبال تعارضات |
| **ما يُسلَّم** | تغييرات الهوية (نطاق التثبيت) + تغييرات علاقة الموكل (نطاق القاعدة) |
| **ما لا يُسلَّم** | لا شيء من بيانات الملفات أو المالية عبر هذا العقد؛ لها عقودها |
| **العمل دون اتصال** | كل العمليات المحلية المدعومة تستمر (ADQ-18) |
| **التعارض** | حسب الصنف (ADQ-16): الأشخاص → حفظ ومراجعة بشرية |
| **الانقطاع الطويل** | لا إتلاف للعمل المحلي؛ تنبيه تباعد (ADQ-17) |
| **الإعادة** | إعادة المحاولة لا تكرر الأثر (ADQ-19) |
| **الذرّية** | عملية واحدة = وحدة واحدة (ADQ-19) |
| **التوقيت** | توقيت تعديل منفصل عن توقيت مزامنة (ADQ-15) |

## 11. C10 — وحدة القواعد

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة: القواعد المتاحة، القاعدة النشطة |
| **تعدد القواعد** | عدة قواعد في الجلسة الواحدة (ADQ-04) |
| **التبديل** | لا يُفقد عملية جارية ولا يُحفظ جزئيًا (ADQ-04) |
| **في البحث** | البحث الشامل يعرض اسم القاعدة لكل نتيجة (ADQ-41) |
| **في البطاقة** | اسم القاعدة إلزامي عند عرض موكل من قاعدة واحدة |
| **عند الانتقال** | يُحفظ سياق البحث والنتائج؛ ويُعاد البحث في القاعدة الجديدة |

## 12. C11 — النسخ الاحتياطي والاستعادة

| البند | المواصفة |
|---|---|
| **نطاق النسخة** | بيانات القاعدة + سجل الأشخاص المشترك (REQ-019، A-47) |
| **الاعتماديات** | علاقة الموكل توجد في نسختين (تثبيت + قاعدة) → يجب أن تُنسخ **متسقة** |
| **الاستعادة** | استعادة سجلات محددة متى أمكن ضمان سلامة علاقاتها (ADQ-29)؛ **لا استعادة جزئية تكسر العلاقات** |
| **عدم محو الأحدث** | نسخة قديمة لا تمحو تغييرات أحدث؛ تُحفظ التغييرات اللاحقة للمصالحة (ADQ-28) |
| **التشفير** | البيانات الحساسة والنسخ والمرفقات مشفرة (ADQ-24) |

## 13. C12 — الاستيراد المنضبط (ADQ-45)

| البند | المواصفة |
|---|---|
| **المرحلة** | استيراد منظبط مطلوب في الإصدار الأول |
| **المتطلبات** | معاينة، مطابقة حقول، تحقق، كشف مكررات، تقرير أخطاء، تراجع عن الدفعة |
| **العلاقة مع الموكلين** | الاستيراد **يكشف** مكررات (يرسلها لمسار مراجعة التكرار) ولا يدمج |
| **الدمج** | «لا تُدمج البيانات دون مراجعة» (ADQ-45) |
| **التراجع** | تراجع عن الدفعة كاملة، لا جزئي |
| **الدرجات** | الوحدة تستهلك، ولا تنشئ محرّك استيراد |

## 14. C13 — الحقول المخصصة (ADQ-44)

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة التعريفات + كتابة القيم |
| **النطاق** | بحسب نوع السجل (شخص طبيعي / جهة / علاقة موكل) |
| **القواعد** | أنواع وقواعد تحقق وإتاحة واضحة؛ لا تغيير للحقول الجوهرية |
| **الانضباط** | لا مخطط عشوائي؛ كل حقل قابل للبحث أو النسخ أو الترحيل بأمان |
| **التخصيص** | الحقول المخصصة شيء مختلف عن تخصيص العرض (انظر `CLIENTS_CUSTOMIZATION.md` §3.3) |

## 16. مخاطر التكامل

| # | الخطر | الأثر | الضبط |
|---|---|---|---|
| I-1 | كتابة الهوية تتجاوز نطاق السجل المشترك (مثل: كتابة ملاحظة قاعدة في السجل) | تسرب بين القواعد | التحقق من النطاق في العقد C1 |
| I-2 | الوحدة تكرر منطق البحث | تكرار المنطق | عقد بحث واحد (C7) |

| I-4 | سلة محذوفات منفصلة عن سلة النظام | سجلات محذوفة لا تُستعاد | استخدام سلة النظام (ADQ-31) |
| I-5 | سجل نشاط موازٍ | تدقيق غير موثوق | سجل واحد (ADQ-32) |
| I-6 | إظهار حقول مالية بلا فحص صلاحية | تسرب مالي | الفحص على البيانات (C6) |

## 17. خلاصة

1. **لا توجد عقود قائمة**؛ ما سبق مسودات مبنية على السلوك المعتمد.
2. **الوحدة مالك لعلاقة الموكل فقط**، ومستهلك لما عداها.
3. **الحدود الأهم**: الهوية مشتركة، وعلاقة الموكل وقاعدة، والملاحظات داخل القاعدة.
4. **لا تعارض صامت** في أي عقد.
5. **الصلاحية تُفرض على البيانات**، لا على الواجهة.
6. **لا أنظمة موازية**: بحث وتخصيص ونشاط ومحذوفات، كلها مستهلكة لا مكررة.
