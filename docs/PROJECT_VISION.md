# رؤية المشروع

## الغاية
[معتمد] إنشاء برنامج متكامل لإدارة مكتب محاماة مصري، يربط العمل القانوني والإداري والمالي، مع مراعاة سلامة البيانات وسهولة الوصول إليها والعمل المحلي متعدد الأجهزة.

## المستخدمون المستهدفون
[معتمد – الآلية معلّقة] مستخدمو المكتب، لكل منهم حساب مستقل وصلاحيات مناسبة؛ تفاصيل الأدوار والصلاحيات غير محسومة.

## النطاق العام
[معتمد] النطاق المستهدف يشمل الأشخاص والعملاء، الملفات والقضايا والمسارات والإجراءات، الجلسات والمواعيد والمهام، المستندات، الأعمال القانونية وغير القضائية، الأتعاب والمصروفات والتحصيل، المحاسبة، المستخدمين، البحث والتقارير، مركز العمل اليومي، الإعدادات، التدقيق، النسخ والاستعادة، إدارة القواعد والمزامنة. هذه قائمة نطاق عام وليست تقسيمًا معتمدًا للوحدات.

[معتمد] يستهدف التشغيل على الكمبيوتر والهاتف، مع أولوية Windows وAndroid (REQ-001)، واستيعاب قاعدة واحدة لمئات الآلاف من الملفات وملايين السجلات. لا تُعد القدرة مثبتة قبل اختبارات فعلية.

## خارج هذه المرحلة
[معتمد] هذه المرحلة توثيقية فقط: لا تطبيق أو قاعدة فعلية أو ترحيلات أو إعداد تشغيل أو بيانات اختبار أو اختيار تقني. لا اعتماد لتقسيم الوحدات أو تحديد وظائف الإصدار الأول بالكامل.

## مرجعية المشروع وحدود التثبيت

[معتمد — ADQ-01، ADQ-03، ADQ-06، ADQ-10، ADQ-14، ADQ-24] مكتب واحد لكل تثبيت، مع قواعد مستقلة متعددة. هوية الشخص موحدة داخل التثبيت وأجهزته وقواعده فقط؛ مرجع سجل الأشخاص تحت سيطرة المكتب ونسخ محلية، دون انتقال تلقائي لبيانات الملفات والقضايا والماليات بين القواعد. السيطرة على المرجع والتنسيق والمفاتيح بيد المكتب، ولا يشترط تشغيل النظام مزودًا خارجيًا أو خادمًا سحابيًا. لا اختيار لبنية تقنية.

[معتمد — ADQ-05، ADQ-18، ADQ-20، ADQ-45] المزامنة المحلية وعبر الإنترنت والاستيراد المنضبط من الملفات المنظمة من متطلبات الإصدار الأول؛ العمل المحلي يستمر دون اتصال. النقل الكامل بين القواعد لا يشترط اكتماله قبل الإطلاق الأول، لكن قابليته دون كسر العلاقات قيد منذ البداية.

[معتمد — ADQ-25، ADQ-33] النسخة المحلية لا تعني إتاحة جميع محتوياتها لكل مستخدم؛ الصلاحيات قيد فعلي. لكل ملف حساب مالي مستقل، وإجمالي حساب الموكل داخل القاعدة نفسها فقط.

النبذة في `README.md` مرجع عام تحكمه التعليمات المعتمدة؛ صُحح توقيت المزامنة فيها. شكل التطبيق، بما فيه احتمال PWA، غير معتمد. توجهات الواجهة مثل RTL ليست متطلبات معتمدة لهذه المرحلة، ولا يُستنتج اعتمادها من قرار البحث العربي ADQ-42. أُغلقت الأسئلة المعمارية الـ45 في `DECISIONS.md`؛ التفاصيل المؤجلة في `OPEN_QUESTIONS.md` لا تمنع الانتقال إلى النموذج المفاهيمي بتعليمات لاحقة، ولا تمنح إذنًا تلقائيًا بذلك.
