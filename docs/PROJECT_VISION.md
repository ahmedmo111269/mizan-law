# رؤية المشروع

## الغاية
[معتمد] إنشاء برنامج متكامل لإدارة مكتب محاماة مصري، يربط العمل القانوني والإداري والمالي، مع مراعاة سلامة البيانات وسهولة الوصول إليها والعمل المحلي متعدد الأجهزة.

## المستخدمون المستهدفون
[معتمد – الآلية معلّقة] مستخدمو المكتب، لكل منهم حساب مستقل وصلاحيات مناسبة؛ تفاصيل الأدوار والصلاحيات غير محسومة.

## النطاق العام
[معتمد] النطاق المستهدف يشمل الأشخاص والعملاء، الملفات والقضايا والمسارات والإجراءات، الجلسات والمواعيد والمهام، المستندات، الأعمال القانونية وغير القضائية، الأتعاب والمصروفات والتحصيل، المحاسبة، المستخدمين، البحث والتقارير، مركز العمل اليومي، الإعدادات، التدقيق، النسخ والاستعادة، إدارة القواعد والمزامنة. هذه قائمة نطاق عام وليست تقسيمًا معتمدًا للوحدات.

[معتمد] يستهدف التشغيل على الكمبيوتر والهاتف، مع أولوية Windows وAndroid، واستيعاب قاعدة واحدة لمئات الآلاف من الملفات وملايين السجلات. لا تُعد القدرة مثبتة قبل اختبارات فعلية.

## خارج هذه المرحلة
[معتمد] هذه المرحلة توثيقية فقط: لا تطبيق أو قاعدة فعلية أو ترحيلات أو إعداد تشغيل أو بيانات اختبار أو اختيار تقني. لا اعتماد لتقسيم الوحدات أو تحديد وظائف الإصدار الأول بالكامل.

## مرجعية المشروع والتعارض
عُثر على نبذة تعريفية سابقة في `README.md` واعتمدت مرجعًا ثانيًا ضمن حدوده. تتفق في استقلال المشروع، عدم اعتماد التقنية، والترابط العام. تعارضها التعليمات الحالية في أن النبذة تطرح المزامنة كتطوير مستقبلي، بينما المزامنة مطلوبة من الإصدار الأول؛ كما تطرح PWA كاحتمال فقط ولا تحسم شكل التطبيق. كذلك توسع بعض التوجهات العامة (مثل RTL) غير وارد ضمن المتطلبات المعتمدة هنا، ولذلك لا يُعامل كمتطلب معتمد. تفاصيل التعارض والأسئلة في `OPEN_QUESTIONS.md`.
