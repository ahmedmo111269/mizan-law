## 1. مبادئ التفاعل

| # | المبدأ | التطبيق |
|---|---|---|
| U1 | أقل خطوات للعمل | كل عمل مستحق: من الصفحة إلى التنفيذ أو السجل في نقرة/لمسة |

| U3 | لا فقدان سياق | العودة تُبقي الموضع والمرشحات ونص البحث |
| U4 | لا فعل مكرر | تعطيل الإجراء أثناء تنفيذه + ذرية ADQ-19 |
| U5 | الأخطاء مفهومة | نص يقول ما حدث وماذا تفعل، لا رمز تقني |

| U9 | الواجهة لا تكذب | «لا يوجد» / «لا تملك صلاحية» / «غير متاح الآن» ثلاث رسائل مختلفة |

## 2. تشريح صف العمل

### 2.1 العناصر

```
┌────────────────────────────────────────────────────────────────────┐
│ [أيقونة النوع] [نوع: جلسة]  العنوان الرئيسي                        │
│ شارة سبب الظهور: متأخرة منذ يومين · الموعد المسجَّل: 2026-10-16    │
│ السياق: ملف: «…» › قضية: «…» · الحالة: … · المسؤول: …              │
│ [الإجراء الأساسي] [⋯ إجراءات]                     [فتح السجل ←]    │
└────────────────────────────────────────────────────────────────────┘
```

| العنصر | القاعدة |
|---|---|
| أيقونة النوع + نصه | إلزاميان معًا (U6)؛ لا لون وحده |
| العنوان | كما هو في السجل الأصلي، مختصرًا بذكاء دون تغيير معناه |
| شارة «سبب الظهور» | إلزامية لكل صف (P2)؛ صيغة بيانية: متأخرة منذ كذا / مستحقة اليوم / جلسة مسجَّلة كذا |
| السياق | روابط للملف/القضية/الموكل حسب توفّرها وصلاحيتها؛ كل رابط يفتح السجل |
| الحالة | حرفية من السجل؛ لا تُشتق الصفحة حالات جديدة |
| المسؤول | يظهر إن كان مدعومًا في المصدر (`HD-11`) |
| الإجراء الأساسي | زر واحد فقط لكل صف = الإجراء التالي الأرجح؛ البقية في قائمة «⋯» |
| فتح السجل | دائم الحضور، ويبقى مسارًا آمنًا حتى تعطّل الإجراءات |

### 2.2 تفاعل الصف

| الحالة | السلوك |
|---|---|
| لوحة المفاتيح | Tab يعبر الصف مرة واحدة (مجموعة منطقية)، السهم يفتح الإجراءات |
| الماوس | تمرير يبرز حدود الصف فقط (لا مبالغة) |
| اللمس | لمسة على الجسد = فتح السجل؛ الإجراءات أهداف منفصلة كبيرة |
| التحديد | تحديد الصف لا يفتح شيئًا (يمنع الفتح العرضي) |

## 3. مركز الإجراءات اليومية

### 3.1 مصفوفة الإجراءات

| الإجراء | الهدف (الوحدة المالكة) | الحالة الحالية | السلوك عند غياب الوحدة |
|---|---|---|---|
| فتح الملف | وحدة الملفات | `[غير منفذ]` | الإجراء محجوب لا معطَّل |
| فتح الجلسة / تسجيل نتيجة جلسة | وحدة الجلسات | `[غير منفذ]` | محجوب |
| فتح مهمة / تحديث حالة | وحدة المهام | `[غير منفذ]` | محجوب |
| تحديث حالة متابعة | وحدة الإجراءات/المتابعات | `[غير منفذ]` | محجوب |
| فتح بيانات موكل | وحدة الموكلين (حزمة مقترحة) | `[مصمَّم]` | محجوب حتى اعتماد التنفيذ |
| موكل جديد | مسار الإنشاء في وحدة الموكلين | `[مصمَّم]` | محجوب |
| ملف قانوني جديد | وحدة الملفات | `[غير منفذ]` | محجوب |
| تسجيل نتيجة إجراء | الوحدة المالكة | `[غير منفذ]` | محجوب |
| استكمال عمل غير منتهٍ | «استئناف» (H3) + الوحدة المالكة | `[مصمَّم]` | جزء الاستئناف يعمل؛ الفتح يتبع مصدره |
| البحث الشامل | منظومة البحث | `[مصمَّم]` | شريط السياق؛ إن غابت المنظومة تُعرض حالة «البحث غير متاح» صريحة |

### 3.2 قواعد عامة للإجراءات

1. **التحويل لا التقليد:** الصفحة لا تفتح نموذج إنشاء خاصًا بها أبدًا.
2. **النتيجة تعود للصف:** بعد إجراء (مثل تسجيل نتيجة) يتحدث صف العمل في مكانه دون إعادة تحميل الصفحة (U10).
3. **الفشل لا يُعمَّم:** فشل إجراء لا يعطّل الصفحة؛ رسالة سطرية عند الصف + إمكان إعادة المحاولة.
4. **الذرية:** إجراء واحد = وحدة متكاملة (ADQ-19)؛ لا «حُفظ جزئيًا».

## 4. تجربة البحث والوصول السريع

| البند | المواصفة |
|---|---|
| المدخل | حقل «بحث…» في شريط السياق، متاح في كل أحوال الصفحة وفي كل المقاسات |
| النطاقات | تستهلك نطاقات البحث العامة: القاعدة النشطة (S1)، سجل الأشخاص (S2)، الشامل عبر القواعد (S3) — كما في عقد البحث العام المقترح (`CLIENTS_SEARCH_AND_FILTERS.md`) معمَّمًا لأنواع السجلات |
| تصنيف النتائج | حسب النوع: أشخاص، ملفات، قضايا/مسارات، جلسات، مواعيد، مهام، إجراءات، مستندات — حسب توفّر المصدر |
| اسم القاعدة | **إلزامي في نتائج S3** (ADQ-41)؛ ويُعرض في كل نتيجة من قاعدة غير نشطة |
| العربية | تطبيع معتدل وفق ADQ-42 يُطبَّقه محرك البحث العام؛ الصفحة لا تطبّع بنفسها |
| الفتح | النقرة تفتح السجل مباشرة في وحدته |
| حفظ السياق | نص البحث والنتائج محفوظان عند الانتقال والعودة (P14) |
| الانقطاع | لافتة: «النتائج من النسخ المحلية وقد لا تشمل تغييرات غير متزامنة» (ADQ-41) |
| الخصوصية | لا تظهر نتائج لسجلات بلا صلاحية أصلًا (ADQ-25)؛ ولا تُدمج نتائج متشابهة (ADQ-12 روحًا) |
| الأداء | تحميل مجزأ للنتائج؛ لا تحميل كل السجلات (REQ-013/014) |
| الحالات | فارغ، خطأ، جارٍ البحث، انقطاع، محرك غير متاح — كلها موصوفة في `HOME_STATES_AND_ERRORS.md` §4 |

## 5. الجلسات والمواعيد والاستعداد — وحدة «جاهزية الجلسات»

### 5.1 محتوى بطاقة الجلسة القادمة

| الحقل | المصدر | الشرط |
|---|---|---|
| موعد الجلسة (تاريخ ووقت مسجلان) | سجل الجلسة | إلزامي |
| المحكمة/الجهة | سجل الجلسة | إن وُجد |
| القضية/المسار | العلاقة المسجلة | إن وُجدت |
| الملف المرتبط | العلاقة المسجلة | إن وُجد |
| الأطراف ذات الصلة | أسماء الأشخاص المرتبطين | وفق الصلاحيات فقط (ADQ-25) |
| آخر نتيجة/إجراء | آخر سجل مرتبط محدَّث | إن وُجد |
| ملاحظات الاستعداد | حقل مخصص لذلك إن وُجد في المصدر | إن وُجد |
| الأعمال المطلوبة قبل الجلسة | المهام/الإجراءات المرتبطة بالجلسة أو بالملف بمواعيد ≤ موعد الجلسة | **بيانات مسجَّلة فقط** |
| مؤشر الجاهزية | نسبة الأعمال المسجَّلة المنجزة من المرتبطة (مثلاً «2 من 3») | مشتق شفاف لا تقييم ذكي |
| الرابط المباشر | فتح سجل الجلسة | دائم |

### 5.2 ضوابط صريحة

1. **لا خلط بين التواريخ:** موعد الجلسة ≠ تاريخ تسجيلها ≠ آخر تعديل ≠ موعد مهمة. كل تاريخ يُسمى بما هو.
2. **لا حساب مواعيد إجرائية** (P8): لا ميعاد استئناف ولا ميعاد شكوى محسوب؛ ما يُعرض فمسجَّل.
3. **تنبيهات الاستعداد** (مثل «جلسة خلال يومين بلا أعمال تحضير مسجلة») `[مقترح — HD-12]`: قاعدتها **غياب بيانات مسجَّلة**، لا استنتاج قانوني؛ وصياغتها إخبارية لا تحذيرية مقلقة.
4. الجلسة تبقى في المجرى بصفها عملًا مستحقًا؛ والوحدة تعرض **الجاهزية** لا نسخة من صف المجرى (P3).

## 8. تقرير اليوم — وحدة «حصيلة اليوم»

| البند | المواصفة |
|---|---|
| البنود المقترحة | أُنجز اليوم · بقي ومستحق · متأخر · نتائج جلسات سُجِّلت اليوم · إجراءات تحتاج متابعة · تنتظر قرارًا |
| الشكل | قائمة بنود؛ كل بند: وصف + عدد + أحدث العناصر (3) + «الكل» |
| الانتقال | كل عنصر يفتح سجله الأصلي (J10)؛ لا أرقام صماء |
| المصادر | استعلامات جاهزة من الوحدات المالكة (H4)؛ الصفحة لا تجمع بنفسها من جداول |
| الحدود | ليست نظام تقارير؛ لا تصدير ولا تدقيق فيها `[خارج نطاق الصفحة]`؛ التقارير الرسمية لمنظومة التقارير المستقلة |
| مطابقة الواقع | «أُنجز اليوم» = ما اكتمل/سُجِّلت نتيجته اليوم بتوقيت مرجعي (ADQ-15) لا بتخمين |

## 9. تدفقات شاشة رئيسية

### 9.1 صباح اليوم (J1)

1. فتح البرنامج ← «مكتب اليوم» (تحميل أول: هياكل + تحديث تدريجي للمناطق).
2. شريط «الآن»: الجلسات وما تجاوز الحد من المتأخر.
3. مسح المجرى؛ لمس أول صف ← تنفيذ أو فتح السجل.
4. العودة بالسياق إلى الموضع نفسه.

### 9.2 تسجيل نتيجة جلسة (J9)

1. صف الجلسة ← «تسجيل نتيجة».
2. تحويل لنموذج النتيجة في وحدة الجلسات `[غير منفذ]`.
3. الحفظ بوحدة واحدة (ADQ-19) + تسجيل الحدث (ADQ-32 عبر العقد).
4. العودة: صف الجلسة محدَّث (النتيجة ظاهرة) + بند في حصيلة اليوم.

### 9.3 تسجيل موكل جديد (J4)

1. «إجراء جديد» ← «موكل جديد».
2. تحويل لإضافة سريعة في وحدة الموكلين.
3. بعد الحفظ: إشعار نجاح + اختيار «العودة لمكتب اليوم» (يُبقي الموضع) أو البقاء في البطاقة.
