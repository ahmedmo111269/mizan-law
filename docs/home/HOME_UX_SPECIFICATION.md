# مواصفات التفاعل وتجربة الاستخدام

> **تصميم مقترح، لا مسارات منفذة.** جميع الإجراءات مشروطة بقدرات الوحدة المالكة وصلاحيات المستخدم وتوفر البيانات محليًا. البنية والأولوية في [HOME_INFORMATION_ARCHITECTURE.md](HOME_INFORMATION_ARCHITECTURE.md) هي المرجع، ولا تُعاد قواعد الأعمال هنا.

## 1. تسلسل الدخول والاستجابة

1. يتحقق الغلاف العام من المستخدم المعتمد والسياق المحلي وصلاحياته؛ لا تُرسم بيانات حساسة من جلسة سابقة قبل ذلك.
2. يظهر H-01 باسم القاعدة الصحيح، ثم الأدوات المتاحة. لا انتظار لكل المصادر حتى يعمل البحث أو التنقل المستقلان.
3. تُطلب معاينات H-05 المحدودة مع معلومات التغطية؛ كل مجموعة تملك تحميلًا وخطأً مستقلين.
4. مصدر غير مسجل/غير منفذ لا يحصل على زر أو رقم صفر. مصدر متاح فشل تحميله يحصل على رسالة قابلة لإعادة المحاولة.
5. يظهر H-07/H-08 فقط إن وفّر مالكهما بيانات وقدرة حقيقية. لا تُملأ مساحتهما بعينات.

إذا لم يتوفر أي مصدر عمل بعد ربط الغلاف مستقبلًا: «عرض الأعمال اليومية غير متاح في هذه النسخة» مع الأدوات المنفذة فقط؛ هذا **ليس** يومًا هادئًا ولا نسخة إطلاق مكتملة.

## 2. سلوك الصف والمعاينة

| المدخل | الأثر المقترح | الرجوع |
|---|---|---|
| عنوان العمل | فتح السجل الأصلي مباشرة بخطوة واحدة | إلى نفس القاعدة والعدسة والمرشح ومرجع الصف |
| «تفاصيل» | اختيار العنصر وعرض معاينة مالكه؛ عمود سياق أو مساحة كاملة حسب العرض؛ تفعيل المستخدم ينقل التركيز إلى عنوانها | إغلاق المعاينة يعيد التركيز إلى زرها |
| الإجراء السياقي الظاهر | فتح إجراء المالك بالمرجع والحالة، لا تعديل مباشر من الصفحة | نتيجة المالك تحدث الجزء المتأثر فقط |
| «إجراءات {نوع السجل}» | قائمة مسماة بالأفعال المسموح بها فقط | إغلاقها يبقي الصف دون تغيير |
| عنوان مجموعة / «عرض الكل» | قائمة العمل نفسها بمرشح المجموعة، بدفعات محدودة | زر «ملخص العمل» يعيد موضع المعاينة السابقة |
| مساحة فارغة في الصف | لا أثر مفاجئ ولا زر يغلف أزرارًا أخرى | تمنع أخطاء اللمس والتداخل |

المعاينة للقراءة والسياق، وليست نموذج تحرير جديدًا. لا يتطلب فتح السجل وجود معاينة؛ يمكن تأجيلها دون تعطيل العمل. على الكمبيوتر لا يتغير محتواها بمجرد مرور المؤشر. وصول تحديث جديد لبيانات العنصر لا يسحب التركيز تلقائيًا من القائمة؛ انتقاله إلى المعاينة يكون بتفعيل «تفاصيل» صراحة، لا لمجرد تحديث أو تحديد بصري.

### محتوى معاينة الجلسة

رأس الجلسة وتاريخها الفعلي والمحكمة، ثم القضية/المسار وروابط الملفات المتعددة إن وجدت، ثم آخر نتيجة مسجلة مع تاريخها، ثم الاستعداد المسجّل وروابط مهامه. لا تعبير «جاهز للجلسة» من نسبة اكتمال مستندات غير معتمدة. لا إنشاء مهمة عند فتح المعاينة، ولا احتساب مهلة طعن أو إعلان.

إن كان للعمل عدة ملفات، يعرض «الملفات المرتبطة المتاحة» وخياراتها؛ لا يعلن عدد ملفات محجوبة. إذا كان الارتباط غير موجود فعليًا، يقال ذلك؛ إذا تعذر عرضه لأسباب وصول، تستخدم رسالة عامة لا تفضح علاقة خفية.

## 3. سجل الإجراءات اليومية المقترح

| الإجراء | موضعه | المالك / شرط الإتاحة | نتيجة النجاح الصحيحة |
|---|---|---|---|
| فتح الملف | الصف إن كان رابط واحدًا، وإلا قائمة العلاقات | وحدة الملفات، قراءة السجل والقاعدة | ملف صحيح، لا قضية مفترضة |
| فتح الجلسة | عنوان الصف | وحدة الجلسات/المسار المسؤول | السجل نفسه لا جلسة مشابهة |
| تسجيل نتيجة جلسة | الإجراء التالي إن أجازه المصدر | نموذج الجلسات الأصلي، صلاحية الحالة والكتابة | تأكيد حفظ النتيجة؛ لا إتمام مفترض للعمل |
| فتح مهمة | عنوان صف المهمة | مالك المهام | تفاصيلها وحالتها الأصلية |
| تحديث متابعة | الإجراء التالي | مالك الإجراء/المتابعة وصلاحية الانتقال | الحالة التي أعادها المالك، لا حالة منزلية |
| إجراء إداري | عنوانه أو فعله التالي | مالك الإجراء، صلاحية محددة لاحقًا | نجاح/فشل/تعليق موثق من المالك |
| فتح موكل أو شخص | بحث/رابط معاينة | الموكلون أو سجل الأشخاص بحسب نوع المرجع | لا تحويل الشخص إلى موكل ضمنيًا |
| موكل جديد | «جديد ← موكل» | مسار الموكلين بعد اعتماد CD اللازمة | تأكيد كامل للهوية والعلاقة بحسب تصميم المالك |
| ملف قانوني جديد | «جديد ← ملف قانوني» | مسار الملفات، قاعدة قابلة للكتابة | ملف كامل؛ لا ربط بقاعدة أخرى صامتًا |
| مهمة/موعد جديد | «جديد» بعد توفر الوحدة | ليس ضمن القائمة قبل تنفيذ المصدر واعتماد حقوله | فتح مسار المالك |
| مراجعة تعارض | H-09 أو إشارة السجل | خدمة المزامنة/المراجعة العامة، صلاحية المراجعة | لا حسم ولا دمج داخل الرئيسية |
| مزامنة يدوية | تفاصيل H-09 | خدمة المزامنة العامة إذا كانت تتيح الأمر | بدء/رفض/فشل بحسب الحقيقة، لا نجاح لمجرد الضغط |

لا حذف جماعي، أو تحرير تاريخ، أو توزيع مهام، أو تصدير من الرئيسية في النطاق الأساسي. يمكن فتح وحداتها عبر التنقل العام عند توفرها، لا إعادة إنشائها.

### قاعدة ظهور الأفعال

- **غير منفذ أو غير معتمد أو غير مصرح به:** لا يظهر كأمر متاح؛ لا لافتات «قريبًا» في الصفحة التشغيلية.
- **منفذ ومصرح به لكنه متعذر مؤقتًا:** يشرح السبب عند السياق الذي يحتاجه المستخدم، مع بديل مأمون إن وجد. مثال: الكتابة متوقفة لتوافق الإصدار، والقراءة متاحة.
- **ظهر متاحًا ثم تغيّرت حالته:** يفحص المالك مجددًا، ويعيد خطأً مفهومًا؛ لا يكفي فحص الواجهة القديم.
- تعطيل زر أثناء إرسال العملية يمنع النقر المكرر بصريًا، لكن منع تكرار الأثر والذرية مسؤولية المالك وفق ADQ-19.

## 4. البحث العام

### 4.1 نقطة الدخول والنطاق

- الكمبيوتر: حقل بحث واضح في الغلاف، مع اختصار عام مقترح `Ctrl+K` إن لم يتعارض مع المنصة. الهاتف: «بحث» في شريط الأدوات السفلي يفتح مساحة بحث كاملة، لا حقلًا ضيقًا دائمًا.
- عند بدء بحث جديد: **«في القاعدة النشطة: {اسمها}»**. عند العودة من نتيجة: يستعاد النطاق السابق ظاهرًا، لا يبدل خفية.
- خياران إضافيان عند دعمهما: **«كل القواعد المحلية المتاحة»** و**«سجل الأشخاص المشترك»**. الأخير ليس كل الأشخاص بلا قيود؛ يطبق صلاحيات السجل.
- حتى مع الإنترنت لا يُعلن بحث بعيد في قواعد غير محلية؛ ADQ-41 يحكم النطاق. يمكن عرض قاعدة مصرح بها غير محلية في مبدل القواعد، لا اختلاق نتائج منها.

### 4.2 النتائج

| العنصر | المعروض المطلوب |
|---|---|
| عنوان مجموعة النتائج | النوع: شخص، موكل، ملف، قضية/مسار، جلسة، موعد، مهمة، إجراء… بحسب المصادر المنفذة فقط |
| صف نتيجة | النص الأصلي، النوع، مرجع عرض يميزه، سبب المطابقة إن أتاحه المحرك، الوجهة |
| المصدر | اسم القاعدة **لكل نتيجة ذات قاعدة**؛ الشخص المشترك يحمل «سجل الأشخاص المشترك» بدل اسم قاعدة مصطنع |
| تمييز القضية | الرقم/السنة/نوع القيد/الجهة المتاحة من المصدر؛ الحقول الغائبة لا تُخمن |
| التغطية | ما تم البحث فيه، وما تعذر من النطاق المصرح به، وحدود التغييرات غير المتزامنة |
| النتائج الكثيرة | دفعات مقترحة حتى 20 نتيجة إجمالًا، تصنيف واضح ومرشح نوع و«المزيد»؛ لا تحميل كل نوع بالكامل |

النتيجتان المتشابهتان تظلان مستقلتين. وجود الشخص نفسه في نتائج الهوية وفي علاقة موكل لا يدمج النوعين؛ يوضح الفرق. لا عرض آلي لمعرّف رسمي أو رقم هاتف كامل في اقتراحات عامة إذا لم يلزم، والتفاصيل الحساسة تبقى محكومة بمصدرها وصلاحيتها.

### 4.3 سلوك الإدخال والاستجابات

- نص فارغ: تعليمات قصيرة «ابحث بالاسم أو المرجع المتاح»؛ لا استعلام يعيد كل السجلات، ولا سجل بحث محفوظ افتراضيًا.
- البحث العام يملك التطبيع العربي المعتدل ADQ-42، وترتيب المطابقة والأخطاء وحدود النص. لا تطبيع محلي ثانٍ في الرئيسية ولا تصحيح أسماء تلقائي.
- عند طلب جديد تُلغى/تُهمل استجابة القديم منطقيًا. لا نتيجة من قاعدة أو نطاق سابق يُسمح بفتحها كأنها حالية.
- أي تأخير لتجميع الكتابة ملك السياسة العامة القابلة للقياس؛ المقترح 250ms بعد توقف الإدخال، مع تنفيذ صريح عند طلب المستخدم. لا تأخير اصطناعي لنتيجة جاهزة ولا بحث خلال تركيب النص بلوحة الإدخال.
- `Enter` يفتح نتيجة اختارها المستخدم بوضوح؛ إن لم يختر، ينفذ/يثبت البحث ولا يقفز إلى أول شخص متشابه. الأسهم تتحرك داخل النتائج، و`Esc` يغلق المساحة ويعيد التركيز.
- الاستعلام يبقى في ذاكرة الجلسة اللازمة للعودة، ولا يُنسخ افتراضيًا إلى سجل نشاط أو رابط أو تفضيل دائم. أسماء السجلات والمعرفات قد تكون حساسة.
- حالة «لا نتائج» لا تثبت أن الشخص غير موجود؛ «موكل جديد» إن أتيح يقود إلى تحقق الوحدة الأصلي لا إنشاء من نص البحث بلا مراجعة.

حالات الفراغ والفشل الجزئي والرفض في HST-05/06/12، وعقد الاستهلاك في HC-07؛ المسودة المرجعية [بحث الموكلين §8](../clients/CLIENTS_SEARCH_AND_FILTERS.md) لا تُستبدل بمحرك خاص.

## 5. إنشاء جديد وحارس الانتقال

قائمة «جديد» قصيرة مرتبة بحسب المسارات المتاحة: موكل، ملف قانوني، ثم الأنواع الأخرى عند تنفيذها. لا زر فرعي لنموذج مكرر، ولا تفضيل تلقائي لنوع حسب لقب المستخدم. اختيار الفعل يمرر القاعدة ومرجع العودة، ولا يكتب السجل.

عند محاولة تغيير القاعدة وفي المالك عملية مؤثرة غير مكتملة:

1. يعيد نظام التنقل العام التحكم إلى المالك برسالة: **«لديك عملية لم تكتمل. أكملها أو ألغها بأمان قبل تغيير القاعدة.»**
2. الخيارات: «العودة للعملية»، «إلغاؤها بأمان» إن أجازه المالك، و«البقاء في القاعدة». لا «احفظ جزئيًا وتابع».
3. «إكمال وحفظ» يتم داخل المالك ويحتاج تأكيد نجاح كامل قبل التبديل.
4. لا يُقترح «حفظ مسودة» إلا إذا اعتمدت الوحدة هذا السلوك ونفذته؛ اقتراح الموكلين ليس ضمانًا عامًا.
5. بعد قبول التبديل تُسحب بيانات السياق القديم من العرض، وتُهمل طلباته المتأخرة، ثم تُحمّل الجديدة. فشل الجديدة لا يعيد بيانات القديمة تحت اسم جديد.

فتح نتيجة بحث من قاعدة أخرى يستخدم الحارس نفسه. عند عدم وجود عملية مؤثرة لا نضيف تأكيدًا روتينيًا لكل فتح، لكن المصدر ظاهر قبل الاختيار وبعده.

## 6. عقد العودة والسياق المرئي

معلومات الجلسة الضرورية: القاعدة، العدسة، مرشحات العرض، معرف آخر عنصر ظاهر/مختار، مرجع الدفعة، النص البحثي في الذاكرة فقط، وموضع التمرير إن كان صالحًا. لا تُحفظ نسخة من البطاقة.

عند العودة: يعاد فحص الوصول والوجود، ثم يعاد العنصر إن بقي في النتائج. إن اكتمل أو حُذف من النطاق، تظهر رسالة «تغيّر هذا العمل؛ حُدثت القائمة» ويعود التركيز إلى أقرب عنوان مجموعة صالح، لا إلى زر كان لسجل آخر. يحتفظ كل سياق قاعدة بمرجع عودة منفصل، ولا توضع بيانات من قاعدتين في استجابة مختلطة.

## 7. استئناف العمل السابق

**الحد الأدنى المقترح HC-11:** حتى ثلاثة مراجع من **الجلسة الحالية** يوفرها نظام التنقل، دون تخزين عناوين أو محتوى أو كل النقرات. يمكن حذف الاختصار دون مساس بالسجل. القائمة لا تستخرج من سجل التدقيق بغرض تتبع كل ما فتحه المستخدم.

| الحالة | السلوك |
|---|---|
| المرجع صالح ومتاح محليًا | جلب عنوانه بعد فحص الصلاحية، وإظهاره مع قاعدته ونوعه |
| تغيّرت الصلاحية/حُذف | لا عنوان قديم؛ رسالة عامة عند محاولة فتح مرجع سبق عرضه، ثم إزالة الاختصار من العرض |
| سجل نُقل/دُمج | تتبع إحالة المالك مع إعادة الفحص؛ لا نقل سياق العلاقة أو القاعدة تلقائيًا بلا بيان |
| قاعدة مصرح بها غير محلية | «هذه القاعدة غير متاحة على الجهاز»؛ لا تخزين محتوى لإيهام الاستئناف |
| نموذج غير مكتمل | يظهر فقط إذا أعاد المالك مرجع مسودة مدعومًا بعد اعتماد HD-12؛ لا يصنع النظام مسودة بديلة |
| لا مراجع | يختفي القسم بهدوء؛ لا محتوى تجريبي |

الاستئناف بعد إغلاق التطبيق خيار لاحق يحتاج سياسة احتفاظ وحماية ومسح عند تبديل المستخدم، ضمن نظام عام. لا يوجد افتراض حفظ دائم افتراضي أو مزامنة نشاط التصفح.

## 8. مراجعة اليوم دون نظام تقارير موازٍ

H-08 يفتح وجهة منظومة التقارير/العروض العامة عند تنفيذ HC-12. الترتيب المقترح للمراجعة:

1. رأس يوضح اليوم والقاعدة ونطاق الشخص والتغطية وحداثة البيانات.
2. **ما أُنجز:** قائمة سجلات لها أحداث إتمام معروفة، بكل بند نوعه ووقته ورابطه.
3. **نتائج مسجلة:** نتائج جلسات/إجراءات مستقلة عن عدد الإتمام؛ النتيجة قد تستدعي متابعة، ولا تعني إغلاق الملف.
4. **ما بقي:** مستحق اليوم والمتأخر والانتظار، بهويات لا تتكرر بين مجموعاتها.

الإنجاز يوم الحدث المسجّل، لا يوم وصول المزامنة. إذا كان الحدث مرتبطًا بتاريخ عمل مختلف عن تاريخ إدخاله، يوضح التقرير الدلالتين وفق مالكه؛ لا تحسم الصفحة قواعد محاسبية أو قانونية. سجل أُعيد فتحه يظهر «أُنجز ثم أُعيد فتحه» إن دعم المصدر التاريخ، ولا يُحسب مستقرًا كمنجز فقط. السجل صاحب أحداث عدة يظهر بندًا واحدًا مع إمكانية فتح أحداثه، وليس عدة أعمال ناجحة.

**إذا لم تُنفذ التقارير العامة:** لا رابط «تقرير اليوم» ميت ولا تقرير مؤقت خاص. يمكن التنقل إلى قائمة «المنجز» في وحدة أصلية إذا كانت تدعمها فعلًا، بتسميتها ونطاقها الصحيحين، دون الادعاء بأنها حصيلة كاملة للمكتب.

## 9. تغير البيانات أثناء الاستخدام

- بعد فعل المستخدم الناجح: تحديث العنصر ومجموعته والتغطية المرتبطة فقط؛ لا إعادة تحميل الصفحة كاملة.
- تحديث خارجي عادي: مؤشر «توجد تحديثات للأعمال — تحديث العرض»؛ لا قفز للصفوف تحت الإصبع أو أثناء قراءة تفصيل. عند التحديث يستعاد المرجع المنطقي إن بقي صالحًا.
- سحب صلاحية/إبطال جهاز/منع أمني: استجابة فورية عند وصول الإشارة؛ إزالة المحتوى المحظور من العرض والمعاينة والاقتراحات، ولو كان المستخدم يقرأه. لا يؤجل ذلك حتى يضغط «تحديث».
- تعارض مؤثر أو إلغاء السجل: لا يُنفذ فعل قديم؛ يعاد التحقق من الحالة عند أي إجراء.
- عبور منتصف الليل أو تغيير المنطقة: لا إعادة تصنيف صامتة وسط فعل جارٍ؛ إشارة تغير اليوم، ثم تحديث آمن بعد العملية. لا تتغير دلالات تاريخ بلا وقت.

## 10. لوحة المفاتيح والوصول والإشعارات

- ترتيب القراءة: سياق ← بحث/بدء عمل ← حالة مؤثرة ← رأس ونطاق ← ملخص المجموعات ← قائمة ← تفاصيل عند الطلب ← استئناف/مراجعة. ترتيب التركيز يطابق الترتيب المنطقي لا توزيع الأعمدة المرئي وحده.
- رابط تخطٍّ إلى الأعمال. جميع الأفعال روابط/أزرار ذات أسماء عربية؛ القائمة ليست جدولًا تفاعليًا معقدًا بلا ضرورة.
- `Tab`/`Shift+Tab` للتنقل، `Enter`/المسافة للتفعيل حسب العنصر، `Esc` للإغلاق الآمن، وسهم الرجوع العام/زر Android يحترم حالة النموذج. لا مفاتيح أحرف منفردة تعمل أثناء الكتابة أو تتعارض مع قارئ الشاشة.
- التركيز محصور داخل الحوار الحقيقي فقط، لا داخل عمود السياق؛ يرجع إلى المُطلِق عند الإغلاق. زر إغلاق واضح، ولا خروج بالسحب وحده.
- تغيّر النتائج يُعلن إعلانًا هادئًا بعد استقرار الطلب، لا قراءة كل صف أو كل تقدم مزامنة. العوائق المهمة ورسائل الحقول مفهومة ومتصلة بسببها.
- رسالة النجاح غير الحرجة يمكن أن تزول، لكن حالة الحفظ تبقى قابلة للتحقق. الخطأ/التعارض لا يعتمد على إشعار مؤقت، والتراجع إن وُجد لا يكون مهلة عابرة وحيدة.
