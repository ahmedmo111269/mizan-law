# التحقق النظري بالسيناريوهات

> **فحص على الورق، لا اختبار تطبيق أو مستخدمين.** الأعداد والظروف التالية سيناريوهات افتراضية طلبها التكليف؛ لم تُنشأ بيانات أو سجلات تجريبية. لا يوجد تطبيق الآن. يُفترض في كل سيناريو مستقبلي أن المصدر المعني نُفّذ واعتمد عقده؛ إن لم يوجد، تسري HST-04 لا واجهة وهمية.

## 1. طريقة المرور

لكل حالة راجعنا ما سيُعرض وترتيبه، فعل المستخدم ومرجع الوجهة، الخطأ المحتمل، الغياب/الصلاحية، ثم النقص الذي يكشفه التصور. الحكم «متسق نظريًا» يعني أن المواصفة تشرح مسارًا معقولًا، ولا يثبت صحة استعلام أو أداء أو سهولة استخدام حقيقية.

المراجع: [البنية والأولوية](HOME_INFORMATION_ARCHITECTURE.md)، [التفاعل](HOME_UX_SPECIFICATION.md)، [العقود](HOME_DATA_CONTRACTS.md)، [الحالات](HOME_STATES_AND_ERRORS.md).

## 2. السيناريوهات الخمسة عشر

### HS-01 — محامٍ لديه خمس جلسات وثلاث مهام متأخرة

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | القاعدة واليوم والنطاق؛ ثلاث مهام في W2 وخمس جلسات في W3 إذا كانت كلها اليوم وحالاتها مؤهلة؛ لا مصدر انتباه مفترض |
| الترتيب | المتأخر بحسب الاستحقاق، والجلسات بحسب أوقاتها المسجلة ثم «وقت غير مسجّل»؛ رؤوس المجموعات ووصول اليوم لا يختفيان |
| الفعل وطريق السجل | عنوان يفتح الأصل، «فتح الملف» إن كانت علاقة واحدة، أو اختيار من علاقات متاحة؛ تسجيل النتيجة عند إتاحته |
| الأخطاء | جلسة أُلغيَت أو مهمة أُنجزت بعد القراءة؛ يعاد التحقق ولا يُستعمل الفعل القديم |
| الغياب/الصلاحية | عدد الجلسات الظاهر هو المسموح فقط؛ غياب الساعة لا يُخمن، وفشل مصدر جلسات يجعل التغطية جزئية |
| النقص والمعالجة | خطر سيادة الجلسات أو تحويل جلسة فات وقتها إلى متأخر؛ عولج بفصل دلالة الحدث عن الاستحقاق وعدم ترجيح النوع |
| الحكم والاعتماد | متسق نظريًا؛ HD-02/04/05 لازمة لدلالات المصدر؛ HJ-01/02/08، HC-02/03/04 |

### HS-02 — موظف إداري لديه عشرون متابعة

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | مرشح نوع المتابعة إن دعم، معاينات المجموعة وروابط القوائم الكاملة؛ عدد 20 فقط إذا عاد معلومًا ومصرحًا |
| الترتيب | مجموعة واحدة لكل عمل وفق استحقاقه/انتظاره؛ لا تجميع حسب الشخص يحول سجلين إلى سجل واحد |
| الفعل وطريق السجل | «عرض الكل» لدفعة حتى 20، ثم فتح/تحديث متابعة في مالكها والعودة إلى موضعها |
| الأخطاء | فشل الدفعة التالية أو انتقال حالة متابعة على جهاز آخر؛ تبقى الدفعة السابقة قابلة للقراءة مع رسالة |
| الغياب/الصلاحية | مسؤول غير مدعوم لا يظهر كحقل فارغ يلزم تعبئته؛ لا بيان «هناك متابعات محجوبة» |
| النقص والمعالجة | البطاقات الكبيرة تجعل المسح بطيئًا؛ صُغرت الوحدة إلى صف بمحتوى ثابت وفعل واحد، مع كثافة مدمجة مأمونة |
| الحكم والاعتماد | متسق نظريًا، ولم تُقَس سرعة المسح أو تنفيذ 20 فعلًا؛ HJ-03، HD-05/16 |

### HS-03 — فتح البرنامج دون اتصال

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | القاعدة المحلية المسموحة والبيانات المتاحة وحدود الحداثة؛ حالة المزامنة من الخدمة لا من انقطاع الإنترنت فقط |
| الترتيب | نفس قواعد العمل المحلية؛ لا إخفاء كل الإجراءات لمجرد الانقطاع |
| الفعل وطريق السجل | بحث محلي وفتح المصدر وفعل محلي مدعوم؛ المزامنة اليدوية من المالك عندما تكون ممكنة |
| الأخطاء | قاعدة بلا نسخة أو مستخدم غير معتمد؛ تختلف رسالتها عن انقطاع مسار المزامنة |
| الغياب/الصلاحية | لا افتراض أن كل القواعد محلية؛ تحديث الصلاحيات البعيد لا يمكن معرفته فورًا دون اتصال |
| النقص والمعالجة | عبارة «غير متصل = لا عمل» خاطئة؛ فُصل توفر البيانات المحلية عن الاتصال وعن الحفظ وعن المزامنة |
| الحكم والاعتماد | مشروط بمحرك محلي وأمان فعليين، لا يثبته الرسم؛ HJ-11، HC-01/09، HST-07/14 |

### HS-04 — مستخدم لديه عدة قواعد بيانات

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | مكتب اليوم لقاعدة نشطة واحدة، ومبدل للقواعد المصرح بمعرفتها؛ البحث الشامل نطاق مستقل معلن |
| الترتيب | الأعمال لا تختلط بين القواعد، ونتائج البحث تحمل المصدر حتى إن تشابه العنوان/الرقم |
| الفعل وطريق السجل | اختيار نتيجة يمرر قاعدتها، ثم حارس العملية عند الحاجة وفتح الأصل؛ العودة تستعيد سياق القاعدة السابقة |
| الأخطاء | رد بحث/عمل قديم بعد التبديل أو حفظ غير مكتمل؛ يهمل الرد القديم ويمنع الانتقال غير الآمن |
| الغياب/الصلاحية | لا نتيجة من قاعدة غير محلية ولا كشف اسم قاعدة محجوبة؛ المتاح غير المحلي يوضح حالته عند محاولة فتحه |
| النقص والمعالجة | حفظ مرجع بلا قاعدة يفتح سجلًا خاطئًا؛ أصبحت القاعدة والنوع جزءًا من المرجع وعقد العودة |
| الحكم والاعتماد | متسق نظريًا؛ HD-03/06/07، HJ-12، HC-01/07/08 |

### HS-05 — مستخدم لا يستطيع الوصول إلى بعض الملفات

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | السجلات والحقول المصرح بها فقط، مع روابط متاحة؛ لا أعداد إجمالية تتضمن المحجوب |
| الترتيب | بعد تطبيق الوصول لا قبله؛ العمل المصرح قد يظهر دون علاقة ملف غير مصرح بها إذا أجاز المصدر ذلك |
| الفعل وطريق السجل | فتح العمل أو رابط مصرح؛ المالك يتحقق ثانية من العملية |
| الأخطاء | رابط سبق ظهوره ثم رُفض؛ رسالة مأمونة لا تؤكد إن كان السجل محذوفًا أو محجوبًا |
| الغياب/الصلاحية | لا جملة «ملف سري واحد» أو اسم محجوب في معاينة أو تحذير؛ غياب الترخيص ليس صفرًا على المكتب كله |
| النقص والمعالجة | التسريب من العدادات والاقتراحات والعلاقات؛ ضُبط في المعلومات المشتركة لكل عقد لا بإخفاء زر فقط |
| الحكم والاعتماد | يتطلب سياسة وصول على مستوى البيانات واختبارات فعلية؛ HD-08، HC-02/05/07، HST-12 |

### HS-06 — يوم هادئ دون مهام

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | حالة خلو قصيرة فقط عند اكتمال التغطية للنطاق؛ بحث/جديد/أقسام متاحة، وربما قادم أو استئناف حقيقي |
| الترتيب | لا صفوف مزعومة ولا رسوم إنجاز أو إجماليات تراكمية لملء المساحة |
| الفعل وطريق السجل | بحث أو بدء إضافة من المالك؛ «القادم» إذا كانت له نتيجة أو قائمة متاحة |
| الأخطاء | جميع المصادر فشلت أو لم تُنفّذ؛ لا يُستعمل نص الخلو نفسه |
| الغياب/الصلاحية | العبارة «ضمن هذا النطاق»؛ لا استنتاج أن المكتب بلا أعمال أو أن المستخدم يرى كل شيء |
| النقص والمعالجة | أخطر خلط هو غياب المصدر بالصفر؛ أضيفت حالات تغطية مستقلة HST-03/04/06 |
| الحكم والاعتماد | متسق نظريًا؛ HJ-01، HC-02، لا دليل على رضا المستخدم عن اليوم الفارغ |

### HS-07 — يوم مزدحم بعشرات الأعمال

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | رؤوس جميع مجموعات الأعمال المتاحة، معاينات محدودة، «كل الأعمال» وروابط المجموعات، مؤشرات التغطية |
| الترتيب | فرز على كامل النتائج قبل الدفعات؛ لا أول عدد من كل البيانات ثم فرز محلي يخفي المتأخر |
| الفعل وطريق السجل | فتح مجموعة، تصفية واضحة، دفعة أخرى، فتح السجل والعودة؛ لا تمرير لا نهائي إلزامي |
| الأخطاء | تغيّر لقطة الدفعات أو فشل مصدر؛ تبطل الاستمرارية القديمة ويشرح التحديث دون مزج لقطات |
| الغياب/الصلاحية | مؤشر «المزيد متاح» عند غياب عدد دقيق، لا حد مزيف للعدد الكلي ولا صفوف محجوبة |
| النقص والمعالجة | حد إجمالي واحد للمعاينة كان يمكن أن يخفي مجموعة كاملة؛ قُسمت الميزانية حسب المجموعة وبقي الوصول الكامل |
| الحكم والاعتماد | منطق التغطية محدد؛ الأداء والحجم غير مثبتين؛ HD-16، HST-15/18 |

### HS-08 — مستخدم يريد تسجيل موكل جديد

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | «جديد ← موكل» فقط عند تنفيذ المسار وإجازته، والقاعدة ظاهرة |
| الترتيب | وصول قصير إلى وحدة الموكلين، لا نموذج إضافي في الرئيسية |
| الفعل وطريق السجل | فتح مسار الإضافة الأصلي والتحقق من شخص قائم/تشابه ثم الحفظ والبطاقة |
| الأخطاء | تطابق موثوق أو فشل جزئي أو ضغط مكرر؛ الوحدة تتحقق وتمنع تكرار الأثر، والرئيسية لا تعرض نجاحًا مبكرًا |
| الغياب/الصلاحية | قبل اعتماد/تنفيذ الموكلين لا يظهر زر يوحي بعملها؛ فقد الكتابة يرفضه المالك ولا يمنحها تخصيص |
| النقص والمعالجة | اختصار الإضافة قد يلتف على الهوية المشتركة؛ أُبقي الاختصار ملاحيًا فقط |
| الحكم والاعتماد | محجوب عن الربط حتى قرارات CD ذات الصلة؛ HD-09، HJ-04، HC-06/08 |

### HS-09 — الوصول إلى قضية بسرعة

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | بحث بنطاق ظاهر ونتائج قضية/مسار مفصولة عن ملف وموكل؛ رقم/سنة/جهة مسجلة تميز النتيجة |
| الترتيب | ترتيب المحرك العام وسبب مطابقة، لا دمج قضايا متشابهة في قاعدتين |
| الفعل وطريق السجل | إدخال نص/مرجع، اختيار النوع عند الحاجة، فتح نتيجة واحدة مباشرة في قاعدتها |
| الأخطاء | لا نتيجة، جزء من نطاق البحث فشل، معرف ناقص، استجابة قديمة؛ لا فتح تلقائي لأول تطابق |
| الغياب/الصلاحية | لا اختلاق بيانات تعريف غائبة أو بحث في قواعد محجوبة؛ تقليل النص المعروض لا يغير الأصل |
| النقص والمعالجة | البحث العام المقترح سابقًا لم يفصل كل المصادر القانونية المطلوبة؛ صيغ طلب توسيع C7 في HC-07، لا محرك ثانٍ |
| الحكم والاعتماد | يحتاج مصدر قضايا ومحركًا عامًا؛ زمن الوصول غير مقاس؛ HD-07/16، HJ-06 |

### HS-10 — العودة إلى سجل تغيرت صلاحياته

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | عند وصول تحديث الوصول يختفي العنوان والتفصيل القديم من العمل والبحث والاستئناف؛ محاولة مرجع قديم تعطي رسالة عامة |
| الترتيب | يعاد حساب النطاق المصرح؛ لا صف محجوب يبقى في مكانه باسم «سري» |
| الفعل وطريق السجل | إعادة التحقق قبل جلب عنوان الاستئناف وقبل فتحه، ثم عودة للمسموح أو إزالة الاختصار |
| الأخطاء | جهاز غير متصل لا يعرف الإلغاء بعد؛ يطبق النظام حدود الاعتماد المحلي وتحديثه عند الاتصال، لا وعد كشف فوري |
| الغياب/الصلاحية | لا محتوى مستعاد من تفضيلات أو لقطات سابقة؛ غياب الوصول مقدم على حفظ موضع القراءة |
| النقص والمعالجة | «آخر ملف» قد يسرب اسمًا حتى دون فتحه؛ HC-11 يحتفظ بمرجع قليل البيانات، والعنوان يجلب بعد الفحص |
| الحكم والاعتماد | ضمان التنفيذ مسؤولية الأمان والتنقل؛ HD-08/12/14، HST-12/19/26 |

### HS-11 — تعديلات محلية لم تُزامن

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | حالة الحفظ المحلي المؤكد، وإشارة انتظار مزامنة مستقلة مع النطاق؛ لا «تمت المزامنة» |
| الترتيب | المصدر المحلي المحدث هو أساس العرض المسموح؛ مهمة أُنجزت محليًا لا تبقى مستحقة لمجرد انتظار الإرسال |
| الفعل وطريق السجل | فتح المصدر للتأكد من النتيجة أو فتح تفاصيل المزامنة العامة وطلبها عند الإتاحة |
| الأخطاء | نتيجة حفظ غير معروفة أو فشل إرسال؛ تُميَّز HST-25 عن HST-10، ولا إعادة إنشاء مكررة |
| الغياب/الصلاحية | لا عدد تغييرات عالمي إذا لم تعرفه الخدمة أو لم يُصرح؛ لا وعد بحفظ إدخال لم يؤكده المالك |
| النقص والمعالجة | خلط حفظ البيانات بنقلها؛ فصلت العقود الإقرار المحلي والانتظار والحسم النهائي |
| الحكم والاعتماد | متسق نظريًا؛ يتطلب اختبارات ذرية وإعادة محاولة ومزامنة؛ HC-08/09، HJ-09/11 |

### HS-12 — تعارض في المزامنة

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | إشارة تعارض حقيقية ونطاقها، وربما شارة للعنصر المتأثر؛ لا تفاصيل محجوبة ولا فوز قيمة تلقائي |
| الترتيب | لا يعاد حساب استحقاق من موعد متعارض غير محسوم؛ إشارة المالك تشرح الحاجة للمراجعة |
| الفعل وطريق السجل | مراجعة التعارض في منظومته للمخول، أو توجيه إلى المسؤول؛ تستمر الأعمال المستقلة |
| الأخطاء | فشل الحسم أو نقص صلاحية، أو تعارض تفضيل مع reset؛ لا يضاف محرك حسم في home |
| الغياب/الصلاحية | من لا يملك الحسم لا يحصل عليه عبر زر، ولا يقرأ القيم المتعارضة بلا تصريح |
| النقص والمعالجة | المسودة السابقة لفوز الأحدث في التفضيلات تخالف ADQ-16؛ HX-01 مسجل، واعتماد مزامنة التفضيلات متوقف على التوحيد |
| الحكم والاعتماد | مسار مقترح صحيح الحد، لكن التعارض الخارجي ما زال حاجزًا؛ HD-10/14، HST-11/24 |

### HS-13 — إخفاء معظم أقسام الصفحة

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | القاعدة والبحث/البدء المتاحان، ملخص مداخل الأعمال، حالة السلامة المؤثرة، وتخصيص/استعادة |
| الترتيب | تفاصيل الكتل المخفية لا تظهر؛ مداخل مجموعات العمل لا تُدفن بسبب الإخفاء؛ حالة المرشح معلنة |
| الفعل وطريق السجل | «كل الأعمال» أو المجموعة يفتح القائمة نفسها؛ «إظهار الأقسام» يعيد التفاصيل؛ إزالة المرشحات توسع العرض صراحة |
| الأخطاء | تفضيل غير صالح بعد تحديث أو فشل الحفظ؛ تخطيط مأمون مؤقت لا محو للتفضيلات |
| الغياب/الصلاحية | إعادة الضبط لا تعيد سجلًا محجوبًا؛ مصدر غير متاح لا يُستبدل بعداد صفر |
| النقص والمعالجة | الحرية المطلقة قد تفقد العمل؛ أضيفت عناصر محمية وفصل بين الإخفاء والحذف، وترتيب القسم وأولوية السجلات |
| الحكم والاعتماد | متسق نظريًا؛ يحتاج موافقة على حدود التخصيص واختبار فهمها؛ HD-10/11، HST-16/17 |

| الفعل وطريق السجل | لمس عنوان أو فعل 44×44 على الأقل، بحث كامل المساحة، تفاصيل كاملة مع رجوع إلى موضع الصف |
| الأخطاء | عنوان طويل، لوحة مفاتيح، مساحة أمان، خط 200%، اتجاه مختلط؛ ارتفاع مرن وشريط غير حاجب |
| الغياب/الصلاحية | لا يحذف الموعد/السبب لإجبار الصف على سطر واحد؛ نفس القيود والمصادر على الهاتف والكمبيوتر |
| النقص والمعالجة | عمود سياق وأزرار صغيرة كانا سيجعلان العرض غير صالح؛ يتحول السياق الكامل وتلتف الأفعال، ولا يصغر النص |
| الحكم والاعتماد | مخطط قابل للفهم فقط؛ لا إثبات إعادة تدفق أو TalkBack فعلي؛ HD-15، مصفوفة العروض الستة |

### HS-15 — مراجعة ما أُنجز اليوم

| البند | نتيجة المرور النظري |
|---|---|
| ما يظهر | وجهة مراجعة عامة عند توفرها، بنود إتمام/نتائج مسجلة وباقي العمل، مع اليوم والقاعدة والتغطية |
| الترتيب | الإتمام بتاريخ الحدث الأصلي، لا وقت المزامنة؛ سجل له أحداث متعددة لا يصبح أعمالًا متعددة؛ إعادة الفتح موضحة |
| الفعل وطريق السجل | فتح بند إلى سجله الأصلي، أو فتح متابعة مرتبطة، والعودة إلى المراجعة |
| الأخطاء | مصدر لا يملك تاريخ إتمام، تأخر مزامنة، تعارض نتيجة، استعادة بيانات؛ لا استنتاج من آخر تعديل |
| الغياب/الصلاحية | إذا غابت منظومة التقرير لا رابط ميت ولا تقرير منزلي بديل؛ يمكن فتح قائمة منجز في مالكها إن توفرت بتسميتها المحدودة |
| النقص والمعالجة | حصيلة مزيفة من عدد التعديلات؛ فُصلت دلالات الأحداث والنتائج والنطاق في HC-12 |
| الحكم والاعتماد | الاعتماد والتنفيذ العامان لازمان؛ HD-13، HJ-10، HC-12 |

## 4. النتيجة وحدودها

مررنا **15/15 سيناريو نظريًا** وحددنا مسارًا أو اعتمادًا معلنًا لكل منها. لا تعني هذه النتيجة أن 15 سيناريو نجحت عمليًا. لا يوجد قياس زمن أو اختبار جهاز أو تدقيق أمني أو تقرير WCAG.

الفجوات التي لا يغلقها الورق: دلالات مصادر الأعمال، الصلاحيات، المحرك المحلي/المزامنة، توحيد التخصيص، مصدر الإتمام والتقارير، واختبار قابلية الاستخدام والأداء. خطة التحقق العملية المقترحة في [النطاق والخطة](HOME_SCOPE_AND_ROADMAP.md)، والحكم النهائي في [مراجعة التصميم](HOME_DESIGN_REVIEW.md).
