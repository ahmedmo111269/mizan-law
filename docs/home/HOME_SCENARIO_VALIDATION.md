## 1. طريقة الاختبار

كل سيناريو يُعالج بجدول ثابت: ما يظهر، كيف تُرتب المعلومات، الإجراء المتاح، الوصول للسجل، حالات الخطأ، غياب البيانات/الصلاحيات، والقصور المكتشف. النتائج تُلخص في §3.

## 2. السيناريوهات الخمسة عشر

### V-01 — محامٍ لديه خمس جلسات وثلاث مهام متأخرة

| البند | النتيجة |
|---|---|
| ما يظهر | شريط «الآن»: أقرب جلستين + أشد المتأخرات؛ المجرى: شريحة «متأخرة» (3 مهام، الأقدم استحقاقًا أولًا) ثم «اليوم» (الجلسات بترتيب وقتها المسجَّل) |
| الترتيب | استحقاق مسجَّل لا «أهمية» مفترضة؛ كل صف بسببه |
| الإجراء | لكل جلسة: [فتح الملف] [تسجيل نتيجة]؛ لكل مهمة: [فتح/تسجيل] |
| الوصول | خطوة واحدة لكل سجل |
| الأخطاء | جلسة بلا ملف مرتبط → لا زر ملف؛ مهمة بلا موعد → تظهر في «اليوم» إن كان استحقاقها اليوم |
| النقص المكتشف | لا نقص؛ تحقق من أن «الآن» لا تتجاوز 5 ولا تكرر صفوف المجرى (P3) |

### V-02 — موظف إداري لديه عشرون متابعة

| البند | النتيجة |
|---|---|
| ما يظهر | المرشح الافتراضي «الكل»؛ شريحة «اليوم» قد تحوي أكثر من الحد → عداد «اليوم (14)» + «عرض الكل» |
| الترتيب | الأقدم استحقاقًا؛ التصفية بالنوع/المسؤول متاحة |
| الإجراء | تحديث الحالة من الصف عبر الوحدة المالكة |
| النقص | **مُعالج:** الحد الافتراضي 5 + عداد صادق (P13)؛ **مُسجَّل:** «عرض الكل» يحتاج قوائم كاملة جاهزة في وحدات المتابعة (اعتمادية) |

### V-03 — مستخدم يفتح البرنامج دون اتصال

| البند | النتيجة |
|---|---|
| ما يظهر | مؤشر «دون اتصال — تعمل محليًا»؛ المجرى من النسخة المحلية |
| الإجراءات | كل المدعوم محليًا (ADQ-18)؛ ما يحتاج اعتمادًا مشتركًا يظهر معلَّقًا بوضوح |
| الأخطاء | تنبيه «قد لا تشمل البيانات تغييرات غير متزامنة» عند الحاجة (ADQ-41/17) |
| النقص | لا نقص؛ تحقق: لا إجراء معطّل بسبب الشبكة إلا ما يستلزمها السلوك المعتمد |

### V-04 — مستخدم لديه عدة قواعد بيانات

| البند | النتيجة |
|---|---|
| ما يظهر | اسم القاعدة النشطة دائمًا؛ المجرى لقاعدة واحدة فقط (P7) |
| الترتيب | لا اختلاط؛ البحث الشامل يظهر اسم القاعدة لكل نتيجة |
| الإجراء | التبديل: فحص العملية الجارية (ADQ-04) ثم إعادة بناء المجرى مع بقاء التفضيلات |
| الأخطاء | سجل «استئناف» من قاعدة أخرى → شارة + تحويل آمن |
| النقص | **مُسجَّل:** هل يحتاج المجرى مؤشرًا على سجلات «الاستئناف» البعيدة؟ (V-10/HD-04) |

### V-05 — مستخدم لا يستطيع الوصول إلى بعض الملفات

| البند | النتيجة |
|---|---|
| ما يظهر | لا تظهر أصلًا في المجرى أو العدادات أو البحث (ADQ-25) |
| الأخطاء | إن كان يملك رابطًا قديمًا → «لم تعد تملك صلاحية الوصول إليه» |
| النقص | تحقق من أن العدادات لا تكشف الوجود (لا «لديك 4 أعمال محجوبة») |

### V-06 — يوم عمل هادئ دون مهام

| البند | النتيجة |
|---|---|
| ما يظهر | شريط «الآن» مطوي برسالة واحدة هادئة؛ المجرى: «لا أعمال مستحقة الآن» + القادمة المسجَّلة إن وُجدت (بيانات حقيقية فقط) |
| الإجراءات | البحث و«إجراء جديد» كما هما؛ لا إحصاءات شكلية ولا تنبيهات مصطنعة |
| النقص | **مُعالج:** القسم «القادم المسجَّل» يعتمد على وجود بيانات فعلية فقط — إن لم يوجد شيء، صمت مريح لا ملء |

### V-07 — يوم مزدحم بعشرات الأعمال

| البند | النتيجة |
|---|---|
| ما يظهر | «الآن» ≤ 5؛ كل شريحة ≤ الحد مع عداد الكلي؛ لا تكرار |
| الترتيب | واضح وثابت؛ لا إخفاء غير مفهوم |
| الإجراء | «عرض الكل» لكل شريحة ينقل لقائمة موسّعة/الوحدة المالكة |
| الأداء | استعلامات محدودة لكل شريحة (H1)؛ لا تحميل الكل (REQ-013) |
| النقص | **مُسجَّل:** جودة تجربة القائمة الموسّعة نفسها تعود لوحداتها — خارج مسؤولية الصفحة |

### V-08 — مستخدم يريد تسجيل موكل جديد

| البند | النتيجة |
|---|---|
| ما يظهر | «إجراء جديد» ← «موكل جديد» **فقط إذا كانت وحدة الموكلين متاحة**؛ وإلا فالإجراء محجوب لا معطَّل |
| الإجراء | تحويل لمسار الإنشاء في الوحدة المالكة (J4) |
| العودة | استعادة موضع المجرى (P14) |
| النقص | **مُعالج:** لا نموذج موازٍ؛ **مُسجَّل:** زمن العودة يعتمد على تجربة وحدة الموكلين نفسها |

### V-09 — مستخدم يريد الوصول إلى قضية بسرعة

| البند | النتيجة |
|---|---|
| ما يظهر | البحث في شريط السياق متاح دائمًا |
| الترتيب | نتائج مصنفة: قضية/مسار، ملف، أشخاص… |
| الإجراء | فتح مباشر؛ في الشامل اسم القاعدة |
| الأخطاء | لا نتائج / خطأ / انقطاع بحالاتها (§4 من الحالات) |
| النقص | لا نقص؛ تحقق من حفظ السياق عند الرجوع (P14) |

### V-10 — مستخدم يعود إلى سجل تغيرت صلاحياته

| البند | النتيجة |
|---|---|
| ما يظهر | عند الفتح من «استئناف» يُعاد التحقق: «لم تعد تملك صلاحية الوصول إليه» |
| السلوك | يُزال العنصر من القائمة أو يُشار إليه كغير متاح دون كشف محتواه |
| النقص | تحقق: لا كشف للمحتوى القديم المحفوظ (H3 يحفظ معرّفات فقط) |

### V-11 — مستخدم لديه تعديلات محلية غير متزامنة

| البند | النتيجة |
|---|---|
| ما يظهر | شارة «تغييرات معلقة» + استمرار العمل الكامل محليًا |
| الإجراء | مزامنة يدوية إن توفّرت؛ وإلا انتظار التلقائي |
| النقص | **مُعالج:** لا رسالة مزعجة لكل حفظ؛ شارة واحدة مستقرة |

### V-12 — مستخدم يواجه تعارضًا في المزامنة

| البند | النتيجة |
|---|---|
| ما يظهر | لافتة أعلى المجرى «توجد تعديلات متعارضة تحتاج مراجعتك» + عدّاد + رابط المراجعة |
| القاعدة | لا استبدال صامت (ADQ-16)؛ الصفحة تعرض التنبيه فقط والحسوم في مسار المنظومة |
| النقص | **مُسجَّل:** هل تُشار الصفوف المتعارضة داخل المجرى؟ (يتوقف على قدرة عقد H7 — `HD-12`) |

### V-13 — مستخدم أخفى معظم أقسام الصفحة بالتخصيص

| البند | النتيجة |
|---|---|
| ما يظهر | المجرى (غير القابل لإخفاء) + مسار واضح لإعادة السكة (قائمة/زر) |
| القاعدة | لا فقد وصول وظيفي (C4)؛ لا حذف بيانات |
| الإجراء | «إعادة الضبط» يعيد الافتراضي |
| النقص | تحقق من أن شريط «الآن» المخفي لا يُخفي أعمالًا لا بديل لها (تبقى في المجرى) |

### V-14 — مستخدم على هاتف بعرض 320px

| البند | النتيجة |
|---|---|
| ما يظهر | العمود الواحد كاملاً؛ شريط سفلي للإجراءات؛ لا تمرير أفقي غير مقصود |
| الأولويات | محفوظة بنفس الترتيب |
| اللمس | أهداف ≥ 44px؛ لا إجراء خلف Hover |
| النقص | تحقق من صف العمل على 320px: العنوان + السبب + زر ظاهر لا مطوي خلف قوائم متداخلة |

### V-15 — مستخدم يريد مراجعة ما أُنجز خلال اليوم

| البند | النتيجة |
|---|---|
| ما يظهر | «حصيلة اليوم»: أُنجز اليوم / بقي / متأخر / نتائج جلسات / تنتظر قرارًا |
| الإجراء | كل بند وكل عنصر ينتقل إلى سجله |
| الأخطاء | بند مصدره غير متاح → «غير متاح الآن» داخل البند فقط |
| النقص | **مُعالج:** ليست أرقامًا صماء؛ **مُسجَّل:** تعريف «أُنجز اليوم» يعتمد على قدرات الوحدات على الاستعلام (H4) |
