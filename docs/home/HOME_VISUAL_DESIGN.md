# الهوية البصرية ونظام العناصر

> **تصور بصري مقترح للاعتماد HD-15، لا مكتبة واجهات ولا اختيار تقنية.** لا صور واجهات منفذة، ولا خطوط أو أصول خارجية، ولا شعارات مولدة. المقاسات أبعاد تصميم منطقية تُترجم إلى وحدات المنصة بعد اعتمادها.

## 1. الفلسفة: رصانة دفتر عمل، لا زخرفة ميزان عدالة

هوية هادئة أقرب إلى ورقة عمل واضحة: خلفية حجرية فاتحة، أسطح نظيفة، نص داكن ذو حضور، ولون بترولي محدود للفعل والتحديد. القيمة البصرية تأتي من **المحاذاة والخط والإيقاع** لا من التدرجات والبطاقات الكثيرة أو صور المحاكم.

- أهم كتلة هي قائمة العمل؛ لا شريط بطاقات إحصائية فوقها.
- عنوان العنصر وموعده يقرآن قبل الوصف الثانوي؛ السبب ظاهر لا يحتاج فتحًا.
- الأنواع تميّز بكلمة وأيقونة ثابتة، لا لون مستقل لكل جلسة ومهمة وموكل.
- اللون التحذيري لحقيقة تحتاج تصرفًا، لا لكل متأخر أو تاريخ قريب تلقائيًا.
- الشعار الحالي غير مصمم في المستودع؛ يُستخدم الاسم النصي «ميزان» فقط، ولا يُعتمد شعار جديد ضمن الصفحة.

## 2. المشهد البصري المقترح

**الكمبيوتر:** شريط تطبيق خفيف يضم الهوية والقاعدة والبحث وبدء العمل. تحته عنوان «مكتب اليوم» وتاريخ ونطاق صغيران. سطر نصي لأسباب العمل والمرشحات، ثم قائمة عريضة على اليمين؛ مساحة سياق على اليسار عند اختيار عنصر فقط. بلا اختيار تتمدد القائمة، ولا تبقى لوحة فارغة توهم بوجود بيانات. نهاية القائمة تضم استئنافًا قصيرًا ورابط المراجعة عند توفرهما.

**الهاتف:** اسم القاعدة لا يغيب؛ عنوان واضح يتبعه ملخص الوصول إلى المجموعات. صفوف قصيرة متعددة الأسطر، وكل إجراء مسمى. الأدوات الأساسية في شريط سفلي بدل ضغط البحث و«جديد» في الرأس. التفاصيل تأخذ مساحة كاملة. لا حائط بطاقات ولا تمرير أفقي للمرشحات الأساسية.

الرسوم التفصيلية وأبعاد المساحات في [التصميم المتجاوب](HOME_RESPONSIVE_DESIGN.md).

### 3.1 فحص أولي حسابي للتباين

حُسبت النسب من قيم sRGB نفسها باستخدام الإضاءة النسبية ومعادلة `(L الأعلى + 0.05) / (L الأدنى + 0.05)`، بعملية محلية عابرة دون مكتبات. هذه **نتيجة حساب ألوان** فقط، لا قياس واجهة ولا إثبات امتثال WCAG.

| الزوج المفحوص | فاتح | داكن |
|---|---:|---:|
| نص أساسي / سطح القراءة | 14.57:1 | 12.95:1 |
| نص ثانوي / سطح القراءة | 6.27:1 | 8.21:1 |
| نص الزر / خلفية الفعل | 7.51:1 | 8.67:1 |
| حد تفاعلي / سطح القراءة | 3.63:1 | 3.91:1 |
| حلقة التركيز / سطح القراءة | 6.01:1 | 9.83:1 |
| نص التحذير / سطحه | 6.23:1 | 8.62:1 |
| نص الخطأ / سطحه | 6.11:1 | 8.05:1 |
| نص المعلومة / سطحها | 7.39:1 | 7.87:1 |
| نص النجاح / سطحه | 6.28:1 | 8.11:1 |

نص الصفحة الأساسي على خلفية الفاتح 13.23:1. أي توليفة أخرى، أو شفافية، أو حالة Hover/تعطيل/تركيز فوق لون مختلف، يجب اختبارها لاحقًا ولا يرث اعتماد هذه الأرقام. الهدف النصي 4.5:1 للعادي و3:1 للكبير المؤهل، والعناصر الدالة غير النصية 3:1. لا يُستخدم الفاصل الزخرفي لتعويض حد وظيفي مطلوب.

## 4. الخطوط والتدرج الطباعي

**الخط المقترح:** خط واجهة النظام المتاح محليًا الذي يدعم العربية جيدًا. يُتحقق من تشكيل الحروف وأوزان الخط على Windows وAndroid قبل الاعتماد. لا تنزيل خط ويب ولا تضمين خط تجاري أو حزمة أيقونات. إن لم تكفِ خطوط النظام، يرفع طلب اعتماد مستقل يشمل الترخيص والحجم والعمل دون اتصال.

| الدور | المقاس المقترح | ارتفاع السطر | الوزن | الضابط |
|---|---:|---:|---|---|
| عنوان الصفحة | 24 للهاتف، 28 للكمبيوتر | 36 / 40 | متوسط ثقيل | ليس عنوانًا دعائيًا ضخمًا |
| عنوان مجموعة | 18 | 28 | متوسط ثقيل | السبب قبل العدد |
| عنوان صف/نص العمل | 16 | 26 | متوسط للعناوين، عادي للنص | لا يصغر بسبب عرض 320px |
| وصف/وقت/مصدر | 14 | 22 | عادي | أرقام ومصدر مقروءان؛ لا 10px |
| أزرار وإدخال | 16 | 24–26 | متوسط | أهداف اللمس منفصلة عن ارتفاع الحرف |
| شارة نوع/حالة | 14 | 22 | متوسط | لا أحرف صغيرة جدًا لاستيعاب عدد شارات زائد |

لا تباعد اصطناعي بين الحروف العربية ولا مدّ زخرفي. الأرقام والرموز المختلطة تُعزل اتجاهيًا داخل النص العربي، ولا يُعكس رقم القضية أو الهاتف. صيغة الأرقام والتاريخ تتبع التفضيل العام بعد HD-04؛ لا تحويل تقويم أو أرقام من داخل الرئيسية.

ارتفاع الصف **حد أدنى لا ارتفاع ثابت**: مريح على الكمبيوتر نحو 80، ومدمج نحو 64 مع الحفاظ على أهداف تفاعل 44. على الهاتف نحو 104 أو أكثر عند وجود وصف وفعل، ويزيد مع المحتوى أو التكبير. لا تقطع السطور لإجبار هذا الارتفاع.

## 6. نظام العناصر المقترح

| العنصر | الحالة الأساسية | التفاعل/الحالات الأخرى |
|---|---|---|
| زر رئيسي | لون الفعل ونص مسمى؛ فعل واحد رئيسي في السياق | Hover بتعتيم محسوب، ضغط واضح، تركيز مستقل، تحميل مع اسم العملية؛ يختبر تباين كل حالة |
| زر ثانوي/رابط | نص دلالي وحد واضح عند الحاجة | الرابط داخل النص مسطر، لا اللون وحده؛ لا خلفية تنافس العنوان |
| حقل البحث | عنوان/تسمية دائمة، نطاق ظاهر، رمز بحث مساعد | تركيز واضح، مسح باسم مفهوم، خطأ ملاصق؛ Placeholder ليس التسمية الوحيدة |
| سطر عمل | نوع، عنوان، موعد، سياق وسبب | المحدد يحمل حدًا عند بداية السطر RTL ونص حالة؛ لا يقفز ارتفاعه لمجرد Hover |
| عنوان مجموعة | سبب/عدد معلوم أو «المزيد متاح»، و«عرض الكل» | الطي يظهر سهمًا وحالة نصية؛ يمكن الوصول باللوحة |
| مرشح/عدسة | نص يبين الحالة المختارة | حد/علامة اختيار مع اللون؛ الالتفاف إلى سطرين بدل سحب أفقي خفي |
| قائمة إجراءات | أفعال مسماة بصيغة فعل واضح | التركيز محسوب، لا تمرير أفقي ولا عناصر فارغة |
| حالة فارغة | عنوان قصير، تفسير نطاق، فعل متاح | بلا رسم زخرفي ضخم أو بيانات عينة |
| حالة تحميل | سطور محايدة بلا أسماء وأعداد | لا وميض أو لمعان مستمر؛ إعلان «جارٍ تحميل الأعمال» لقارئ الشاشة |
| شريط استثناء | أيقونة + رسالة محددة + فعل للتعافي | لا تكرار للافتة نفسها فوق كل مجموعة؛ خطأ الجزء يبقى عنده |

مثال **تركيب** صف، لا بيانات اختبار:

```text
[نوع السجل]  {العنوان الأصلي القابل للفتح}
{دلالة الموعد وقيمته المسجلة} · {المحكمة أو الجهة إن انطبق}
{القضية/المسار} · {الملف أو العلاقات المتاحة} · {المسؤول إن دعم}
{سبب الظهور}                         [الإجراء التالي] [تفاصيل]
```

## 7. الأيقونات وحالات الدلالة

أسلوب خطي واحد، حجم 20 أو 24، وسماكة متسقة وفق القدرة المتاحة محليًا. أسماء عربية مقروءة للأفعال الأساسية؛ لا أيقونة مبهمة وحيدة للإنجاز أو تغيير القاعدة. أي اعتماد لمكتبة لاحق منفصل، ولا يُطلب تنزيل موارد عند التشغيل.

- تعكس الاتجاه فقط أيقونات «رجوع/تقدم» ومسار القراءة. لا تُعكس الساعة أو المستند أو الأرقام.
- النوع يحمل اسمًا «جلسة/موعد/مهمة/إجراء»، لا شكل مطرقة يوحي بأولوية قانونية.
- «محفوظ محليًا» و«بانتظار المزامنة» و«متعارض» نصوص مستقلة؛ لا علامة صح خضراء تجمعها.
- المتأخر شارة نصية مع الموعد؛ الأحمر لفشل/عائق مؤثر، وليس كل عمل قديم.

## 8. التركيز والتحديد والحركة

- التركيز المرئي المقترح: حلقة 2 مع فصل 2 عن العنصر؛ لا تخفيها الخلفية أو الشريط الثابت، وتختبر عند كل سطح.
- التحديد غير التركيز: سطح خفيف + حد دلالي + حالة مسماة؛ يمكن أن يكون الصف محددًا والتركيز على البحث.
- انتقالات اختيارية قصيرة 120–180ms للتوسع/الحوار، دون تحريك صفوف الأعمال تلقائيًا. هذه قيم مقترحة لا تقنية اعتماد.
- تفضيل تقليل الحركة: إلغاء الحركة غير الضرورية واللمعان، مع بقاء التغير مفهومًا فورًا.
- لا رسوم عدادات متصاعدة، ولا احتفالات بالإنجاز، ولا سحب لإتمام سجل كوسيلة وحيدة.

## 9. الفاتح والداكن والاتساق العام

المبدأ نفسه في الوضعين: التباين وترتيب المعلومات، لا عكس آلي لكل لون. يتبع الوضع تفضيل النظام العام أو اختيار المستخدم إن نفذ؛ لا مفتاح theme خاص بالرئيسية ولا تفضيل منافس. لا تُقلَّل أهمية النص الثانوي في الداكن ولا تستخدم مساحات حمراء متوهجة.

ينبغي عند التنفيذ اللاحق تحويل الأدوار الدلالية إلى نظام تصميم عام يخدم الموكلين والملفات والبحث. هذا لا يغيّر حزمة الموكلين الحالية، ولا يفترض أن لها مكونات بصرية منفذة. مراجعة الأسماء والأزرار والحالات المشتركة تسبق بناء أي مكون خاص بـhome.

## 10. قائمة تحقق الوصول البصري

| الفحص المستقبلي | معيار القبول المقترح |
|---|---|
| كل أزواج النص/الخلفية والحالات | نسب AA المناسبة، بما فيها النطاق المعطل والمرشحات والروابط |
| لون فقط | يمكن تفسير المتأخر/التعارض/التحديد بالنص والأيقونة دون ألوان |
| تكبير النص 200% وإعادة التدفق 320px | لا اختفاء فعل أو مصدر أو تمرير ثنائي الاتجاه |
| رؤية التركيز | ظاهر وغير محجوب بشريط ثابت أو حوار؛ ترتيب منطقي عربي |
| نص عربي طويل ومختلط | تشكيل صحيح، لا انقلاب معرّفات، وعدم قطع دلالة الموعد |
| قارئ شاشة | عناوين ومجموعات وقوائم مسماة، والأيقونة الزخرفية لا تكرر نصها |
| الحركة/التباين العالي | احترام إعدادات المستخدم وإبقاء العناصر الدالة مفهومة |

هدف الحزمة **الاسترشاد بمبادئ WCAG 2.2 AA**، وليس شهادة امتثال. يلزم اختبار على المنصة المعتمدة فعلًا، خصوصًا TalkBack على Android وقارئ شاشة Windows مناسب، دون فرض مكتبة للوصولية.
