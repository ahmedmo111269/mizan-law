## 1. فلسفة الهوية: «الرصانة الهادئة»

أداة عمل قانونية تُستخدم ساعات يوميًا: يجب أن تنقل **الثقة والانضباط** دون صرامة مُرِهقة، و**الحداثة** دون موضة عابرة. لذلك:

| المبدأ | الترجمة |
|---|---|
| رصانة | لون أساسي عميق، خطوط واضحة، لا زخرفة |
| هدوء | مساحات تنفس، تدرج رمادي دافئ، حركة قليلة مبرَّرة |
| وضوح | تسلسل بصري حاد: العمل أولًا، والسياق تابع |
| عدالة تباينية | كل نص وحالة يحققان تباينًا كافيًا في الوضعين |
| اتساق قابل للتوسع | الرموز (tokens) مشتركة لباقي «ميزان» عند الاعتماد |

## 2. نظام الألوان — الأدوار قبل القيم

> القيم أدناه **مقترحة** كرموز تصميمية (design tokens) لتوضيح النظام؛ قد تُعدَّل عند الاعتماد والقياس الفعلي للتباين. الأولوية للأدوار لا للأكواد.

### 2.1 الأدوار اللونية

| الدور | الاستخدام | القيمة المقترحة (فاتح) | القيمة المقترحة (داكن) |
|---|---|---|---|
| الحبر (Ink) | النصوص الأساسية | `#1C2430` | `#E8ECF2` |
| الحبر الثانوي | النصوص المساعدة | `#5A6472` | `#A9B2BF` |
| الورق (Surface) | خلفية الصفحة | `#F7F5F1` (رمادي دافئ) | `#141A22` |
| اللوح (Panel) | الأسطح المرتفعة (الصفوف، السكة) | `#FFFFFF` | `#1D2530` |
| الأساسي (Primary) | الأزرار الأساسية، التركيز | كحلي الحبر `#24405E` | `#7FA8D4` |
| البرونز (Accent) | التمييز الراقي، التحديد الخفيف | برونزي `#8A6D3B` | `#C9A227` |
| الدلالة — متأخر | شارة التأخير | أوكر محروق `#9A4A24` | `#E0906A` |
| الدلالة — اليوم/استحقاق | استحقاق اليوم | كهرماني `#8A6116` | `#E4B25C` |
| الدلالة — انتظار | ينتظر قرارًا/متابعة | أزرق رمادي `#3E6280` | `#8FB3D4` |
| الدلالة — اكتمل | حصيلة/إنجاز | أخضر هادئ `#2F6B4F` | `#7FBF9A` |
| الدلالة — خطأ/تعارض | حالات الفشل | أحمر مطفأ `#8E2F2F` | `#E08A8A` |

### 2.2 قواعد الألوان الحاكمة

1. **اللون لا يحمل المعنى وحده أبدًا** (U6): كل حالة دلالية = لون + أيقونة + نص.
2. **اللون الأساسي للعمل لا للزينة:** الكحلي للتفاعل، والبرونز للمسات التمييز المحدودة (التحديد، التبويب النشط) — لا انتشار عشوائي.
3. **الأحمر نادر:** للخطأ والتعارض فقط؛ التأخير «أوكر» لأن المتأخر واقع عمل يومي لا كارثة.
4. **تباين مستهدف:** كل نص مقابل خلفيته ≥ 4.5:1، والعناصر الكبيرة والأيقونات ≥ 3:1 (WCAG 2.2 AA — استهداف لا ادعاء امتثال قبل الاختبار).
5. **الوضع الداكن موازٍ لا مقلوب:** أدوار محفوظة بقيم معدَّلة؛ صور العرض والشارات تُختبر في الوضعين.

## 3. الخطوط والأحجام

| البند | القرار |
|---|---|
| عائلة الخط | **معلّقة على اعتماد** (`HD-07`): مرشحة عربية عالية الوضوح للواجهات (مثل عائلات Sans عربية مفتوحة المصدر)؛ لا تحميل خارجي دون موافقة |
| المقياس الطباعي | 12 / 13 / 15 / 17 / 20 / 24 / 30 (px مقترحة) |
| نص الصف | 15px سطر 1.7 — كثافة مريحة للاستخدام الطويل |
| عناوين الشريحة | 17px شبه ثقيل |
| عنوان الصفحة | 20–24px |
| الشارات والوسوم | 12–13px |
| ارتفاع السطر | ≥ 1.6 لكل النصوص العربية (نقط وعلامات الاتصال) |
| العناوين المقطعية | لا نصوص ضخمة؛ التسلسل بالوزن والمسافة لا بالحجم الصارخ |

## 4. المسافات والشبكة

| البند | القرار |
|---|---|
| وحدة المسافة | 4px؛ السلّم: 4، 8، 12، 16، 24، 32، 48 |
| حشو الصف | 12–16px عموديًا، 16px أفقيًا |
| فواصل الشرائح | 24px بين شرائح المجرى |
| عرض المحتوى الأقصى | 1440px مركزيًا؛ لا تمدد مطلق على الشاشات العريضة |
| الاتجاه | RTL منطقي (logical properties): الحواف «بداية/نهاية» لا «يسار/يمين» |

## 5. أشكال العناصر التفاعلية

| العنصر | الشكل |
|---|---|
| الزر الأساسي | مستطيل بزوايا 8px، ملء الكحلي، نص فاتح؛ **زر أساسي واحد لكل منطقة** |
| الزر الثانوي | حد + خلفية شفافة |
| زر الإجراءات «⋯» | دائري محايد بلا نص؛ تسمية وصول إلزامية |
| صف العمل | لوح بزوايا 8px وحد خفيف؛ التمييز بالمسافة لا بالبطاقة الملوّنة |
| الشارة (سبب الظهور) | حبة (pill) صغيرة بلون دلالي خفيف النص + أيقونة |
| الحقول | ارتفاع ≥ 44px، حد 1px، تركيز واضح |
| القوائم المنسدلة | لوح مرتفع بظل ناعم، عناصر ≥ 44px |
| التبويب/الشريحة النشطة | خط سفلي برونزي + وزن أثقل (لا ملء لوني) |

## 6. القوائم والبطاقات

| القاعدة | السبب |
|---|---|
| **الصف هو الوحدة** (list-first) لا البطاقة المربعة | كثافة معلومات مريحة + قابلية المسح البصري |
| البطاقات مقصورة على السكة (وحدات مصغّرة) ونتائج البحث | حيث يتطلب المحتوى استقلالًا بصريًا حقيقيًا |
| لا شبكة بطاقات إحصائية | القرار الحاكم في الأمر §1 وP1 |
| التسلسل داخل الصف: عنوان ← سبب ← سياق ← إجراء | يطابق ترتيب أسئلة المستخدم |

## 7. حالات التنبيه والتركيز

| الحالة | المظهر |
|---|---|
| معلومة عابرة | شريط سطري هادئ (info) يختفي ذاتيًا |
| نجاح إجراء | رسالة قصيرة عند الصف + تغيير الحالة؛ لا نوافذ احتفال |
| تحذير (مثلاً تباعد المزامنة) | شارة أوكر + نص؛ بلا اهتزاز |
| خطأ | رسالة صريحة + إجراء (إعادة المحاولة/التفاصيل) باللون الدلالي المطفأ |
| تعارض مزامنة | لافتة أعلى المجرى مع زر «مراجعة التعارضات» (مسار المنظومة العامة) |
| التركيز (Keyboard) | حلقة تركيز 2px بلون الأساسي مع تباعد داخلي؛ مرئية في الوضعين |
| التحديد/التفعيل | لا يعتمد على اللون وحده (U6) |

## 8. الحركة والانتقالات

| البند | القرار |
|---|---|
| المدة | 120–220ms للحالات الصغيرة؛ ≤ 300ms للطي والتوسيع |
| المبرر الوحيد | توضيح تغير البنية (طي شريحة، ظهور منطقة، تحديث صف) — لا حركة للزينة |
| ممنوع | الارتداد، الوميض، الحركة المتكررة، القلوب المتسارعة |
| `prefers-reduced-motion` | تُلغى الحركة ويُحل محلها تغيير فوري مفهوم |
| التحديث الحي | وميض خفيف للحد فقط عند تغيّر صف (≤ 1 ثانية) |

## 9. الوضع الفاتح والداكن

| البند | القرار |
|---|---|
| الافتراضي | الفاتح (بيئة مكاتب مصرية مضيئة وشاشات متوسطة) |
| الداكن | اختياري `[معلّق — HD-14]`؛ يُنفَّذ بنفس الأدوار لا بقلب مقلوب |
| الالتزام | التباين المتساوي في الوضعين؛ الصور والشارات تُختبر فيهما |
| النظام | احترام تفضيل النظام مع تجاوز يدوي محفوظ (عبر التخصيص العام) |

## 10. الاتساق بين أقسام «ميزان»

1. **الرموز أصل مشترك:** الألوان والمسافات والخط والظلال tokens واحدة تُعار للوحدات عند اعتمادها.
2. **قواعد الصف والشارة والزر موحّدة:** ما ظهر في «مكتب اليوم» يعود بنفس الشكل في القوائم الكاملة.
3. **الشارات الدلالية (متأخر/اليوم/انتظار/اكتمل/خطأ) قاموس مشترك** لكل البرنامج.
4. **الأيقونات:** أسلوب واحد مقترح (خطوط بسمك موحّد، أركان 2px)، ومجموعة واحدة تُعتمد تقنيًا لاحقًا؛ كل أيقونة لها بديل نصي.
5. **النصوص:** لغة عربية فصحى موحّدة قصيرة (انظر قاموس التسمية في `HOME_INFORMATION_ARCHITECTURE.md` §6).

## 11. إمكانية الوصول البصرية — استهدافات

| البند | الاستهداف |
|---|---|
| تباين النصوص | ≥ 4.5:1 (عادي) و≥ 3:1 (كبير) |
| تركيز مرئي | حلقة على كل عنصر تفاعلي |
| أهداف اللمس | ≥ 44×44px |
| التكبير | قابلية الاستخدام عند تكبير النص 200% دون قص أفقي |
| قارئات الشاشة | ترتيب منطقي؛ منطقة حيّة مهذبة لتحديثات المجرى؛ أسماء أزرار وصفية |
| لا اعتماد على اللون | دائمًا (U6) |

> هذا استهداف تصميمي؛ **لا ادعاء بامتثال WCAG قبل اختبارات فعلية** (أمر §24).

## 12. ممنوعات بصرية صريحة

1. تدرجات لونية صارخة وخلفيات مزخرفة.
2. ظلال عميقة أو «زجاجية» (glassmorphism) تستهلك GPU على Android متوسط.
3. أيقونات ملونة مبهجة غير متناسقة الأسلوب.
4. نصوص متحركة أو ماركيه.
5. إطارات وحواف مزدوجة (حد داخل حد) بدون مبرر.
6. ألوان نظام مختلفة عن الرموز المعتمدة.
7. بطاقات مكررة ملوّنة لكل نوع عمل.
