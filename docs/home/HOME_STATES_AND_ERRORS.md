# حالات الواجهة والأخطاء والاتصال والمزامنة

> **سلوك ورسائل مقترحة للاعتماد، لا حالات مقاسة في تطبيق.** تعتمد كل رسالة على إشارة مصدر حقيقية من [العقود](HOME_DATA_CONTRACTS.md). النص بين الأقواس المعقوفة متغير من مصدر مصرح، لا قيمة تجريبية.

## 1. حالات مستقلة لا «متصل/غير متصل» فقط

تُقرأ أربعة محاور متزامنة:

1. **البيانات:** تحميل، متاحة، جزئية، فارغة مؤكدة، غير معروفة، فشل.
2. **العمل المحلي:** محفوظ مؤكد، حفظ جارٍ، فشل، نتيجة عملية غير معروفة؛ ليست مرادفات لانتظار المزامنة.
3. **المزامنة:** مسار اتصال محلي/إنترنت/غير متاح، انتظار، جارٍ، فشل، تعارض، حداثة معروفة أو غير معروفة.
4. **الوصول/التوافق:** متاح، قراءة فقط، تغيرت صلاحية، إبطال، إصدار غير متوافق.

قد تجتمع بيانات محلية صالحة مع فشل مزامنة وتعارض في سجل آخر. لا يحل وصف أخضر عام محل هذه الحقائق. انقطاع الإنترنت لا يمنع المزامنة عبر الشبكة المحلية إذا كانت الخدمة تتيحها.

### ترتيب عرض الاستثناءات

العائق الأمني/التوافقي المؤثر أولًا؛ ثم التعارض أو الفشل المؤثر؛ ثم الانتظار/التباعد؛ ثم حالة الاتصال الهادئة. هذا ترتيب رسائل لا ترتيب أهمية قانونية. التفاصيل تجمع الحالات الأخرى دون محوها، وكل حالة تبين نطاقها: القاعدة النشطة أو سجل الأشخاص أو سجل محدد.

| **HST-08 — تغييرات محلية تنتظر** | «توجد تغييرات محفوظة محليًا بانتظار المزامنة» إذا أكدت الخدمة الحفظ والانتظار | فتح تفاصيل الحالة؛ طلب مزامنة عند توفر القدرة | لا نجاح مزامنة أخضر، ولا إعادة العمل إلى مستحق لمجرد انتظار الإرسال |
| **HST-09 — مزامنة جارية** | «جارٍ مزامنة {النطاق المصرح}»؛ تقدم فقط إذا أعاده المالك بدلالة صحيحة | استمرار العمل المحلي؛ فتح التفاصيل | لا نسبة مختلقة، لا زر يطلق عملية ثانية مكررة، لا قفل بقية الوحدات دون سبب |
| **HST-10 — فشل المزامنة** | «لم تكتمل المزامنة» + وقت الفشل إن عُرف. «التغييرات المحلية المحفوظة باقية» فقط إن أكد المالك ذلك | تفاصيل/إعادة محاولة من الخدمة، أو توجيه إلى المسؤول عند سبب وصول | لا محو تغييرات أو إعادة تهيئة جهاز، ولا تحويل فشل الإرسال إلى فشل كل قراءة |
| **HST-11 — تعارض يحتاج مراجعة** | «توجد تعديلات متعارضة تحتاج مراجعة» ضمن المسموح، وإشارة على السجل المتأثر | فتح المراجعة العامة للمخول؛ «تواصل مع المسؤول المخول» إن لم توجد له قدرة حسم | لا فوز الأحدث، ولا حسم في الرئيسية، ولا تعطيل سجل مستقل بلا داعٍ |
| **HST-12 — فقد صلاحية** | إزالة تفاصيل السجل/القاعدة من العرض. «تعذّر إتاحة هذا المحتوى ضمن صلاحياتك الحالية» عند محاولة الوصول | العودة إلى الأعمال المسموحة أو اختيار قاعدة متاحة | لا عنوان قديم في المعاينة/البحث/الاستئناف، ولا عدّ للمحجوب؛ لا كشف إن كان محذوفًا أو موجودًا سرًا |
| **HST-13 — تغيير القاعدة النشطة** | القاعدة المختارة واضحة، حالة انتقال، لا صفوف قديمة تحت اسم جديد | حارس العملية: استكمالها/إلغاؤها بأمان/البقاء، ثم تحميل السياق الجديد | منع انتقال أثر عملية أو نتيجة طلب قديم للقاعدة الجديدة؛ لا حفظ جزئي |
| **HST-14 — قاعدة غير متاحة محليًا** | «هذه القاعدة غير متاحة على هذا الجهاز» فقط لقاعدة مسموح بمعرفتها | اختيار قاعدة محلية؛ فتح إدارة الإتاحة إن نُفّذت | لا افتراض تنزيل تلقائي، لا عرض ملف مخبأ من سياق آخر، ولا أسماء قواعد محجوبة |
| **HST-15 — أعمال كثيرة** | معاينات محدودة لكل مجموعة + «عرض الكل» ومؤشر مزيد/عدد معلوم | قائمة المجموعة بدفعات، تصفية نوع/مسؤول مدعوم | لا حد أقصى للعمل الفعلي؛ لا تحميل كل السجلات ولا إسقاط مجموعة ازدحمت |
| **HST-16 — أقسام مخفية** | مدخل «الأقسام المخفية»/«تخصيص»، وملخص وصول محمي للأعمال والاستثناءات | إظهار قسم أو «استعادة الافتراضي» | لا اختفاء للبحث/التنقل الأساسي عند توفرهما، ولا حذف بيانات أو تعديل صلاحيات |
| **HST-17 — استعادة التخصيص** | «ستُستعاد إعدادات عرض مكتب اليوم في {النطاق} فقط؛ لن تتغير بيانات العمل» | تأكيد، ثم نتيجة حفظ؛ إلغاء أو بقاء الإعداد السابق عند الفشل | لا إعادة ضبط تفضيلات الوحدات الأخرى ولا اعتبار reset عملية بلا تعارض |
| **HST-18 — تحديث خارجي أثناء العرض** | «توجد تحديثات للأعمال — تحديث العرض»؛ لا تبديل ترتيب تحت التركيز | تحديث محدود مع حفظ مرجع الموضع؛ فورًا للمنع الأمني عند وصوله | لا قفز تلقائي للصفوف أو إغلاق نموذج المالك؛ حالة السجل تُفحص قبل الفعل |
| **HST-19 — فتح سجل لم يعد متاحًا** | «تعذّر فتح السجل؛ قد لا يكون متاحًا في هذا السياق الآن»؛ تفصيل الحذف/النقل فقط إن سمح المالك | عودة، إعادة تحقق، أو إحالة أصل/وجهة مصرح بها | لا كشف وجود سجل محجوب، ولا إنشاء بديل يحمل الاسم نفسه |
| **HST-20 — حداثة غير مؤكدة/تباعد مؤثر** | «آخر مزامنة ناجحة: {الوقت}» أو «وقت آخر مزامنة غير معروف». تنبيه التباعد فقط بإشارة المالك | فتح الحالة ومتابعة المحلي؛ تحديث عند توفره | لا حد زمني يبتكره home، ولا عبارة «محدث الآن» بسبب إعادة رسم القائمة |
| **HST-21 — قراءة فقط/إصدار غير متوافق** | «القراءة فقط متاحة» أو «تحتاج هذه البيانات إصدارًا متوافقًا» بحسب إشارة المصدر | فتح تحديث/إدارة عامة إن نُفّذت، أو العودة | منع الكتابة غير المتوافقة ADQ-43؛ قراءة فقط إذا أكد المالك سلامتها، لا فتح قسري |

| **HST-24 — تفضيل قديم/تعارض تخطيط** | «تعذّر تطبيق بعض إعدادات العرض» أو «تفضيلات العرض تحتاج مراجعة» | تخطيط مأمون مؤقت، مراجعة عامة/إعادة ضبط ضمن النطاق | لا محو تفضيلات محفوظة أو فوز الأحدث؛ لا تعطيل قراءة الأعمال |
| **HST-25 — نتيجة العملية غير معروفة** | «لم نتأكد من نتيجة العملية بعد»؛ تختلف عن «فشل» وعن «تم» | الاستعلام عن نتيجتها من المالك، وإعادة محاولة تمنع تكرار الأثر | لا إنشاء ثانٍ، لا حذف الإدخال، لا نسبة إنجاز زائفة |
| **HST-26 — إبطال مستخدم/جهاز وصل للنظام** | شاشة الأمان العامة وتوجيه مأمون، بلا تفاصيل العمل | مسار استرداد/دخول معتمد إن وجد؛ المسؤول المخول | يحجب الوصول غير المسموح؛ لا ادعاء محو جهاز غير متصل أو محو تغييرات محلية من home |

## 3. حالات مركبة يجب ألا تختزل

| الحالة المركبة | العرض الصحيح |
|---|---|
| الإنترنت مقطوع والشبكة المحلية تزامن بنجاح | «المزامنة عبر الشبكة المحلية»؛ لا لافتة توحي أن كل المزامنة متوقفة |
| مصدر جلسات فشل والمهام المحلية ظهرت | خطأ جلسات في موضعه، ومهام قابلة للعمل؛ التغطية جزئية لا «يوم هادئ» |
| حفظ محلي ناجح ومزامنة فاشلة | تأكيد الحفظ من المالك + فشل مزامنة منفصل؛ لا إعادة إرسال عملية إنشاء كأن الحفظ فشل |
| تعارض في سجل الأشخاص، والقاعدة متزامنة | وصف النطاقين في تفاصيل H-09؛ لا «الكل متزامن» ولا حجب كل الملفات |
| عمل اكتمل محليًا وحالة مزامنته انتظار | لا يظهر مستحقًا؛ يظهر في مراجعة اليوم إن دعم المصدر الحدث مع شارة الانتظار |
| الموعد متعارض وتاريخان مختلفان | علامة عدم يقين وفتح المراجعة؛ لا اختيار الأحدث أو احتساب تأخر من أحدهما |
| الاستئناف يشير إلى سجل سُحبت صلاحيته | إزالة العنوان القديم وعدم فتحه؛ الرسالة عامة، والتنقل لبقية المسموح يستمر |
| المستخدم أخفى الدفتر ثم ظهرت أعمال انتباه | ملخص الوصول المحمي يبين وجودها بحسب المسموح؛ لا فتح القسم أو كشف محتواه رغماً عن التفضيل |
| انقطاع طويل ثم عودة | إشارة التباعد، مراجعة التعارض والصلاحيات قبل الاعتماد النهائي حيث يلزم؛ لا إعادة تهيئة تمحو العمل |

## 4. قواعد التعافي والإشعارات

- **الخطأ محلي الأثر:** فشل H-07 لا يوقف H-05، وفشل بحث في قاعدة لا يمحو نتائج القواعد الأخرى. أما سحب اعتماد المستخدم فيحكم كل السياق وفق الأمان.
- **إعادة المحاولة تخص المالك:** لا تنشئ الصفحة طابور مزامنة أو حفظ، ولا تحدد تكرارًا لا نهائيًا. تشرح ما سيعاد: تحميل مجموعة، بحث، أو استعلام نتيجة عملية.
- **الحداثة لا تُختلق:** إذا كان آخر النجاح غير معروف يبقى كذلك. عرض بيانات محلية صحيح لا يثبت أنها تشمل آخر تغييرات كل الأجهزة.
- **لا تسريب في النص:** تفاصيل تقنية/معرفات أجهزة/مسارات تخزين تظهر فقط في مسار دعم مأمون إن اعتمد، لا في رسالة عامة أو سجل تحليلات خارجي.
- **نجاح معلوم:** رسالة حفظ لا تظهر إلا بعد تأكيد المالك؛ الانتظار ليس فشلًا، والتعارض ليس فسادًا، ونقص البيانات ليس يومًا هادئًا.
- **لا مفاجآت مكانية:** تحميل الدفعة وإعادة المحاولة لا ينقلان المستخدم لأول الصفحة. إزالة عنصر لسبب أمني تتقدم على حفظ موضعه.

## 5. إمكان الوصول للحالات

| نوع التغير | الإعلان والتفاعل المقترح |
|---|---|
| تحميل/انتهاء نتائج | إعلان هادئ لمرة واحدة مرتبط بالمجموعة؛ لا قراءة الهيكل الوهمي |
| خطأ في إجراء المستخدم | رسالة ثابتة بجوار السياق، عنوان مفهوم، وتركيز على ملخص الخطأ أو الحقل لدى المالك |
| فشل جزء مستقل | لا سرقة تركيز من فعل آخر؛ رسالة قابلة للوصول وروابط تعافٍ مسماة |
| خطر أمني أو عملية لا يمكن إكمالها | نقل إلى مسار الأمان/المالك عند الضرورة مع تفسير، لا حوار دوري مزعج |
| مزامنة متكررة | لا إعلان كل تغيير نسبة؛ الحالة التفصيلية متاحة عند الطلب |
| عداد/تغطية | إعلان النطاق و«غير معروف» أو «جزئي»، لا تحويلها إلى صفر لقارئ الشاشة |

## 6. دليل التحقق المطلوب لاحقًا

تُحقن هذه الحالات في عقود المصادر أثناء اختبارات مستقبلية بعد اعتماد التقنية، لا بيانات إنتاج وهمية: رد متأخر، فشل مجموعة، غياب نسخة، كتابة فاشلة، نتيجتان متعارضتان، إبطال، تغير اليوم، reset متزامن. تقارن الرسالة والإجراء واستمرار الأجزاء المستقلة مع الجدول أعلاه. اجتياز التحليل النظري في [السيناريوهات](HOME_SCENARIO_VALIDATION.md) لا يستبدل هذه الاختبارات.
