## 1. قواعد عامة للحالات

1. **استقلال المناطق:** فشل منطقة يُعالج في مكانها ولا يعطّل المجرى أو البحث أو الإجراءات (P9 في الرؤية).
2. **ثلاث رسائل لا واحدة:** «لا يوجد» ≠ «لا تملك صلاحية» ≠ «غير متاح الآن» (U9).
3. **لا حالة وهمية:** كل مؤشر مرتبط بعقد مصدره؛ إن غاب المصدر فالحالة «غير متاحة» لا تقدير.
4. **كل خطأ له مسار:** رسالة + إجراء (إعادة محاولة، تفاصيل، مراجعة، رجوع).
5. **التحميل الهيكلي:** هيكل (skeleton) لكل منطقة؛ لا شاشة تجميد واحدة.

## 2. مصفوفة الحالات الشاملة

| الحالة | ما يظهر | السلوك | الإجراءات المتاحة | الرسالة المقترحة |
|---|---|---|---|---|
| **التحميل الأول** | هياكل في المجرى والسكّة؛ شريط السياق جاهز | مناطق تكتمل تدريجيًا | بحث متاح لحظة اكتمال مصدره | (بلا رسالة؛ هياكل صامتة) |
| **بيانات فارغة (لا أعمال)** | حالة هادئة: «لا أعمال مستحقة الآن» + القادمة المسجَّلة إن وُجدت | لا ملء بعناصر ضعيفة (P10) | الإجراءات والبحث كما هما | «لا أعمال مستحقة الآن. أعمالك القادمة المسجَّلة: …» |
| **لا نتائج بحث** | مساحة نتائج فارغة + صياغة محايدة | لا إخفاء للإدخال | تعديل البحث، تغيير النطاق | «لا نتائج لعبارة البحث» |
| **فشل تحميل منطقة (مجرى)** | حالة مصغّرة في رأس المجرى | بقية الصفحة تعمل | «إعادة المحاولة» | «تعذر تحميل الأعمال الآن» |
| **فشل تحميل وحدة سكة** | حالة داخل الوحدة فقط | بقية السكة والمجرى كما هما | «إعادة المحاولة» | «تعذر تحميل هذه الوحدة الآن» |
| **انقطاع الاتصال** | مؤشر «دون اتصال — تعمل محليًا» في شريط السياق | كل المدعوم محليًا يعمل (ADQ-18) | متابعة العمل؛ مزامنة يدوية لاحقًا | «تعمل محليًا. المزامنة عند عودة الاتصال» |
| **مزامنة جارية** | مؤشر حركي مهذب + نسبة إن توافرت من المنظومة | لا تجميد للواجهة | إلغاء المزامنة اليدوية (إن أتاحتها المنظومة) | «جارٍ تأمين التغييرات…» (صيغة منظومة المزامنة) |
| **تغييرات محلية معلقة** | شارة «تغييرات معلقة» | العمل مستمر | مزامنة يدوية | «تغييراتك على هذا الجهاز في انتظار المزامنة» |
| **فشلت المزامنة** | شارة دلالية + رابط التفاصيل | لا تُمسح البيانات المحلية | إعادة المحاولة، عرض التفاصيل | «فشلت المزامنة. عملك المحلي محفوظ» |
| **تعارض يحتاج مراجعة** | لافتة أعلى المجرى + عدّاد | لا استبدال صامت (ADQ-16) | «مراجعة التعارضات» → مسار المنظومة | «توجد تعديلات متعارضة تحتاج مراجعتك» |
| **بيانات قد لا تكون محدثة** | تنبيه لطيف عند التباعد المؤثر (ADQ-17) | العرض مستمر بوصفه محليًا | تحديث عند الاتصال | «قد لا تشمل هذه البيانات تغييرات غير متزامنة» |
| **قاعدة بيانات غير متاحة** | شريط السياق: القاعدة بحالة تعذر الوصول | لا عرض بيانات قاعدة أخرى بديلاً | فتح قائمة القواعد، إعادة المحاولة | «القاعدة النشطة غير متاحة على هذا الجهاز» |
| **التبديل بين القواعد** | نافذة: «توجد عملية جارية» (ADQ-04) | لا فقد ولا حفظ جزئي (ADQ-19) | استكمال / إلغاء بأمان ثم تبديل | «تُستكمل أو تُلغى العملية الجارية قبل التبديل» |
| **فقد الصلاحية (أثناء الجلسة)** | عناصر تختفي عند التحديث القادم؛ إن كان المستخدم ينظر إليها: إشعار | لا استمرار عرض بيانات ممنوعة | — | «تغيّرت صلاحياتك؛ بعض العناصر لم تعد متاحة» |
| **أعمال كثيرة (ازدحام)** | حدود الشرائح + عدادات صادقة | لا إسقاط صامت (P13) | «عرض الكل» لكل شريحة | — |
| **إخفاء أقسام بالتخصيص** | القسم يختفي؛ محتواه المهم يبقى ممثلاً في مساراته البديلة | لا فقد بيانات | إعادة الضبط | — |
| **استعادة التخصيص** | عودة فورية للوضع الافتراضي | تفضيلات الصفحة فقط | — | «أُعيد التخطيط الافتراضي» |
| **تحديث بيانات أثناء الفتح** | وميض خفيف للحد + إشعار «تحديث جديد» | لا قفز بالصف (U10) | «عرض التحديث» | «تتوفر بيانات أحدث» |
| **سجل لم يعد متاحًا** (فتح من استئناف/نتيجة بحث) | رسالة صريحة حسب السبب | لا رابط ميت | العودة، فتح قائمة القاعدة إن كان السبب التبديل | «السجل لم يعد متاحًا» / «السجل في قاعدة غير نشطة» / «لم تعد تملك صلاحية الوصول إليه» |
| **إخفاء كل أقسام السكة** | المجرى وحده + مسار عرض الوحدات | لا فقد وصول وظيفي (التخصيص C4) | قائمة «إظهار السكة» | — |
| **فشل إجراء محوّل** | رسالة عند الصف | لا تجميد للصفحة | إعادة المحاولة | «تعذر إتمام الإجراء. لم تُحفظ أي أجزاء منه» (ذرية ADQ-19) |
| **عملية مكررة سريعة** | الزر معطّل أثناء التنفيذ | منع الأثر المزدوج | — | — |

## 3. رسائل الحالة الثلاث — أمثلة موحدة

| الحالة | الصياغة | أين تظهر |
|---|---|---|
| لا يوجد شيء | «لا متابعات مستحقة اليوم» | داخل المنطقة المعنية |
| لا صلاحية | «لا تملك صلاحية عرض هذه البيانات» (نادر؛ الأصل ألا يظهر المُمنوع) | عند محاولة وصول موثقة |
| غير متاح الآن | «هذه الوحدة غير متاحة في هذا الإصدار» / «البحث غير متاح الآن» | عند غياب مصدر أو وظيفة |

## 4. حالات البحث التفصيلية

| الحالة | السلوك |
|---|---|
| كتابة أولى | تلميحات مبكرة إن أتاحتها المنظومة؛ لا استعلام قبل الحد الأدنى |
| جارٍ البحث | مؤشر في مساحة النتائج؛ الإدخال غير مجمد |
| نتائج جزئية | مصدر واحد فشل ضمن الشامل → «تعذر تضمين نتائج من: [القاعدة]» مع بقية النتائج |
| انقطاع أثناء البحث | استمرار على النسخ المحلية + لافتة ADQ-41 |
| محرك غير متاح | «البحث غير متاح الآن» + بديل: فتح القوائم الكاملة في الوحدات |
| سجل في قاعدة أخرى | شارة اسم القاعدة + فتح يمر عبر التبديل الآمن |

## 5. حالات المزامنة التفصيلية (سلوك الصفحة فقط)

| الحالة | المؤشر | أثر على المحتوى | الممنوع |
|---|---|---|---|
| متصل — متزامن | نقطة خضراء هادئة | — | — |
| دون اتصال | نقطة محايدة + نص | عرض محلي | الإيحاء بأن البيانات عالمية محدثة |
| مزامنة جارية | نبض مهذب | التحديث يصل تدريجيًا | تجميد المجرى |
| تغييرات معلقة | شارة عدد إن توافر | — | إخفاء الحالة |
| فشل | شارة أوكر/أحمر مطفأ + رابط | المحلي محفوظ (ADQ-17) | رسالة ذنب أو فقد |
| تعارضات | لافتة + عدّاد | العناصر المتعارضة تُشار إليها عند توافر ذلك من المنظومة | استبدال صامت أو «حُسم» تلقائي |
| انقطاع طويل | تنبيه التباعد (ADQ-17) | استمرار العمل | إعادة تهيئة ممحية للعمل المحلي |

## 6. تغيّر القاعدة النشطة

| الخطوة | السلوك |
|---|---|
| قبل التبديل | فحص العمليات الجارية (ADQ-04)؛ إن وُجدت: استكمال/إلغاء |
| أثناء التبديل | هيكل قصير للمجرى والسكة؛ شريط السياق يعرض الاسم الجديد فورًا |
| بعد التبديل | إعادة بناء المجرى والسكة للقاعدة الجديدة؛ **التفضيلات تبقى** (مرتبطة بالمستخدم)؛ **نص البحث والنتائج يُعاد تقييمها** (السياق محفوظ مع تنبيه «أُعيد البحث في القاعدة الجديدة») |
| سجل «استئناف» من قاعدة أخرى | يبقى ظاهرًا بشارته؛ فتحه يطلب التبديل الآمن |

## 7. تحديث البيانات أثناء الاستخدام

| الحالة | السلوك |
|---|---|
| تحديث مجرى يمس صفًا يقرؤه المستخدم | لا إزالة مفاجئة؛ الصف يُعلم «حُدِّث» ثم يُستقر |
| إضافة عمل مستحق جديد | إشعار «أُضيف عمل مستحق جديد» + زر «إدراج في المجرى» (لا قفز تلقائي) |
| اكتمال عمل من وحدة أخرى (مزامنة) | الصف ينتقل لحالة مكتملة ويخرج من المجرى مع وميض قصير مفسر |
| فقدان صلاحية عنصر مرئي | إزالة مهذبة + إشعار عام واحد لا رسالة لكل صف |

## 8. التحميل والأداء المُحسَّب

| البند | القرار |
|---|---|
| ترتيب التحميل | شريط السياق ← المجرى ← السكة (الأهم أولًا) |
| الجدولة | كل منطقة تُحدَّث مستقلة؛ لا حجب انتظار تام |
| الحدود | كل شريحة ≤ N عنصرًا (الافتراضي 5) + عداد الكلي |
| إعادة المحاولة | تلقائية مرة واحدة ثم يدويًا مع رسالة |
| لا تجميد | العمليات الثقيلة خارج مسار الرسم (وفق قدرات المنصة عند التنفيذ) |
