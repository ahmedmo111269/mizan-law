# المستخدمون ورحلات العمل اليومية

> **تحليل تصميمي مقترح، لا بحث ميداني مكتمل ولا مصفوفة صلاحيات.** أساس الرحلات: التكليف الحالي، [نموذج المجال](../DOMAIN_MODEL.md)، وحدود [الصلاحيات](../SECURITY_REQUIREMENTS.md). لا توجد وحدات منفذة لاختبار الرحلات عليها الآن.

## 1. يوم العمل الذي يُصمَّم له

يبدأ اليوم بفرز ما يستحق العمل، ثم يتكرر الانتقال بين سجل قانوني وموكل وإجراء، وقد يقع ذلك على هاتف أو دون اتصال. آخر اليوم مراجعة للنتائج لا تجميع لعدد النقرات. الفرضية المطلوب اختبارها مع المكتب: **تقليل فتح الأقسام المتتابع أهم من عرض مؤشرات الحجم الكلي**.

| شخصية للدراسة، لا دور معتمد | المهمة التي نختبرها | تكييف العرض المقترح، ضمن الصلاحيات نفسها |
|---|---|---|
| صاحب المكتب | متابعة القرارات والأعمال العالقة وتوزيع الانتباه | مرشح «المتاح لي» أو مسؤول معين إن دعم المالك الإسناد؛ لا افتراض رؤية كل الملفات |
| محامٍ | الاستعداد لجلسة ثم تسجيل نتيجتها | وقت/محكمة/قضية، وفتح الملف أو إجراء النتيجة |
| موظف إداري | تنفيذ إجراءات ومراجعة أوراق أو متابعات | مرشح نوع العمل، وحالة واضحة والإجراء التالي |
| سكرتارية | البحث السريع واستقبال موكل ومتابعة موعد | البحث و«جديد» قريبان، بلا افتراض صلاحية ماليات أو كتابة هوية |
| مسؤول متابعات | مراجعة الأعمال المتأخرة أو المنتظرة | قائمة كاملة محدودة الصفحات مع ترتيب معلن، لا إسقاط العناصر المزدحمة |
| مستخدم مالي أو مسؤول نظام | الوصول إلى إجراء متخصص إن كان متاحًا | رابط الوحدة الأصلية من الأقسام؛ لا لوحة مالية أو إدارة صلاحيات داخل الرئيسية |

لا تُضاف شخصية عميل خارجي ولا بوابة موكلين. الشخصية ليست مفتاح صلاحية ولا سببًا لتوسيع البيانات. «مسند إليّ» لا يظهر إذا لم توجد دلالة إسناد معتمدة في المصدر، وغياب الإسناد ليس «كل أعمال المكتب».

## 2. الرحلات الأساسية

معرفات المكونات H-01…H-10 موصوفة في [بنية المعلومات](HOME_INFORMATION_ARCHITECTURE.md). عدد الخطوات أدناه انتقالات مقترحة، لا قياسًا لزمن التنفيذ.

### HJ-01 — بداية يوم المحامي

| البند | المواصفة |
|---|---|
| الهدف | معرفة الأعمال المسندة أو المتاحة لليوم والمتأخر منها، دون جولة على الأقسام |
| البداية | فتح «مكتب اليوم» في قاعدة نشطة محلية ومصرح بها |
| الخطوات | 1. التحقق من القاعدة وتاريخ العرض والتغطية. 2. قراءة أسباب مجموعات العمل. 3. فتح العنصر أو تحويل العدسة إلى الأجندة |
| المعلومات اللازمة | نوع العمل، موعده ودقته، الحالة الفعلية، السبب، المحكمة/الجهة إن انطبق، المسؤول إن كان مدعومًا |
| الإجراءات | فتح سجل؛ فتح إجراءه السياقي؛ الوصول إلى القائمة الكاملة أو التصفية |
| الأخطاء | مصدر جلسات لم يُحمّل؛ صلاحية تغيرت؛ وقت الجهاز غير موثوق؛ لا يُفسَّر أي منها بصفر أعمال |
| الاحتكاك | سيطرة الجلسات على الشاشة وإخفاء المهام؛ افتراض أن كل جلسة أولوية أعلى |
| الاختصار المنعكس في التصميم | H-05 مجموعات بميزانية عرض مستقلة، H-04 مرشح صريح، H-09 حداثة وتغطية، بلا درجات قانونية |

### HJ-02 — الوصول إلى ملف قبل الجلسة

| البند | المواصفة |
|---|---|
| الهدف | العثور على الملف الصحيح وآخر نتيجة والاستعداد المسجّل قبل الحضور |
| البداية | جلسة ظاهرة في H-05 أو نتيجة من H-02 |
| الخطوات | 1. قراءة هوية الجلسة والقضية. 2. «فتح الملف» إن كانت له علاقة وحيدة متاحة، أو اختيار ملف من العلاقات المصرح بها. 3. الرجوع إلى العمل |
| المعلومات اللازمة | تاريخ الجلسة لا تاريخ تسجيلها، المحكمة، القضية/المسار، الملفات والأطراف بصفاتهم، نتيجة سابقة ومهام استعداد حقيقية |
| الإجراءات | فتح الجلسة؛ فتح الملف/القضية؛ فتح مهمة استعداد أو مستند في مالكه |
| الأخطاء | عدة ملفات للقضية؛ رابط غير متاح؛ مرفق غير موجود محليًا؛ لا يعرض مصدر غير مصرح به ولا يختار ملفًا عشوائيًا |
| الاحتكاك | اختصار رقم القضية دون نوع/سنة/جهة؛ تخمين ساعة جلسة؛ العودة إلى أعلى القائمة |
| الاختصار المنعكس في التصميم | H-06 ملخص سياقي عند الطلب، مرجع متعدد العلاقات، وعقد HC-08 يعيد موضع القائمة |

### HJ-03 — الأعمال الإدارية المستحقة

| البند | المواصفة |
|---|---|
| الهدف | تنفيذ المتابعات الإدارية دون تحويلها إلى جلسات أو مهام جديدة |
| البداية | قائمة العمل، مرشح نوع «إجراء إداري/متابعة» حيث يدعمه المصدر |
| الخطوات | 1. تصفية النوع أو المسؤول. 2. قراءة الوصف والحالة والموعد. 3. فتح الإجراء التالي من الوحدة المالكة. 4. العودة والانتقال للعنصر التالي |
| المعلومات اللازمة | الهوية الأصلية للعمل، الوصف، الملف أو الجهة، المسؤول، دلالة الموعد، الإجراء التالي |
| الإجراءات | فتح إجراء؛ تحديث حالة متابعة عبر المالك؛ فتح الملف |
| الأخطاء | المصدر لا يدعم الإسناد أو تحديث الحالة؛ سجل مؤرشف أو عملية محجوبة؛ لا زر «إنجاز» عام لكل الأنواع |
| الاحتكاك | عشرات العناصر المتشابهة؛ إعادة فتح الملف لكل متابعة؛ تكرار نفس الإجراء بسبب تعدد أطرافه |
| الاختصار المنعكس في التصميم | H-05 صفوف متجانسة مع بقاء النوع والهوية، «كل المتابعات» وصفحات ثابتة؛ التجميع بصري لا دمج |

### HJ-04 — تسجيل موكل جديد

| البند | المواصفة |
|---|---|
| الهدف | بدء مسار تسجيل الموكل من مكان واحد دون إنشاء هوية مكررة |
| البداية | H-03 «جديد»؛ القاعدة النشطة ظاهرة |
| الخطوات | 1. «جديد». 2. «موكل» إن كان المسار متاحًا. 3. إكمال مسار الوحدة الأصلية للتحقق والإضافة أو اختيار شخص قائم. 4. الوصول إلى بطاقته أو العودة |
| المعلومات اللازمة | قاعدة العلاقة، صلاحية الكتابة، حالة سجل الأشخاص المحلي؛ الحقول نفسها تملكها وحدة الموكلين |
| الإجراءات | استدعاء مسار إضافة الموكل فقط، لا نافذة مختصرة جديدة داخل الرئيسية |
| الأخطاء | تشابه أسماء؛ تطابق موثوق؛ فشل جزء من الحفظ؛ صلاحية ناقصة؛ تتعامل معها الوحدة ولا تسجل الرئيسية نجاحًا قبل تأكيدها |
| الاحتكاك | خلط «إضافة شخص» بـ«إضافة موكل»، أو اعتبار الشخص موكلًا في كل القواعد |
| الاختصار المنعكس في التصميم | HC-06/08؛ خطوة الوصول القصيرة لا تختصر التحقق. اعتماد CD-01/02/03/05/15 شرط تكامل، لا قرار جديد من الصفحة |

### HJ-05 — إنشاء ملف قانوني

| البند | المواصفة |
|---|---|
| الهدف | بدء ملف في القاعدة الصحيحة، سواء ارتبط بقضية أو لم يرتبط |
| البداية | H-03 «جديد ← ملف قانوني» |
| الخطوات | 1. مراجعة اسم القاعدة. 2. فتح مسار وحدة الملفات. 3. اختيار الأطراف والصفات واستكمال البيانات بحسب الوحدة. 4. حفظ وفتح الملف |
| المعلومات اللازمة | القاعدة، صلاحية الإنشاء، الأطراف عند اختيارها؛ لا ضرورة مفترضة لقضية واحدة |
| الإجراءات | إنشاء في المالك؛ ربط شخص قائم إن دعم المسار ذلك |
| الأخطاء | قاعدة قراءة فقط؛ تغيير القاعدة أثناء الإدخال؛ فشل الحفظ؛ لا يُنشأ ملف جزئي ولا تُربط بيانات من قاعدة أخرى صامتًا |
| الاحتكاك | فرض «قضية أولًا»؛ فقد النموذج عند تبديل قاعدة |
| الاختصار المنعكس في التصميم | HC-05/08 وحارس التبديل H-01؛ إجراء الملف مستقل عن إجراء القضية، والمسودات ليست مفترضة |

### HJ-06 — البحث عن قضية أو موكل

| البند | المواصفة |
|---|---|
| الهدف | الوصول إلى سجل بعينـه بذكرى جزئية أو رقم، مع معرفة مصدره |
| البداية | H-02 أو اختصار البحث العام على الكمبيوتر |
| الخطوات | 1. فتح البحث ونطاقه الافتراضي «القاعدة النشطة». 2. كتابة النص. 3. تضييق النوع أو اختيار «كل القواعد المحلية المتاحة». 4. فتح نتيجة واضحة النوع والمصدر |
| المعلومات اللازمة | عنوان أصلي، نوع، سبب المطابقة إن توفر، هوية القضية المرئية، اسم القاعدة لكل نتيجة ذات قاعدة |
| الإجراءات | فتح مباشر؛ تعديل النطاق؛ تصفية نوع؛ متابعة النتائج المحدودة |
| الأخطاء | لا نتائج؛ فشل قاعدة واحدة؛ صلاحية ناقصة؛ استجابة قديمة بعد تبديل النطاق؛ لا دمج نتائج متشابهة |
| الاحتكاك | إعادة كتابة النص عند العودة؛ عدم تمييز الشخص المشترك عن الموكل في قاعدة |
| الاختصار المنعكس في التصميم | HC-07 يستكمل C7 العام؛ بحث مصنف، عودة إلى النص والموضع، وتغطية محلية صريحة |

### HJ-07 — استئناف العمل السابق

| البند | المواصفة |
|---|---|
| الهدف | العودة إلى سجل فُتح سابقًا دون بحث جديد أو تتبع شامل للسلوك |
| البداية | H-07 «استئناف» إن وفر نظام التنقل مرجعًا صالحًا |
| الخطوات | 1. اختيار مرجع ظاهر مع قاعدته. 2. إعادة التحقق من الوجود والوصول والتوفر المحلي. 3. فتح المالك في آخر موضع صالح |
| المعلومات اللازمة | مرجع السجل والقاعدة وموضع منطقي غير حساس؛ العنوان يُجلب بعد التحقق، لا يُخزن في التفضيلات |
| الإجراءات | فتح؛ إزالة الاختصار من الاستئناف فقط، لا حذف السجل |
| الأخطاء | سحب صلاحية؛ سلة/نقل/دمج؛ قاعدة غير محلية؛ مسودة غير مدعومة؛ لا إعادة فتح محتوى مخزن بلا تحقق |
| الاحتكاك | الوعد باستعادة نص غير محفوظ؛ كشف اسم ملف على جهاز مشترك |
| الاختصار المنعكس في التصميم | HC-11، حتى ثلاثة مراجع جلسة مقترحة؛ الحفظ بين الجلسات والمسودات مؤجلان إلى HD-12 |

### HJ-08 — مراجعة المتأخر

| البند | المواصفة |
|---|---|
| الهدف | الوصول إلى كل عمل متأخر فعليًا ومعرفة ما يمكن فعله، لا عدّ الملفات القديمة |
| البداية | عنوان مجموعة «متأخر» في H-05 أو ملخص مجموعات العمل |
| الخطوات | 1. فتح المجموعة الكاملة. 2. قراءة الموعد المسجّل وسبب التأخر. 3. فتح السجل أو الإجراء. 4. العودة إلى العنصر التالي |
| المعلومات اللازمة | استحقاق ذو دلالة معتمدة، حالة مفتوحة، مسؤول إن توفر، روابط صحيحة |
| الإجراءات | فتح المهمة/الإجراء؛ إجراء الحالة من المالك؛ تصفية المسؤول/النوع |
| الأخطاء | مهمة اكتملت على جهاز آخر؛ موعد متعارض؛ لا ساعة مرجعية موثوقة؛ لا تحديث حالة جماعي يخفي الأخطاء |
| الاحتكاك | وضع جلسة قديمة بلا نتيجة تلقائيًا في التأخر؛ عدّ نفس المهمة في «اليوم» أيضًا |
| الاختصار المنعكس في التصميم | قاعدة إسناد وحيد للمجموعة في البنية؛ سبب واضح، وترقيم للقائمة الكاملة، دون تصنيف قانوني |

### HJ-09 — تسجيل نتيجة إجراء أو جلسة

| البند | المواصفة |
|---|---|
| الهدف | تسجيل نتيجة صحيحة في موضعها دون فقد الأصل أو اختلاق متابعة |
| البداية | الإجراء السياقي في صف العمل أو H-06 |
| الخطوات | 1. «تسجيل نتيجة» إذا أجازه المالك. 2. فتح نموذج المالك مع المرجع والقاعدة. 3. تحقق وحفظ محلي متكامل. 4. العودة مع تحديث العنصر المتأثر |
| المعلومات اللازمة | هوية السجل وحالته الحالية، العملية المتاحة، نتيجة التأكيد من المالك |
| الإجراءات | تسجيل نتيجة جلسة؛ تحديث متابعة؛ لا زر واحد يكتب الحالات لكل الأنواع |
| الأخطاء | ضغط متكرر؛ فشل حفظ؛ تعارض؛ فقد صلاحية؛ يظل النموذج لدى مالكه، ولا يُسقط الصف باعتباره مكتملًا قبل التأكيد |
| الاحتكاك | رسالة «تمت المزامنة» بدل «تم الحفظ محليًا»؛ افتراض أن تسجيل النتيجة يُغلق العمل |
| الاختصار المنعكس في التصميم | HC-08/09؛ النجاح المحلي والمزامنة إشارتان مستقلتان، وتصنيف الصف من حالة المصدر الجديدة |

### HJ-10 — مراجعة حصيلة اليوم

| البند | المواصفة |
|---|---|
| الهدف | قراءة ما أُنجز وما بقي والنتائج التي تحتاج متابعة، مع فتح كل سجل |
| البداية | H-08 «مراجعة اليوم» عند توفر الوجهة العامة |
| الخطوات | 1. تثبيت اليوم والنطاق والقاعدة. 2. قراءة بنود الإنجاز والنتائج والباقي. 3. فتح سجل يحتاج متابعة. 4. الرجوع إلى نفس المراجعة |
| المعلومات اللازمة | أحداث إتمام/نتائج مؤرخة من المصادر، حالة حالية، حدود التغطية والمزامنة |
| الإجراءات | فتح بند؛ تغيير نطاق أو تاريخ إذا دعمه التقرير؛ لا تصدير أو طباعة محليان داخل الرئيسية |
| الأخطاء | لا تاريخ إتمام؛ استعادة/تراجع؛ إتمام محلي غير متزامن؛ لا احتساب «آخر تعديل اليوم» بوصفه إنجازًا |
| الاحتكاك | جمع نتائج الجلسات والمهام في رقم إنجاز واحد؛ نتائج مكررة من سجل التدقيق والمصدر |
| الاختصار المنعكس في التصميم | HC-12؛ مراجعة بنود قابلة للفتح لا بطاقات إحصائية، أو إخفاء رابط التقرير إذا لم يتوفر مالكه |

### HJ-11 — العمل دون اتصال

| البند | المواصفة |
|---|---|
| الهدف | مواصلة العمل المحلي المدعوم ومعرفة ما لم يتزامن |
| البداية | فتح الصفحة بلا إنترنت، أو انقطاعه أثناء العمل |
| الخطوات | 1. قراءة حالة الاتصال بالمزامنة وتاريخ آخر نجاح المعلن. 2. البحث/الفتح المحلي. 3. تنفيذ عملية محلية إن سمح المالك. 4. مراجعة المزامنة عند توفر مسار اتصال |
| المعلومات اللازمة | توفر القاعدة والسجل المحلي، الصلاحيات المتاحة، حالة الحفظ، انتظار المزامنة/التعارض |
| الإجراءات | كل عملية محلية مدعومة؛ فتح حالة المزامنة؛ إعادة المحاولة فقط إذا كانت خدمة المزامنة تتيحها |
| الأخطاء | لا نسخة محلية؛ فشل كتابة؛ تباعد مؤثر؛ لا تُعرض عبارة «كل تعديلاتك محفوظة» لمجرد انقطاع الإنترنت |
| الاحتكاك | تعطيل التطبيق بسبب الإنترنت رغم وجود شبكة محلية؛ الادعاء أن البيانات حديثة عالميًا |
| الاختصار المنعكس في التصميم | H-09 حالة مركبة لا ثنائية، HC-09، ورسالة حداثة داخل نطاق البيانات لا لافتة خطأ عامة |

### HJ-12 — العمل على أكثر من قاعدة

| البند | المواصفة |
|---|---|
| الهدف | التنقل والبحث عبر القواعد المتاحة دون خلط العلاقات أو فقد عملية |
| البداية | مبدل H-01 أو نتيجة بحث شاملة |
| الخطوات | 1. اختيار قاعدة مصرح بها. 2. إن وجدت عملية مؤثرة: استكمالها أو إلغاؤها بأمان أو البقاء. 3. تفعيل السياق الجديد ومسح عرض بيانات القاعدة السابقة. 4. استرجاع موضع مستقل عند العودة |
| المعلومات اللازمة | هوية القاعدة واسمها، توفرها المحلي، القراءة فقط، حارس العملية، مرجع نتيجة البحث |
| الإجراءات | تبديل؛ فتح نتيجة في قاعدتها؛ العودة إلى قاعدة المصدر؛ لا نقل ملف من هذا المسار |
| الأخطاء | قاعدة غير محلية؛ حارس يرفض التبديل؛ استجابة متأخرة تخص القاعدة السابقة؛ سحب وصول |
| الاحتكاك | إنشاء موكل في قاعدة نتيجة قديمة؛ جمع حسابات أو أعمال قواعد بلا اختيار |
| الاختصار المنعكس في التصميم | HC-01/07/08؛ الصفحة لقاعدة واحدة افتراضيًا، والبحث الشامل مستقل؛ لا لوحة تجمع كل القواعد تلقائيًا |

## 3. حصيلة التحليل المؤثرة في الاختيار

1. HJ-01/03/08 تتطلب قائمة عمل متعددة الأنواع، لا تقويمًا مسيطرًا.
2. HJ-02/09 تتطلب سياقًا عند الاختيار، لا بطاقة تفاصيل لكل عنصر طوال الوقت.
3. HJ-04/05/06 تفرض بقاء البحث و«جديد» متاحين حتى في اليوم الفارغ أو بعد تخصيص الصفحة.
4. HJ-07/12 تجعل العودة والتبديل عقدًا عامًا لا مجموعة روابط بسيطة.
5. HJ-10/11 تمنع اعتبار الأعداد أو آخر تعديل أو الاتصال بالإنترنت إثباتًا للإنجاز أو الحداثة.
