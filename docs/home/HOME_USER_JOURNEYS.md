# رحلات المستخدم وتحليل المهام اليومية — «مكتب اليوم»

| الحقل | القيمة |
|---|---|
| الصفحة | «مكتب اليوم» — مركز العمل اليومي |
| المرحلة | تصميم وتحليل فقط |
| الحالة | **مقترح — بانتظار الاعتماد** |
| التاريخ | 2026-10-18 |
| الوثيقة الأم | `HOME_VISION.md` |
| الملاحظة | الرحلات **أساس تصميم**؛ نتائجها منعكسة مباشرة في بنية الصفحة، لا تقرير منفصل |

---

## 1. الأدوار في هذه الدراسة

> الأدوار أدناه **فرضيات اختبار** لفهم الاستخدام، وليست اعتمادًا لمصفوفة صلاحيات؛ تفاصيل الأدوار مؤجلة في المشروع (`docs/OPEN_QUESTIONS.md` §3). لا يفرض التصميم أدوارًا جديدة، وكل ما يتعلق بالوصول يمر عبر نظام الصلاحيات (ADQ-25).

| الدور | نمط الاستخدام اليومي المتوقع | ما تخدمه الصفحة له |
|---|---|---|
| صاحب المكتب | نظرة شاملة على الأعمال والجلسات والملفات المتأخرة | المجرى الكامل + حصيلة اليوم |
| المحامي | جلساته وملفاته وأعماله المسندة إليه قبل الجلسات وبعدها | مجرى «المسندة إليّ» + جاهزية الجلسات |
| الموظف الإداري | أعمال إدارية ومستندات ومتابعات محددة المهام | تصفية النوع + شرائح الاستحقاق |
| السكرتارية | مواعيد، اتصالات، تسجيل سريع، توجيه | الإجراءات السريعة + البحث |
| مسؤول المتابعة | كثافة متابعات وتغيير حالات وتسجيل نتائج | شريحتا «ينتظر» + إجراءات الصفوف |

## 2. الرحلات الاثنتا عشرة

### J1 — محامٍ يفتح البرنامج صباحًا ليستعرض جلساته وأعماله

| البند | الوصف |
|---|---|
| **الهدف** | معرفة ما يجب فعله اليوم خلال أقل من دقيقة |
| **نقطة البداية** | فتح البرنامج ← «مكتب اليوم» |
| **الخطوات** | 1) يرى شريط «الآن» (جلسات اليوم + المتأخر الحاد). 2) يمسح مجرى الأعمال من أعلى. 3) يفتح أولويته الأولى أو يغيّر التصفية إلى «المسندة إليّ» |
| **المعلومات اللازمة** | جلسات اليوم مسجلة، مهام/متابعات مستحقة، أسماء الملفات المرتبطة |
| **الإجراءات المتاحة** | فتح صف، فتح السجل المرتبط، تنفيذ الإجراء التالي، تحديث تصفية |
| **حالات الخطأ** | لا توجد أعمال مستحقة → حالة هادئة مفهومة (V-06)؛ فشل تحميل مصادر → استقلال المناطق |
| **نقاط الاحتكاك** | التنقل بين أقسام متفرقة لمعرفة اليوم؛ ضياع المتأخر في القوائم |
| **فرص الاختصار** | الصفحة الافتتاحية مباشرة؛ ترتيب جاهز دون إعداد |
| **الانعكاس في التصميم** | شريط «الآن» + المجرى مرتبًا افتراضيًا؛ تصفية «المسندة إليّ» بنقرة |

### J2 — محامٍ يريد الوصول إلى ملف قبل جلسة

| البند | الوصف |
|---|---|
| **الهدف** | فتح الملف والاطلاع على آخر تطورات القضية قبل الجلسة بدقائق |
| **نقطة البداية** | «مكتب اليوم» → وحدة «جاهزية الجلسات» أو صف الجلسة في المجرى |
| **الخطوات** | 1) يحدد جلسة اليوم/الغد. 2) يرى: المحكمة، القضية/المسار، الملف، آخر نتيجة، الأعمال التحضيرية. 3) يضغط «افتح الملف» |
| **المعلومات اللازمة** | بيانات الجلسة المسجلة، رابط الملف، آخر نتيجة/إجراء، الأعمال المرتبطة بالجلسة |
| **الإجراءات المتاحة** | فتح الملف، فتح سجل الجلسة، فتح مهمة تحضيرية، فتح القضية/المسار |
| **حالات الخطأ** | الملف غير متاح (صلاحيات/حذف/قاعدة أخرى) → رسالة صريحة + مسار بديل؛ لا أعمال تحضيرية مسجلة → «لا أعمال مسجلة لهذه الجلسة» لا تحذير مخيف |
| **نقاط الاحتكاك** | البحث عن الجلسة ثم عن الملف في مكان آخر؛ فقدان «آخر نتيجة» |
| **فرص الاختصار** | كل بيانات التهيئة ظاهرة في صف الجلسة نفسه؛ فتح الملف من داخله |
| **الانعكاس في التصميم** | وحدة جاهزية الجلسات + تشريح صف الجلسة (`HOME_UX_SPECIFICATION.md` §5) |

### J3 — موظف إداري يستعرض الأعمال الإدارية المستحقة

| البند | الوصف |
|---|---|
| **الهدف** | إنجاز الدفعة الإدارية المستحقة اليوم بالترتيب الصحيح |
| **نقطة البداية** | «مكتب اليوم» ← تصفية النوع «متابعات/إجراءات» |
| **الخطوات** | 1) يطبق التصفية. 2) يمسح شرائح الاستحقاق (متأخر ← اليوم). 3) ينفذ الإجراء التالي لكل بند ويحدّث حالته |
| **المعلومات اللازمة** | نوع العمل، الوصف المختصر، الحالة، الموعد، السجل المرتبط، المسؤول إن وُجد |
| **الإجراءات المتاحة** | فتح السجل، تحديث حالة المتابعة، تسجيل نتيجة، الانتقال للإجراء الإداري |
| **حالات الخطأ** | سجل مرتبط محذوف → «السجل المرتبط لم يعد متاحًا» مع إبقاء صف العمل وإحالته للتدقيق؛ حالة مزامنة معلقة → تنبيه لطيف |
| **نقاط الاحتكاك** | التكرار البصري لنفس العمل؛ غياب السبب في ترتيب القائمة |
| **فرص الاختصار** | شارة «سبب الظهور» تلغي السؤال «لماذا هذا هنا؟»؛ التحديث من الصف مباشرة |
| **الانعكاس في التصميم** | شريحتا «اليوم» و«متأخرة» + فلترة النوع + إجراء «تحديث حالة» |

### J4 — مستخدم يريد تسجيل موكل جديد

| البند | الوصف |
|---|---|
| **الهدف** | تسجيل موكل أثناء المقابلة دون مغادرة سياق يوم العمل |
| **نقطة البداية** | مركز الإجراءات ← «موكل جديد» |
| **الخطوات** | 1) يختار «موكل جديد». 2) **يُحوَّل إلى مسار الإنشاء في وحدة الموكلين** (الإضافة السريعة هناك). 3) بعد الحفظ يعود إلى الصفحة أو يبقى في البطاقة |
| **المعلومات اللازمة** | الحقول كما تحددها وحدة الموكلين (لا تفرضها الصفحة) |
| **الإجراءات المتاحة** | تحويل للوحدة المالكة فقط؛ الصفحة لا تملك نموذج إنشاء |
| **حالات الخطأ** | الوحدة غير منفذة بعد → **الإجراء غير معروض** لا زر معطّل؛ انقطاع → يكمل محليًا وفق ADQ-18 |
| **نقاط الاحتكاك** | مغادرة الصفحة وفقدان موضع المجرى |
| **فرص الاختصار** | فتح المسار بزر واحد + استعادة الموضع عند العودة (P14) |
| **الانعكاس في التصميم** | مركز الإجراءات + قاعدة «الغائب يُحجب» + عقد `H5` |

### J5 — مستخدم يريد إنشاء ملف قانوني جديد

| البند | الوصف |
|---|---|
| **الهدف** | فتح ملف قانوني جديد وربطه بموكل/قضية من نقطة الانطلاق اليومية |
| **نقطة البداية** | مركز الإجراءات ← «ملف قانوني جديد» |
| **الخطوات** | تحويل إلى مسار إنشاء الملف في وحدة الملفات `[غير منفذ]`، ثم العودة |
| **المعلومات اللازمة** | ما تحدده وحدة الملفات؛ الصفحة لا تجمع بيانات الإنشاء |
| **الإجراءات المتاحة** | التحويل فقط + حفظ الموضع |
| **حالات الخطأ** | كسابقتها (J4) |
| **الانعكاس في التصميم** | نفس مركز الإجراءات؛ لا نموذج موازٍ |

### J6 — مستخدم يبحث عن قضية أو موكل بسرعة

| البند | الوصف |
|---|---|
| **الهدف** | الوصول إلى سجل محدد خلال ثوانٍ من أي مكان |
| **نقطة البداية** | حقل البحث في شريط السياق (متاح في كل أحوال الصفحة) |
| **الخطوات** | 1) يكتب (بندسة عربية وفق ADQ-42). 2) يرى نتائج مصنفة حسب النوع. 3) في البحث الشامل تظهر اسم القاعدة لكل نتيجة. 4) يفتح السجل مباشرة |
| **المعلومات اللازمة** | عقد البحث العام؛ أسماء القواعد المتاحة |
| **الإجراءات المتاحة** | تصفية النوع/النطاق (نشط/شامل)، فتح السجل، العودة بالسياق |
| **حالات الخطأ** | لا نتائج، خطأ بحث، انقطاع (نتائج محلية + تنبيه)، سجل بلا صلاحية (لا يظهر أصلًا) |
| **نقاط الاحتكاك** | فقدان نص البحث أو النتائج عند العودة؛ نتائج بلا مصدر |
| **فرص الاختصار** | بحث دائم الظهور؛ حفظ السياق (P14) |
| **الانعكاس في التصميم** | `HOME_UX_SPECIFICATION.md` §4 + عقد `H2` |

### J7 — محامٍ يعود لاستكمال عمل سابق

| البند | الوصف |
|---|---|
| **الهدف** | متابعة من حيث توقف أمس دون إعادة البحث |
| **نقطة البداية** | وحدة «استئناف» في سكة اليوم |
| **الخطوات** | 1) يرى آخر سجلات فتحها (ملف/مهمة/موكل) بترتيب الأحدث. 2) يضغط فيعود إلى السجل نفسه لا إلى نسخة منه |
| **المعلومات اللازمة** | سجل «آخر فتح» (معرّفات + وقت)، فحص الصلاحية والوجود عند العودة |
| **الإجراءات المتاحة** | فتح السجل، مسح القائمة (اختياري)، التبديل للقاعدة المالكة للسجل عند الحاجة |
| **حالات الخطأ** | السجل حُذف/مؤرشف/أصبح بلا صلاحية/في قاعدة غير نشطة → إجراء صريح لكل حالة (لا رابط ميت) |
| **نقاط الاحتكاك** | فقدان الموضع؛ حفظ بيانات حساسة في «الأخيرة» |
| **فرص الاختصار** | القائمة قصيرة (3 عناصر مقترحة) ومحفوظة بأقل بيانات |
| **الانعكاس في التصميم** | وحدة «استئناف» + عقد `H3` + قيود الخصوصية |

### J8 — مستخدم يراجع أعمالًا متأخرة

| البند | الوصف |
|---|---|
| **الهدف** | معرفة المتأخر وحجمه ومعالجته بالأقدم أولًا |
| **نقطة البداية** | شريحة «متأخرة» (أول شريحة في المجرى) |
| **الخطوات** | 1) يفتح الشريحة (مفتوحة افتراضيًا). 2) يرى مقدار التأخير المسجَّل في «سبب الظهور». 3) ينفذ الإجراء التالي أو يؤجل بموعد مسجَّل جديد |
| **المعلومات اللازمة** | تاريخ الاستحقاق المسجَّل، الحالة، المرتبط |
| **الإجراءات المتاحة** | تنفيذ، تسجيل نتيجة، تعديل الموعد (في الوحدة المالكة)، فتح السجل |
| **حالات الخطأ** | تكرار محاولة غير مكتملة → ذرية ADQ-19 تمنع أثرًا مزدوجًا |
| **الانعكاس في التصميم** | ترتيب «الأقدم استحقاقًا أولًا» + شارة المدة |

### J9 — مستخدم يحتاج إلى تسجيل نتيجة إجراء أو جلسة

| البند | الوصف |
|---|---|
| **الهدف** | تسجيل النتيجة فور وقوعها (في المحكمة مثلاً) قبل نسيانها |
| **نقطة البداية** | زر «تسجيل نتيجة» في صف الجلسة/الإجراء أو من مركز الإجراءات |
| **الخطوات** | 1) يختار السجل. 2) يُحوَّل لنموذج النتيجة في الوحدة المالكة `[غير منفذ]`. 3) تُحدَّث حالة العمل ويُسجَّل الحدث في سجل النشاط |
| **المعلومات اللازمة** | سجل الجلسة/الإجراء، صلاحية التسجيل |
| **الإجراءات المتاحة** | التحويل للتسجيل + عرض النتيجة لاحقًا في صف السجل وفي حصيلة اليوم |
| **حالات الخطأ** | الوحدة غائبة → الإجراء محجوب؛ انقطاع → حفظ محلي وتنبيه مزامنة |
| **الانعكاس في التصميم** | إجراءات سياقية + ارتباط «حصيلة اليوم» بنتائج اليوم (H4) |

### J10 — مستخدم يراجع حصيلة يوم العمل

| البند | الوصف |
|---|---|
| **الهدف** | معرفة ما أُنجز وما بقي قبل إغلاق اليوم |
| **نقطة البداية** | وحدة «حصيلة اليوم» |
| **الخطوات** | 1) يفتح الوحدة. 2) يرى بنودًا: أُنجز اليوم، بقي، متأخر، نتائج جلسات، تنتظر قرارًا. 3) ينقر بندًا فينتقل إلى السجل/القائمة المرتبطة |
| **المعلومات اللازمة** | استعلامات جاهزة من الوحدات (H4): المكتمل اليوم، المسجل اليوم، الباقي |
| **الإجراءات المتاحة** | الانتقال لكل بند، فتح السجل، العودة |
| **حالات الخطأ** | مصدر غير متاح → بند الوحدة يعرض «غير متاح الآن» دون تعطيل باقي البنود |
| **الانعكاس في التصميم** | حصيلة بنقر قابلة للانتقال لا أرقامًا صماء (`HOME_UX_SPECIFICATION.md` §8) |

### J11 — مستخدم يعمل دون إنترنت

| البند | الوصف |
|---|---|
| **الهدف** | مواصلة يوم العمل رغم انقطاع الشبكة |
| **نقطة البداية** | «مكتب اليوم» في وضع محلي |
| **الخطوات** | يرى مؤشر «دون اتصال — تعمل محليًا»؛ يستعرض المجرى من النسخة المحلية؛ ينفذ الإجراءات المدعومة محليًا |
| **المعلومات اللازمة** | النسخة المحلية الكاملة (REQ-004) + حدود الصلاحيات (ADQ-25) |
| **الإجراءات المتاحة** | كل العمليات المحلية المدعومة (ADQ-18)؛ العمليات المشتركة المعلقة تظهر بحالتها الصريحة |
| **حالات الخطأ** | بيانات غير متزامنة → تنبيه عدم الحداثة (ADQ-41)؛ تعارض لاحق → مسار المراجعة |
| **الانعكاس في التصميم** | `HOME_STATES_AND_ERRORS.md` §5 + مؤشرات شريط السياق |

### J12 — مستخدم يعمل على أكثر من قاعدة بيانات

| البند | الوصف |
|---|---|
| **الهدف** | العمل في قاعدة والتتبّع بسهولة دون اختلاط |
| **نقطة البداية** | شريط السياق: اسم القاعدة النشطة + مبدّل |
| **الخطوات** | 1) يرى اسم القاعدة دائمًا. 2) يبدل القاعدة بأمان (تُستكمل أو تُلغى العملية الجارية أولًا — ADQ-04). 3) يُعاد بناء المجرى للقاعدة الجديدة مع الحفاظ على التفضيلات |
| **المعلومات اللازمة** | قائمة القواعد المتاحة، القاعدة النشطة، حالة العمليات الجارية |
| **الإجراءات المتاحة** | التبديل، البحث الشامل (مع اسم القاعدة)، فتح سجل من قاعدة أخرى عبر التبديل الآمن |
| **حالات الخطأ** | عملية غير مكتملة → إشعار «تُستكمل أو تُلغى قبل التبديل»؛ سجل في قاعدة أخرى من «استئناف» → تحويل للتبديل أو إشعار |
| **الانعكاس في التصميم** | شريط السياق + سلوك التبديل (`HOME_STATES_AND_ERRORS.md` §6) |

## 3. أنماط مشتركة استُخلصت من الرحلات

| النمط | الرحلات | النتيجة التصميمية |
|---|---|---|
| **البداية بسؤال واحد: ماذا عليّ اليوم؟** | J1، J3، J8، J10 | مجرى الأعمال هو البطل لا لوحة إحصاءات |
| **الوصول للسجل خطوة واحدة من العمل** | J2، J3، J7 | زر السجل/السياق المترابط في كل صف |
| **الإنشاء عبر الوحدات المالكة لا الصفحة** | J4، J5 | مركز إجراءات «محوِّل» لا نماذج موازية |
| **البحث في متناول دائم** | J6 | شريط سياق ثابت يحمل البحث |
| **الاستئناف يلغي إعادة الاستكشاف** | J7، J2 | وحدة استئناف مصغرة |
| **النتيجة تُسجَّل في اللحظة** | J9 | إجراءات سياقية على الصفوف |
| **الإغلاق اليومي دورة كاملة** | J10 | حصيلة قابلة للنقر لا أرقام صماء |
| **الانقطاع والقواعد واقع يومي لا حالات نادرة** | J11، J12 | مؤشرات صادقة + قاعدة النشطة بوضوح |
