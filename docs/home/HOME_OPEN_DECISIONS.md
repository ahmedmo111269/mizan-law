# القرارات المطلوبة لاعتماد «مكتب اليوم»

> **جميع البنود التالية معلقة.** التوصية ليست قرارًا، والسكوت ليس موافقة، ودمج وثائق التصميم لا يمنح إذن التنفيذ. لا تُعد هذه القائمة إعادة فتح للقرارات المعتمدة ADQ-01…ADQ-45.

## 1. فصل أنواع الموافقة

1. **بوابة التصميم:** الشكل والسلوك والترتيب والنطاق والحدود الآمنة. يمكن اعتماد الهيكل مع تأجيل ميزات مثل الاستئناف الدائم والتقرير.
2. **تثبيت عقود التكامل:** دلالات السجلات والأفعال والصلاحيات والمصادر، مع مالكي المجالات العامة؛ لا يصنع home بديلًا لحسمها.
3. **بوابة التقنية:** قرارات المشروع التقنية المؤجلة لا تزال غير معتمدة. بعد بوابتي التصميم والتقنية يلزم **أمر تنفيذي جديد** قبل البرمجة.

الحاجز له نطاق: غياب تقرير اليوم يمنع H-08، لا البحث. غياب الأمان أو التقنية يمنع تنفيذًا إنتاجيًا مأمونًا عمومًا. جميع التفاصيل المقترحة هنا قابلة للمراجعة ضمن حدود السلوك المعتمد.

## 3. ما لا يُعاد طرحه للاختيار

| ثابت معتمد | ما يبقى تفصيلًا مطلوبًا |
|---|---|
| مكتب واحد وقواعد مستقلة، هوية شخص مشتركة في التثبيت | طريقة عرض السياق والعودة، لا دمج القواعد |
| إتاحة قواعد متعددة وتبديل لا يفقد عملية | شكل الحارس وتكامل المالك، لا السماح بحفظ جزئي |
| بحث شامل محلي وفق الصلاحيات وتطبيع عربي معتدل | عقد النتائج والمصادر والقياس، لا بحث خاص أو تغيير الأصل |
| حفظ التعارضات ومراجعتها حسب الصنف | واجهة الإشارات والحسم العام، لا قاعدة آخر تعديل صامتة |
| الصلاحيات قيد على البيانات والعمليات | الأدوار والدقة وتحديث الاعتماد المحلي، لا إخفاء أزرار فقط |
| تشغيل محلي ومزامنة من الإصدار الأول | التقنية والمؤشرات، لا إعادة جعل المزامنة تحسينًا اختياريًا |
| السلة والأرشفة وثبات القيد والتدقيق | سياسة عرض الأعمال ونطاق التفاصيل، لا حذف تاريخ أو تغيير ماليات |
| دعم الحجم مع اختبارات فعلية | ميزانيات مقترحة وأجهزة، لا أرقام أداء مثبتة بالتصميم |

المرجع [DECISIONS.md](../DECISIONS.md). التفاصيل القانونية، مثل مشروعية حفظ معرفات وأي قواعد مواعيد إجرائية، تحتاج مراجعة متخصصة ولا تُحسم من صفحة يومية.

## 4. إحالات التعارض التي تحتاج توجيهًا

- **HX-01 → HD-10:** اعتماد توحيد مسودة التخصيص والعروض المحفوظة مع ADQ-16 في مهمة توثيقية لاحقة، أو إبقاء الحفظ المتزامن غير مفعل. لم يُغيّر أي ملف سابق هنا.
- **HX-02 → HD-12:** اقتراح مسودات الموكلين لا يعتمد استئناف النماذج في كل النظام. يلزم مالك واحتفاظ وحماية قبل إظهار الوعد.
- **HX-05 → HD-06/07/09:** توحيد إحالات رسم C2/C3 مقابل C4/C5 وإحالة قسم البحث عند تجميد العقود العامة؛ تستخدم هذه الحزمة جدول العقود والنص التفصيلي.
- **HX-06 → HD-05:** سياسة السلة والأرشيف في اليومية تقترح هنا صراحة، ولا تُستورد كقرار من PR #2 المفتوح.

التفاصيل والأدلة في [فحص المشروع §6](HOME_PROJECT_ASSESSMENT.md). لا تحتاج المراجعة الحالية إلى دمج أو إغلاق PR #2، ولا إلى تعديل قرار معماري نافذ.

## 5. تسلسل حسم عملي

1. اعتماد أو تعديل التصور والهوية والنطاق: HD-01/02/03/04/11/15/17.
2. إسناد مراجعة دلالات المصادر والعقود والأمان إلى مالكيها: HD-05/06/07/08/09/14؛ تحديد ما سيُفعّل وما سيبقى غير ظاهر.
3. حسم التخصيص/الاستئناف/الحصيلة بحسب النطاق المختار: HD-10/12/13؛ لا تجعل الميزات الاختيارية تعطّل أساسًا مستقلًا.
4. اعتماد خطة القياس قبل الأجزاء الحساسة: HD-16.
5. استكمال HD-18 في المسار التقني، ثم إصدار أمر تنفيذ محدد المراحل والاختبارات.

## 6. صيغة مراجعة مقترحة لصاحب المشروع

يمكن أن تكون نتيجة المراجعة: «اعتماد HD-01 وHD-15 كما هما»، و«تعديل HD-02 إلى …»، و«تأجيل HD-12/13 وعدم إظهار مكونيهما»، و«تكليف مراجعة العقود/التقنية لاحقًا». يجب أن يُذكر ما اعتُمد وما تأجل صراحة، لا عبارة عامة تفترض حسم CD أو التقنية.

**في جميع الأحوال يتوقف هذا التسليم عند الوثائق وطلب المراجعة. لا يبدأ الوكيل برمجة أو تصميم قاعدة أو تثبيت أدوات من تلقاء نفسه بعد أي خطوة توثيقية.**
