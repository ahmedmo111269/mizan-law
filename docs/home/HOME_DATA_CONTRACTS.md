## 1. حالة الواقع

> فحص المستودع: **لا توجد عقود تنفيذية ولا وحدات منفَّذة**. كل عقد أدناه **مسودة مقترحة** بُنيت على السلوك المعتمد، ولا تُلزم الوحدات بحقول أو دورات لم تعتمدها. عقود الأنظمة العامة (البحث، التخصيص، الصلاحيات، المزامنة، القواعد، التدقيق) **نفسها المستهلكة** في حزمة الموكلين؛ هذه الصفحة لا تُعيد تعريف ملكياتها بل تُعلن استهلاكها وتحدد حاجتها.

## 2. المبدأ الحاكم: الصفحة عرض لا مصدر

1. لا تُنشأ في الصفحة أي وحدة بيانات أو جدول أو «كيان عمل»؛ مجرى الأعمال **استعلام مركّب** (projection) فوق سجلات الوحدات.
2. كل عنصر وظيفي يُصنَّف بمصدره وحالتها: منفَّذ / مصمَّم / مستقبلي — واليوم لا شيء منفَّذ.
3. العمليات الكتابية كلها **تُحوَّل** إلى الوحدات المالكة عبر عقودها؛ الصفحة لا تكتب في مصادر البيانات.
4. لا يُنشأ مصدر بيانات «لتسهيل عنصر بصري»؛ إن لم يتوفر مصدر، يُحجب العنصر أو يُعرض بحالته الصريحة.

## 5. عقود الصفحة المقترحة

### H1 — استعلام مجرى الأعمال (WorkStreamQuery)

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة من الوحدات المالكة للسجلات |
| **الطلب** | قائمة عناصر مستحقة للمستخدم الحالي في القاعدة النشطة، محدودة العدد لكل شريحة، مع: نوع السجل، معرّفه، عنوانه المختصر، استحقاقه المسجَّل، حالته، مسؤوله (إن وُجد)، السياق المرتبط، سبب الظهور الآلي |
| **الضمانات** | لا يعيد المكتمل/الملغى؛ يحترم ADQ-25؛ لا يدمج قواعد؛ الترتيب وفق القاعدة المعتمدة (`HD-01`) |
| **دون اتصال** | من النسخة المحلية |
| **الفشل** | حالة مصغّرة في رأس المجرى مع «إعادة المحاولة»؛ لا سقوط للصفحة |
| **غير المسموح** | لا يُنشئ سجلات؛ لا يحتفظ بذاكرة جانبية للنتائج |

### H2 — مدخل البحث (SearchEntry)

| البند | المواصفة |
|---|---|
| **الاتجاه** | استعلام عبر منظومة البحث العامة |
| **الطلب** | نص + نطاق (نشط/سجل الأشخاص/شامل) + فلاتر نوع؛ نتائج مصنفة مع اسم القاعدة للشامل |
| **الضمانات** | ADQ-41 (المصدر، الانقطاع) وADQ-42 (التطبيع) يُطبَّقان في المنظومة لا في الصفحة |
| **الفشل** | حالات §4 من `HOME_STATES_AND_ERRORS.md` |

### H3 — سجل الاستئناف (ResumeContext)

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة/كتابة محدودة عبر التخزين/التفضيلات العامة (لا نظام موازٍ) |
| **الطلب** | حتى 3 عناصر: معرّف + نوع + قاعدة + وقت آخر فتح |
| **الضمانات** | لا محتوى ولا بيانات حساسة (ADQ-27)؛ الفتح يعيد التحقق من الوجود والصلاحية والقاعدة |
| **المزامنة** | تفضيلات المستخدم تُزامَن وفق ADQ-16 (إعدادات) — ما لم يُقرر `HD-04` خلاف ذلك |
| **الفشل** | إخفاء الوحدة باحترام؛ لا خطأ عام |

### H4 — حصيلة اليوم (DaySummary)

| البند | المواصفة |
|---|---|
| **الاتجاه** | استعلامات جاهزة من الوحدات المالكة |
| **الطلب** | ستة بنود: أُنجز اليوم / بقي ومستحق / متأخر / نتائج جلسات اليوم / إجراءات تحتاج متابعة / تنتظر قرارًا — لكل بند عدد + أحدث 3 + إمكانية القائمة الكاملة |
| **الضمانات** | الاحتساب بتوقيت مرجعي (ADQ-15)؛ الصلاحيات على البيانات؛ لا ماليات في الإصدار الأول |
| **الفشل** | بند مستقل يعرض «غير متاح الآن» |

### H5 — موجّه الإجراءات (ActionRouter)

| البند | المواصفة |
|---|---|
| **الاتجاه** | تحويل إلى الوحدات المالكة |
| **الطلب** | تنفيذ إجراء معرَّف (فتح/إنشاء/تسجيل) على سجل معرَّف أو بلا سجل |
| **الضمانات** | الهدف الغائب يُحجب (P5)؛ النتيجة تُسجَّل في سجل النشاط (ADQ-32) عبر المالك؛ الذرية (ADQ-19) في المالك |
| **الفشل** | رسالة عند نقطة التنفيذ + إعادة محاولة؛ لا تنفيذ جزئي |

### H6 — جاهزية الجلسات (SessionReadiness)

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة من وحدة الجلسات والمهام |
| **الطلب** | الجلسات القادمة ضمن النافذة (`HD-09`) مع: بياناتها + أعمالها المسجَّلة + آخر نتيجة + مؤشر «أنجز/الكل» |
| **الضمانات** | لا اشتقاق قانوني؛ المؤشر نسبة أعمال مسجَّلة فقط (شفافية) |
| **الفشل** | وحدة مستقلة |

### H7 — حالة الاتصال والمزامنة (SyncStatus)

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة من منظومة المزامنة |
| **الطلب** | الحالة العامة (متصل/دون اتصال/مزامنة/فشل/تعارضات/تغييرات معلقة) + عدّاد التعارضات + رابط المراجعة |
| **الضمانات** | لا حالة وهمية أبدًا؛ إن غابت المنظومة تُعرض «حالة المزامنة غير متاحة» |

### H8 — السياق والتخصيص (Context & Preferences)

| البند | المواصفة |
|---|---|
| **الاتجاه** | قراءة القاعدة النشطة (وحدة القواعد) + قراءة/كتابة تفضيلات `home.*` (منظومة التخصيص العامة) |
| **الضمانات** | التبديل الآمن (ADQ-04)؛ التفضيلات لا تتجاوز الصلاحيات ولا تحذف بيانات |
