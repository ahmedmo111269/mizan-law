# خريطة البيانات وعقود الاستهلاك

> **مسودات سلوكية تحتاج اعتمادًا، لا API أو مخطط تخزين أو تنفيذ.** أسماء المعلومات أدناه وصف لمعناها، لا اختيار أنواع بيانات أو بروتوكول أو بنية خدمات. لا يوجد مصدر تطبيقي منفذ عند أساس الفحص. كل وحدة مالكة مذكورة بحسب المجال، وليس ذلك اعتمادًا نهائيًا لتقسيم الوحدات REQ-015.

## 1. كيف تتصل الصفحة بالمشروع

- تبدأ العقود العامة من مسودات [تكامل الموكلين](../clients/CLIENTS_INTEGRATION_CONTRACTS.md): C6 للصلاحيات، C7 للبحث، C8 للتخصيص، C9 للمزامنة، C10 للقواعد، C5 للتدقيق.
- **HC** يصف ما تحتاجه الرئيسية كمستهلك، لا نظامًا بديلًا يملكه قسم home. تضاف الأنواع والمتطلبات الناقصة إلى نفس العقود العامة عند اعتمادها.
- القرارات ADQ-03/07/10/15/16/19/25/32/41/42/43 حدود نافذة، بينما التفاصيل الجديدة معلقة في HD-05…HD-14.
- لا تحتفظ الصفحة بنسخة مستقلة من مهام أو أشخاص أو تقارير؛ تحصل على إسقاط قراءة محدود، وتعيد الأفعال إلى المالك.

## 2. معلومات مشتركة لازمة لكل قراءة

| المعلومة المنطقية | الغرض والضمان المطلوب |
|---|---|
| نطاق التثبيت والمستخدم وسياق الصلاحية | عزل جلسات المستخدمين، وإعادة الفحص عند تغير الاعتماد أو الوصول |
| القاعدة/نوع المصدر/مرجع السجل الأصلي | هوية قابلة للفتح وعدم خلط قواعد أو دمج تشابه أسماء؛ الشخص المشترك له نطاق تثبيت بدل قاعدة مصطنعة |
| مرجع الطلب وسياقه | منع استعمال استجابة وصلت بعد تبديل القاعدة أو المرشح أو المستخدم |
| وقت/مرجع لقطة القراءة | اتساق الصفوف والعدادات والتنقل بين الدفعات؛ لا يُساوى بآخر مزامنة |
| نطاق التغطية | المصادر التي شملها الطلب، المكتمل/الجزئي/غير المعروف، والفشل ضمن المسموح؛ لا قائمة قواعد محجوبة |
| حداثة النسخة | وقت آخر تحديث محلي معروف وآخر مزامنة ناجحة إن عرفتهما الخدمة، والتنبيه إلى التباعد عند إبلاغ المالك |
| الاستمرار | مرجع الدفعة التالية/السابقة أو مؤشر وجود مزيد؛ لا حتمية معرفة إجمالي دقيق |
| قدرات المصدر/السجل | قراءة، معاينة، أفعال، إسناد، تواريخ إتمام، عمل محلي، قراءة فقط… يُعلن المتاح فعلًا |
| سبب عدم الإتاحة | خطأ مأمون لا يفضح وجود سجل/حقل محجوب؛ يميز الفشل المؤقت عن قدرة غير منفذة |

طلب البيانات يطبق قيود الوصول **قبل** الفرز والعدّ وتجميع النتائج. الصفحة لا تستلم بيانات محجوبة ثم تخفيها. جميع الروابط والأفعال تُفحص مرة أخرى عند الفتح أو الحفظ؛ إعلان القدرة ليس تفويضًا دائمًا.

### 5.1 الطلب المقترح

يتضمن: القاعدة، مرجع «اليوم» ووقت التقييم، العدسة والمجموعة والأنواع، نطاق «المتاح لي/المسند» إن دعم، الفرز المعلن، حدود المعاينة والدفعة، ومرجع السياق السابق إن وجد. لا يقبل العميل طلب «كل السجلات» لتصفيتها في الذاكرة.

الاستجابة تعطي مجموعات محدودة مع عدد دقيق **إن كان معلومًا ومصرحًا**، أو مؤشر مزيد، وحالة تغطية لكل مجموعة/مصدر. الصفحة الكاملة المقترحة 20 سجلًا؛ معاينات 3 أو 5 لكل مجموعة نشطة. هذه حدود استجابة أولية HD-16 لا سقف حجم للقاعدة.

### 5.2 دلالات ملزمة قبل تسجيل مصدر

1. يبين المالك هل الموعد **حد استحقاق** أم **وقت حدث**، وهل هو تاريخ فقط أم توقيت معلوم؛ لا يُستنتج من اسم الحقل.
2. يعلن معنى «مفتوح/مكتمل/ملغى/في السلة/مؤرشف» وأهلية العرض، دون فرض نفس الحالات على كل الأنواع.
3. «انتظار قرار/متابعة/انتباه» إشارة حقيقية مع سبب، لا تحويل ملاحظة حرة إلى قاعدة تلقائية.
4. يحدد الهوية الأصلية إذا عرضت وحدتان العمل نفسه؛ يسجل مصدر مالك واحد، ولا يُسمح بإزالة تكرار تشابهية تخفي عملًا مستقلًا.
5. يميز بين نتيجة غير موجودة، معلومة غير معروفة، ومعلومة محجوبة. الحجب لا يُفسر حالة عمل جديدة.
6. الفرز على كامل مجموعة النتائج قبل تقسيمها، لا فرز الدفعة الحالية وحدها. تغير اللقطة يمنع إعادة استعمال استمرار غير صالح.
7. عند تعدد الروابط لا تُنشأ صفوف بعدد الأطراف أو الملفات؛ المجموعة تعرض العمل مرة واحدة.
8. إن نقصت هذه الدلالات، لا يدّعي المصدر أهلية العرض الكامل. تعتمد السياسة قبل تفعيله؛ لا صفوف مخترعة لتجاوز الاعتماد.

|---|---|
| الغرض | الوصول للسجلات من بوابة واحدة في H-02 |
| البيانات المطلوبة | نص ونطاق وأنواع/مرشحات وحدود دفعة؛ نتيجة ذات نوع ومرجع وعنوان أصلي ومصدر وسبب مطابقة وتغطية واستمرار |
| المصدر/المالك | C7؛ [مسودة البحث العام §8](../clients/CLIENTS_SEARCH_AND_FILTERS.md) تُستكمل ولا تُستبدل |
| حالة المصدر | ADQ-41/42 معتمدان، مسودة عامة موجودة، لا محرك منفذ |
| العمليات المسموحة | بحث/تصفية/توضيح مطابقة/فتح؛ لا فهرس منزلي ولا تعديل النص الأصلي |
| الصلاحيات | تطبيق الوصول قبل النتائج والاقتراحات والعدادات؛ تفاصيل الحقول الحساسة من المالك |
| دون اتصال | جميع القواعد المتاحة محليًا فقط حسب النطاق، وسجل الأشخاص المصرح؛ ليست نتائج المكتب العالميّة |
| المزامنة | تُبيّن حدود التغيرات غير المتزامنة؛ تحديث الفهرس مسؤولية البحث لا الصفحة |
| الفشل | لا نتائج، فشل مصدر، نطاق غير متاح، طلب قديم، نص غير مقبول؛ النتائج الناجحة الأخرى تبقى مع تغطيتها |
| نقطة التكامل | توسيع مصادر المسودة لتشمل القضية/المسار والجلسة والموعد والمهمة والإجراء عند تنفيذها؛ نفس كشف المصادر والتطبيع العام، HD-07 |

لا يُفترض تنفيذ بحث نص المرفقات أو بحث دلالي أو صوتي. لا تعاد كتابة جداول التطبيع المقترحة في الموكلين داخل الصفحة؛ يلزم مراجعتها في مالك البحث عند تجميد العقد.

## 11. HC-08 — التنقل والإجراءات ونتيجة العملية

| البند | المواصفة |
|---|---|
| الغرض | فتح المصدر الصحيح وتفويض الفعل وحفظ العودة دون تكرار منطق الأعمال |
| البيانات المطلوبة | مرجع سجل/قاعدة ونوع، فعل معلن، مرجع عودة غير حساس، حالة عملية جارية، نتيجة حفظ/فشل/تعليق ومرجع السجل المحدث |
| المصدر/المالك | نظام التنقل العام والوحدة الأصلية؛ C6 يفحص العمليات وC5 يتلقى أحداثها من المالك |
| حالة المصدر | سلامة التبديل والذرية معتمدة ADQ-04/19؛ لا عقد تنقل أو سجل قدرات تنفيذي |
| العمليات المسموحة | طلب فتح/إجراء/عودة/تبديل آمن؛ لا عملية حفظ بيانات أعمال مباشرة في home |
| الصلاحيات | إعادة التحقق عند فتح المرجع وعند الحفظ؛ القدرة المعروضة لا تتجاوز أحدث قرار وصول متاح |
| دون اتصال | فتح وعمل محلي مدعوم؛ ما يتطلب اعتمادًا مشتركًا يبقى معلقًا، لا تحايله الصفحة |
| المزامنة | تأكيد الحفظ المحلي مستقل عن حالة الإرسال/المصالحة؛ نتيجة العملية لا تُستنتج من نجاح المزامنة |
| الفشل | مرجع قديم، عملية غير مكتملة، رفض، تعارض، فشل حفظ، أثر مجهول بعد انقطاع؛ يستعلم المالك عن النتيجة ولا يعاد الإنشاء بلا تحقق |
| نقطة التكامل | اعتماد حارس الانتقال وإعلان الأفعال وعودة السياق ونتائج عدم تكرار الأثر؛ وسيلة التنفيذ لاحقة، HD-06 |

لا تسجل الرئيسية حدث إنجاز ثانيًا مكررًا بجانب ما يسجله المالك. سجل التدقيق العام إلحاقي ADQ-32؛ لا تنشأ سجلات فتح وبحث تفصيلية تلقائيًا لأغراض «استئناف» أو «إحصاءات». سياسة تسجيل أحداث الواجهة المهمة تحتاج اعتمادًا عامًا وتقليل بيانات.

## 12. HC-09 — الاتصال والمزامنة والحداثة

| البند | المواصفة |
|---|---|

| العمليات المسموحة | قراءة حالة، فتح تفاصيل عامة، طلب مزامنة يدوية أو مراجعة تعارض إذا كانت الخدمة تتيحها |
| الصلاحيات | لا عداد تعارضات لملفات محجوبة، ولا بيانات أجهزة/مستخدمين بلا تصريح؛ الحسم بصلاحية مالكه |
| دون اتصال | العمل المحلي مستمر؛ لا يساوى انقطاع الإنترنت بانقطاع الشبكة المحلية أو عدم إمكان المزامنة |
| المزامنة | القاعدة وسجل الأشخاص نطاقان معروفان؛ يمكن تزامن أحدهما دون الآخر، فلا عبارة نجاح شامل زائفة |
| الفشل | آخر نجاح غير معروف، فشل إرسال، تعارض قائم، إبطال جهاز، إذن قديم؛ رسائل مستقلة ولا نجاح مصطنع |
| نقطة التكامل | عرض مركب للحالة وتوقيت المرجع وحدود التباعد من المالك؛ لا حد «قديم بعد ساعة» من الصفحة؛ HD-14 |

## 13. HC-10 — التخصيص العام

| المزامنة | إعدادات المستخدم بحسب نطاقها المعتمد؛ مراجعة القيم المتعارضة ADQ-16 لا فوز آخر تعديل صامتًا |

## 14. HC-11 — الاستئناف من التنقل العام

| المصدر/المالك | سياق التنقل HC-08؛ التفضيلات العامة إن اعتمد دوام المراجع، ونماذج الوحدات للمسودات |

## 16. ضمانات مشتركة واختبارات العقد قبل الربط

| الاختبار المستقبلي | النتيجة المطلوبة |
|---|---|
| مصدران يعيدان مرجع العمل ذاته | مالك واحد للعرض وعدّ واحد؛ لا دمج سجلات مستقلة متشابهة |
| قضية لها عدة ملفات | عمل واحد وروابط مصرح بها متعددة؛ لا افتراض ملف وحيد |
| رد طلب من القاعدة السابقة يصل متأخرًا | يُهمل، ولا يظهر تحت اسم القاعدة الحالية |
| فشل مصدر بعد نجاح مصدر آخر | النتائج الناجحة تبقى، والتغطية جزئية؛ لا «لا أعمال» |
| إتمام محلي ولم تتم المزامنة | المصدر يقر الإتمام المحلي، مع انتظار مزامنة مستقل؛ لا عودة لمستحق بسبب انتظار الإرسال وحده |
| سحب صلاحية لصف معروض | سحب بياناته ومعاينته وإعادة العدّ؛ لا عنوان مخبأ في resume/بحث/تفضيل |
| إعادة محاولة حفظ نتيجته مجهولة | المالك يضمن عدم تكرار الأثر؛ الرئيسية لا تنفذ إنشاءً ثانيًا |
| موعد تاريخي بلا ساعة، أو توقيت تعارض | يبقى بلا ساعة/متعارض، ولا يتولد استحقاق وهمي |
| تغيير/استعادة بنية أو لقطة | إبطال مراجع الاستمرار غير الصالحة، والتحقق من التوافق قبل الكتابة |

عدم تحديد وسيلة الجلب أو رسائل التحديث أو التخزين هنا مقصود: إنها جزء من بوابة التقنية، لا نقص يُملأ باختيار مكتبة من داخل وثيقة الصفحة.
