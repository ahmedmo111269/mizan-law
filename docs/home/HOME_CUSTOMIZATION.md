## 1. موقف حاسم

> **لا يجوز إنشاء نظام تخصيص داخل «مكتب اليوم».** التخصيص نظام عام مقترح (`CLIENTS_CUSTOMIZATION.md`) تُستهلكه الصفحة كأي وحدة أخرى. هذه الوثيقة فقط **تُعلن ما تدعمه الصفحة من مفاتيح** ضمن مساحة الأسماء `home.*`.

| المعيار | القرار |
|---|---|
| ملكية منظومة التخصيص | نظام عام (وحدة إعدادات/تخصيص مقترحة) |
| دور الصفحة | **مستهلك**: تعلن مفاتيحها وتقرأ قيمها وتكتبها عبر العقد |
| ما لا يُسمح | نسخة موازية، أو قاعدة تفضيلات خاصة بالصفحة |
| التوافق مع حزمة الموكلين | الطبقات L1 مفتوحة (ع/إخفاء/ترتيب/كثافة)؛ L2 مؤجلة؛ L3 غير موصى بها — **نفس الموقف** |

## 3. نطاقات التفضيلات

| النطاق | الاستخدام في الصفحة | المزامنة |
|---|---|---|
| **مستخدم** (الافتراضي) | كل مفاتيح `home.*` | نعم، بين أجهزته (ADQ-16: الإعدادات تُدمج وتُراجع المتعارض) |
| **جهاز** | كثافة العرض فقط (شاشة صغيرة/كبيرة) | لا |
| **دور** | غير مستخدم في هذه الصفحة | — (الأدوار مؤجلة في المشروع) |

> **القاعدة الذهبية كما في المنظومة العامة:** تفضيلات المستخدم تُزامَن؛ تفضيلات الجهاز لا تُزامَن؛ ولا شيء يُحل محل صلاحية.

## 4. أوضاع العرض الجاهزة (Presets)

| الوضع | التكوين | لمن |
|---|---|---|
| **اليوم الافتراضي** | المجرى كاملًا + السكة الثلاث + «الآن» ظاهر | الجميع عند البدء |
| **الجلسات أولًا** | «الآن» ظاهر + جاهزية الجلسات أولاً + مرشح يبرز الجلسات | المحامي في موسم جلسات |
| **متابعة إدارية** | مرشح المتابعات/الإجراءات + إخفاء جاهزية الجلسات + كثافة مضغوطة | الإداري/مسؤول المتابعة |
| **هدوء** | إخفاء «الآن» عند خلوها + السكة مطوية | من يفضّل مساحة |

> الأوضاع **حزم تفضيلات** لا أنظمة سلوك؛ تُستعاد منقولة بين الأجهزة مع المستخدم، ولا تتجاوز تفضيلات الجهاز في الكثافة.

## 5. القيود الحاكمة (غير قابلة للتتجاوز)

| # | القيد | السبب |
|---|---|---|
| C1 | **إخفاء ≠ حذف:** لا يحذف التخصيص بيانات أو أعمالًا | ADQ-44 روحًا، ADQ-25 |
| C2 | **لا يتجاوز الصلاحيات:** تفعيل إعداد لا يُظهر ممنوعًا | ADQ-25 |
| C3 | **لا يغيّر الفهرسة أو البحث:** العناصر المخفية تبقى في نتائج البحث | ADQ-41 |
| C4 | **لا يُفقد الوصول:** إخفاء السكة كلها يُبقي مسارًا (قائمة «إظهار السكة» أو تفضيل فتح السجل) | الأمر §16 |
| C5 | **لا يغيّر قواعد العمل:** الترتيب والظهور فقط؛ لا تعطيل تحقق أو ذرية | ADQ-19 |
| C6 | **كل تخصيص قابل لإعادة الضبط** بزر ظاهر | الأمر §16 |
| C7 | **التفضيلات ليست بيانات شخصية** ولا تُسجَّل كمحتوى سجلات | ADQ-10، ADQ-27 |
| C8 | **الصفحة لا تملك حقولًا مخصصة:** الحقول المخصصة شيء آخر (ADQ-44) وتخصيص الصفحة لا يمسها | الفصل المعتمد في `CLIENTS_CUSTOMIZATION.md` §3.3 |

## 8. عقد التكامل (عبر المنظومة العامة)

| العملية | الوصف |
|---|---|
| تسجيل مفاتيح الصفحة | `home.*` بنوعها وقيمها المسموحة وافتراضاتها — عند تهيئة الوحدة |
| قراءة | قيم فعالة للمستخدم/الجهاز |
| كتابة | عند تغيير المستخدم مع تسجيل المصدر والوقت |
| تصفير | إعادة ضبط مفتاح أو الصفحة كاملة |
| تصدير/استيراد | عبر نظام التفضيلات العام (إن اعتُمد) دون بيانات |

**الضمانات المستهلكة (كما في المنظومة العامة):** لا مفتاح يعطي صلاحية؛ لا مفتاح يغيّر قواعد العمل؛ القيم غير الصالحة تُتجاهل؛ كل كتابة لها سجل (ADQ-32 للإعدادات حيث يلزم).

## 9. ما لا تفعله تخصيصات الصفحة

1. إنشاء أو إسقاط حقول بيانات.
2. إخفاء بيانات عن مستخدم بصلاحية (الإخفاء تفضيل شخصي لا عقوبة).
3. تعطيل البحث أو الصلاحيات أو المزامنة.
4. تغيير معنى الحالات الدلالية أو ألوانها النظامية.
5. حفظ محتوى عمل (استئناف لا يُخزَّن هنا؛ انظر `HOME_DATA_CONTRACTS.md` H3).
6. إنشاء «لوحات مخصصة» حرة (L3) — غير موصى بها توافقًا مع المنظومة العامة.
