# القرارات التقنية المعلقة

لا تتضمن البنود أدناه توصية أو ترتيب بدائل؛ لا يُعتمد أي منها في هذه الوثيقة. حُسم السلوك وحدود البيانات في ADQ-01 إلى ADQ-45 في `DECISIONS.md`؛ المؤجل هنا طريقة التنفيذ فقط ولا يمنع النموذج المفاهيمي.

| المسألة | ما يتوقف عليها |
|---|---|
| شكل التطبيق | الوصول من الكمبيوتر والهاتف، والعمل المحلي، وتجربة المستخدم |
| لغة البرمجة | تنفيذ التطبيق وصيانته |
| إطار العمل | بناء التطبيق وتشغيله على الأجهزة المستهدفة |
| محرك قاعدة البيانات | تخزين البيانات والعلاقات والبحث والحجم |
| التخزين المحلي | النسخة المحلية الكاملة والعمل دون اتصال |
| آلية المزامنة وبنية جهة التنسيق | تنفيذ الاتصال المحلي والإنترنت والتنسيق تحت سيطرة المكتب واستمرار العمل المحلي وفق ADQ-05 وADQ-06 وADQ-14 |
| تنفيذ إدارة التعارضات | الاكتشاف والعرض وإجراءات المراجعة وفق السياسات المحسومة لكل صنف في ADQ-16 |
| تنفيذ الهوية والمعرفات | تمثيل الهوية وتوليد المعرفات والمطابقة والدمج داخل التثبيت وفق ADQ-03 وADQ-07 وADQ-11 إلى ADQ-14 |
| تنفيذ النقل والنسخ | آلية النقل والتحقق والمعالجة المحاسبية؛ الفصل والمحتوى والمصدر والمعرفات محسومة في ADQ-20 إلى ADQ-23 |
| التشفير والمفاتيح | حماية البيانات المحلية والمالية والمرفقات والنسخ وإبطال الأجهزة |
| النسخ والاستعادة | الوجهات والاعتماديات والتحقق والاستعادة عبر الأجهزة |
| بنية تخزين المستندات | الروابط والإصدارات والتطابق والمزامنة والنقل |
