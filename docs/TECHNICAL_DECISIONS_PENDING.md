# القرارات التقنية المعلقة

لا تتضمن البنود أدناه توصية أو ترتيب بدائل؛ لا يُعتمد أي منها في هذه الوثيقة.

| المسألة | ما يتوقف عليها |
|---|---|
| شكل التطبيق | الوصول من الكمبيوتر والهاتف، والعمل المحلي، وتجربة المستخدم |
| لغة البرمجة | تنفيذ التطبيق وصيانته |
| إطار العمل | بناء التطبيق وتشغيله على الأجهزة المستهدفة |
| محرك قاعدة البيانات | تخزين البيانات والعلاقات والبحث والحجم |
| التخزين المحلي | النسخة المحلية الكاملة والعمل دون اتصال |
| آلية المزامنة وجهة تنسيقها | تبادل التغييرات عبر الإنترنت أو الشبكة المحلية واستمرار العمل عند التعطل |
| إدارة التعارضات | حفظ التعديلات المتعارضة ومراجعتها وسياسات كل نوع بيانات |
| إدارة الهويات عبر القواعد | السجل المشترك ومنع الازدواج ومزامنة الهوية |
| نقل الملفات القانونية | حدود المحتوى، النقل أو النسخ، المعرفات والعلاقات والتحقق |
| التشفير والمفاتيح | حماية البيانات المحلية والمالية والمرفقات والنسخ وإبطال الأجهزة |
| النسخ والاستعادة | الوجهات والاعتماديات والتحقق والاستعادة عبر الأجهزة |
| بنية تخزين المستندات | الروابط والإصدارات والتطابق والمزامنة والنقل |
