# القرارات التقنية المعلقة

يحدد `TD-01` في `DECISIONS.md` تقنية **الأساس المحلي الأولي** ونطاقه فقط، استنادًا إلى موافقة صاحب المشروع بتاريخ 2026-10-18. لا يمثل ذلك اعتمادًا لمنظومة إنتاجية ولا يلغي الأسئلة التالية؛ لا يختار أي بند منها بديلًا تقنيًا.

| المسألة المعلقة | ما يتوقف عليها |
|---|---|
| مزامنة البيانات وبنية جهة التنسيق | بروتوكول المزامنة المحلية وعبر الإنترنت، التحكم تحت إدارة المكتب، النسخ المحلية الكاملة، العمل دون اتصال |
| إدارة التعارض | اكتشاف التعارض وعرض القيم ومراجعتها واعتماد حسمها لكل نوع سجل |
| الهوية على مستوى المنتج | المطابقة والدمج والتراجع وحفظ التاريخ والصلاحيات عبر الأجهزة والتثبيتات |
| المصادقة والتشفير | الحسابات، سياسات الأجهزة، تخزين المفاتيح واستعادتها وإبطالها وتحديث الصلاحيات |
| النسخ الاحتياطي والاستعادة | نطاق النسخ ووجهاته وتشفيره والتحقق منه واستعادته على جهاز آخر مع التبعيات |
| المستندات والمرفقات | مواضع التخزين والروابط والإصدارات والتعرف على التطابق والنقل والمزامنة |
| توافق الإصدارات | التحديثات عبر الإصدارات، منع الكتابة القديمة، النسخ الاحتياطي والترحيل القابل للتحقق والاستعادة |
| الاستيراد والنقل والتصدير | الصيغ والمعاينة والمطابقة والتراجع والاحتفاظ بالمصدر والاعتماديات |
| النشر والتوزيع | توقيع التطبيق والتحديثات وسياسة الإصدارات وتوليد حزم Windows وAndroid |
| الأداء التشغيلي | معايير قابلة للقياس واختبارات على أجهزة ممثلة وأحجام فعلية؛ لا توجد نتائج اعتماد أداء بعد |
| التدقيق والاحتفاظ | سجل التدقيق الإنتاجي وسياسات الاحتفاظ وسلة المحذوفات والإتلاف وفق المتطلبات القانونية |

التفاصيل التي يختبرها هذا الأساس المحلي فقط موثقة في `docs/implementation/`. لا تستخدمه ببيانات حقيقية قبل اعتماد وتنفيذ الضوابط الإنتاجية المناسبة.
