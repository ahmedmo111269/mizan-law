# حدود الاستخدام المحلي والأمان

## تحذير الاستخدام

**هذه نسخة تأسيسية محلية للاختبار ببيانات اصطناعية فقط. لا تستخدمها لحفظ بيانات موكلين حقيقية أو سرية أو أرقام هوية أو مستندات أو تفاصيل قضايا.**

إن وجود SQLite وترحيلات وفحوص تكامل لا يعني أن التطبيق آمن للإنتاج أو متوافق مع التزامات قانونية أو مهنية. لم تُجرَ مراجعة أمنية أو قانونية، ولا توجد ضمانات تشغيلية أو دعم إنتاجي.

## ما لا توفره النسخة

- لا حسابات مستخدمين أو مصادقة أو أدوار أو صلاحيات.
- لا تشفير لقواعد SQLite أو للمرفقات أو للنسخ الاحتياطية، ولا إدارة مفاتيح.
- لا مزامنة محلية أو عبر الإنترنت، ولا خادم أو خدمة سحابية أو معالجة تعارض متعددة الأجهزة.
- لا نسخ احتياطي واستعادة عبر الأجهزة أو سياسات احتفاظ أو حذف نهائي.
- لا سجل تدقيق إنتاجي، ولا تسجيل من فعل ماذا أو مراجعة قانونية لتدفقات البيانات.
- لا نظام مستندات أو مرفقات أو تصدير/استيراد إنتاجي.

## التعامل مع البيانات المحلية

- تحفظ ملفات SQLite في مجلد دعم التطبيق الذي توفره المنصة؛ لا توضع في مستودع Git. قد تبقى الملفات بعد إغلاق التطبيق أو حتى بعد إلغاء تثبيته حسب المنصة.
- لا تنسخ ملفات قواعد حقيقية أو سجلاتها إلى تذكرة أو محادثة أو مستودع عام. قد تتكون قاعدة التطبيق من فهرس وسجل أشخاص وعدة ملفات قواعد، ونسخ ملف منفرد يدويًا ليس نسخة احتياطية متسقة.
- التعديل على هوية مشتركة ينعكس على العلاقات التي تشير إلى الهوية في قواعد هذا التثبيت؛ يعرض التطبيق تأكيدًا قبل هذا التعديل. الأرشفة على العكس تخص علاقة واحدة في قاعدة العمل الحالية.
- تشخيص الأعطال يسجل اسم حدث تقني ونوع الاستثناء فقط، ولا يفترض تسجيل اسم الشخص أو الهاتف أو البريد. لا تزال سجلات النظام أو بيئة التطوير خارج نطاق ضمان الخصوصية الشامل.

## قبل أي استخدام حقيقي مستقبلًا

يلزم قرار وتنفيذ ومراجعة منفصلة للمصادقة، وإدارة الأجهزة والصلاحيات، وتشفير البيانات والمفاتيح، والنسخ الاحتياطي والاستعادة، والمزامنة والتعارض، والتدقيق والاحتفاظ، والاختبارات الأمنية، والاستشارات القانونية والمتطلبات التنظيمية. تُتبع المسائل المتبقية في [`docs/TECHNICAL_DECISIONS_PENDING.md`](../TECHNICAL_DECISIONS_PENDING.md). لا يرفع هذا الأساس حدًا أدنى من الضمانات إلى مستوى إنتاجي.
