# ملخص التنفيذ الحالي

**الحالة:** أساس تطبيق محلي أولي على الفرع `arena/61389710-mizan-law`. اعتمد صاحب المشروع المقترحات التقنية والتنفيذية لهذا النطاق في 2026-10-18. التنفيذ ليس إصدارًا إنتاجيًا ولا يحقق جميع متطلبات ميزان العامة.

## ما يعمل في النطاق المقصود

- تطبيق Flutter/Dart عربي من اليمين إلى اليسار، بواجهة متجاوبة على الهواتف والشاشات الواسعة.
- شاشة «مكتب اليوم» تعرض القاعدة النشطة وحالة السجل الحقيقي، والبحث المختصر والإجراءات المتاحة. لا تعرض مؤشرات أو سجلات وهمية.
- قائمة الموكلين مع بحث بالاسم والهاتف والبريد، وحالة نشط/مؤرشف، وترتيب وصفحات محدودة.
- إضافة موكل، واختيار هوية شخص موجودة، أو مراجعة نتائج تشابه قبل إنشاء هوية جديدة. التشابه تحذير وليس دمجًا.
- بطاقة موكل، وتعديل الهوية المشتركة بعد تأكيد واضح، وأرشفة علاقة الموكل بهذه القاعدة أو استعادتها.
- إنشاء قواعد عمل محلية مستقلة والتبديل بينها. يسجل فهرس التثبيت اسم كل قاعدة والقاعدة النشطة.
- ترحيلات SQLite مرقمة، وتحقق أولي من تكامل العلاقات عند بدء التشغيل، ورسائل تشخيص لا تطبع حقول الهوية.

## حدود نموذج البيانات

- هوية الشخص محفوظة مرة واحدة في سجل الأشخاص المشترك على مستوى تثبيت المكتب.
- علاقة الموكل وحالتها محفوظتان داخل ملف قاعدة العمل المختارة. يمكن للهوية المشتركة نفسها أن ترتبط بأكثر من قاعدة، لكن العلاقة والأرشفة لا تنتقلان بينها تلقائيًا.
- الصفة القانونية لشخص داخل ملف أو قضية ليست علاقة الموكل نفسها، ولم تُنفذ هنا إدارة ملفات أو قضايا.
- لا توجد عملية حذف نهائي من واجهة الموكلين؛ أرشفة العلاقة قابلة للعكس ولا تحذف هوية الشخص.

## خارج النطاق

لا تشمل هذه الدفعة الملفات والقضايا والأطراف والصفات القانونية، والجلسات والمهام والإجراءات والمستندات والمالية، والمزامنة أو الخدمة المركزية، والبحث بين القواعد، والمستخدمين والصلاحيات، والتدقيق الإنتاجي، والتشفير، والنسخ الاحتياطي والاستعادة، أو استيراد البيانات. لا يوجد ادعاء بشأن جاهزية قانونية أو أمنية أو أداء واسع النطاق.
