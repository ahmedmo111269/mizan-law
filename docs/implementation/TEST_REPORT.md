| التحقق | النتيجة | ما يثبته |

شملت مجموعات اختبارات Dart: تطبيع العربية، مستودع الموكلين، قاعدة المكتب، اختبار بدء واجهة المكتب، والتنقل والواجهة المتجاوبة. استخدمت الاختبارات أسماء ومعرّفات اصطناعية وقواعد مؤقتة؛ لا تستخدم بيانات أشخاص حقيقية.

## ما لم يُنفذ محليًا أو على جهاز فعلي

لم يكن Flutter SDK أو Dart متاحًا في بيئة العمل المحلية، لذلك لم تُشغّل فيها `flutter pub get` أو `flutter analyze` أو `flutter test` أو بناء المنصات. نُفذت هذه الفحوص بنجاح على GitHub Actions في التشغيل المشار إليه أعلاه.

لم يُشغّل التطبيق على هاتف أو جهاز Windows فعلي، ولم يُختبر توزيع APK على جهاز Android. بناء CI يتحقق من نجاح خطوات البناء المحددة فقط، ولا يثبت عمل التطبيق على كل الأجهزة.

## ما لا يثبته تقرير الاختبارات

نجاح CI وعقد SQL لا يثبتان التوافق مع جميع إصدارات Android وWindows، أو سلامة إغلاق التطبيق أثناء الكتابة، أو الأداء عند البيانات الضخمة، أو التشفير أو النسخ الاحتياطي أو المزامنة. لا يثبتان الجاهزية الإنتاجية. يلزم اختبار المنصات المستهدفة ومراجعة الأمن والتشغيل قبل اعتماد نسخة قابلة للتوزيع.
